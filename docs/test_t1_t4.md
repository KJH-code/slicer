### 1.1 T1 — 관례 각도 대 자동 결정

**팔 (arm)**

| 팔 | 정의 |
|---|---|
| 고정 15° · 20° · 25° · 45° | 균일 원뿔 (outward) |
| 자동 균일(J) | `select_banded_j(N=1)` — 기준선 (a) |
| 자동 밴드2 | `select_banded_j(N=2)` |
| 균일(밴드2 아랫각) | 기준선 (b) — 참고용으로 같이 적는다 |
| **사후 최적 균일** (정답지) | 아래 후보 집합에서 미지지 mm 최소. 동점(차 ≤ 1e-6mm)은 \|θ\| 작은 쪽 |

**사후 최적의 후보 집합**: outward 격자 0~44° (2°) ∪ 고정 각 {15, 25, 45} ∪ {자동 균일(J) 의 각}.
inward(음수) 격자는 **해석식으로 가지치기**한다 — 그 모델에서 어떤 음수 격자각의 해석식 서포트가
0° 의 해석식 서포트보다 작을 때만 음수 격자 전체를 후보에 넣는다. 이 가지치기를 확인하려고
모든 모델에서 −20° 의 툴패스 mm 를 0.4mm 에서 한 번 재서 같이 적는다.
후보 집합이 고정 각을 포함하므로 균일 팔의 후회는 항상 ≥ 0 이다 (밴드2 는 음수가 될 수 있다).

**지표**: 미지지 mm, 평균 |θ|(`compare_waist.mean_abs_angle`), **후회** = 팔의 mm − 사후 최적의 mm.

**베드 상한 두 판**
- 상한 없음: 위 그대로.
- 상한 있음 (B_safe = 22.79°, `analyze_gap_sample.BED_CAP` = `floor(b_safe)` 층고 0.3 값; 층고 0.4 의
  계획기 값 23.38° 보다 작아 두 층고 모두 안전): 고정 25°·45° 는 **실현 불가**로 표시하고 판정에서 뺀다.
  자동 팔은 `select_capped` 의 균일·밴드2. 사후 최적은 후보 집합 중 |θ| ≤ 22.79° 인 것.
  참고로 25°·45° 를 계획기(`bed_safe_profile`) 에 넣어 나온 '요청 + 램프' 프로필도 재서 적는다 (판정 밖).

**사전 기준 (판정 셀 4개 = 층고 2 × 상한 판 2)**
- 셀마다: **자동 균일(J) 의 후회 중앙값(21 모델)이 실현 가능한 모든 고정 각도의 후회 중앙값보다 엄격히 작으면**
  그 셀 통과. 4 셀 모두 통과 → "자동 결정이 관례 각도보다 낫다(미지지 기준)".
- 자동 밴드2 에도 같은 기준을 따로 적용해 적는다 (보조).
- 어느 고정 각이 자동과 같거나 나으면 그 각도와 이유(표본이 그 각도 근처에 몰렸나 — 사후 최적 각의 분포로 본다)를
  적용 범위로 기록한다.
- **미리 적어 두는 우려**: J 는 각도 비용(k·평균|θ|)을 같이 보므로 mm 만 보는 후회에서는 큰 고정각(45°)이
  자동보다 작게 나올 수 있다. 그 경우 결론은 "mm 만으로는 자동이 이기지 못한다" 로 적고, 보조 지표로
  **고정 각 대비 자동이 mm(0.5mm 무승부)·평균|θ| 두 축에서 모두 같거나 나은 모델 수**(파레토 비지배)를 같이 적는다.
  이 보조 지표는 기준을 대신하지 않는다.

### 1.2 T4 — 견고성 (한 축씩만)

**기준점**: 표본 모델 그대로, 임계각 45°, 층고 0.3/0.4.

| 축 | 값 | 구현 |
|---|---|---|
| 메시 해상도 | 세분화 ×4 | `trimesh.Trimesh.subdivide()` (중점 분할, 면 4배). **곡면 형상은 그대로**라 삼각분할 불변성 확인이다 |
| | 단순화 ×0.5 | `simplify_quadric_decimation(face_count = 면수/2)` (`fast_simplification`) → `center_on_axis`. 형상이 실제로 바뀐다 |
| 축 정렬 오차 | 중심 0.1·0.5mm 이동 | 센터링 뒤 x 로 평행이동, **다시 센터링하지 않는다** (축 추정 오차를 흉내) |
| | 축 1°·3° 기울임 | x 축 둘레로 회전 → `center_on_axis` (기울어진 채 저장된 STL 이 파이프라인을 타는 경우) |
| 임계각 | 40° · 50° | 선택기의 `threshold_deg` 만 바꾼다. 검사기 A 에는 임계각 손잡이가 없어 mm 측정은 같다 |
| 층고 | 0.2 | 선택기에는 층고 입력이 없어 각도는 정의상 같다. mm 만 잰다 |

**지표**: 자동 균일(J) 각의 변화 |Δθ|(°), 자동 밴드2 각의 변화 max_i |Δθᵢ|(°), 각 팔의 미지지 mm 변화(같은 층고끼리).

**사전 기준**
- 해상도(2값)·정렬 오차(4값) 의 교란마다 **|Δθ| ≤ 2°(격자 한 칸) 인 모델 비율**을 자동 균일·자동 밴드2 각각 보고한다.
  해석: 축(해상도 / 정렬)의 모든 교란에서 그 비율이 **≥ 90%** 면 그 축은 "견고" 라 쓴다. 아니면 어긴 모델을 적는다.
- 세분화 ×4 는 형상이 같으므로 |Δθ| = 0 이 아니면 **구현 결함 신호**로 따로 적는다.
- **튐 세기**: |Δθ| > 2° 이면서, 교란 메시에서 **원래 각도의 J 가 새 최선 J 와 k·격자 = 0.2×2 = 0.4 %p 안**이면
  "평평한 목적함수 위의 튐" 으로 분류해 따로 센다 (`verification.md` 2026-09-28 의 24°→32° 와 같은 부류인지 표시만).
- 임계각: 방향 기대 = **임계각↑ → 고른 균일각 비증가** (θ(40°) ≥ θ(45°) ≥ θ(50°)). 이 순서를 지키는 모델 비율을 보고한다.
  밴드2 는 평균 |θ|(메시 면적 가중) 로 같은 순서를 본다.
- 층고: 각도 변화 0 을 확인하고(정의상), mm 가 층고에 따라 어떻게 변하는지만 적는다 (기준 없음).

### 2.2 적용 범위 — 왜 그런가 (사후 최적 각의 분포)

- **상한 없음**: 사후 최적 균일각이 **큰 각도 쪽에 몰려 있다** — 층고 0.3 에서 21 중 16 모델이 30~36°, 3 모델이 45°;
  층고 0.4 에서 18 모델이 38~44°. 툴패스 미지지 mm 는 각도를 키울수록 거의 단조로 줄고, J 는 k·평균|θ| 비용 때문에
  22° 근처에서 멈춘다. 그래서 각도 비용이 없는 mm 후회에서는 45° 가 가장 가깝다. 이건 J 의 각도 비용(k=0.2)이
  '미지지 mm 만' 이라는 판정 지표와 **목적이 다르다**는 뜻이지, 45° 가 실물에서 낫다는 뜻은 아니다 —
  45° 는 베드 충돌로 이 기계에서 실현할 수 없다(아래).
- **상한 있음**: 사후 최적이 거의 모두 **상한 바로 아래 22°** 에 붙는다(0.3: 19/21, 0.4: 18/21). 자동 팔(`select_capped`)도
  대부분 22° 를 고르므로 후회가 0 이다. 즉 상한 셀의 '통과'는 **"상한까지 각도를 올리는 것이 관례 15°·20° 보다 낫다"** 는
  것에 가깝고, 자동 선택기의 형상 적응 능력을 보인 것은 아니다. 예외는 0.3 의 torus(−6°)·mushroom(4°),
  0.4 의 funnel(6°)·mushroom(6°)·허리3 ×1.5(20°)다. 자동은 torus(밴드2 [−6,2])·0.3 mushroom 을 맞췄고(후회 0),
  **funnel 은 두 층고 모두 크게 놓쳤다** — 상한 판 자동이 0° 를 골라 미지지 736 mm(0.3, 정답 22° 는 2 mm),
  942 mm(0.4, 정답 6° 는 523 mm).
- 자동 밴드2 는 상한 없는 0.3 에서 자동 균일보다 낫지만(6.9 대 15.7) 0.4 에서는 나빠진다(56.1 대 43.3) —
  층고 0.4 에서 구·sphere·허리3 ×2 의 밴드2 미지지가 균일보다 크다(94 대 36, 58 대 21, 316 대 3). 밴드2 가 층고에 따라
  균일보다 나빠질 수 있다는 것이고, T4 에서 밴드2 가 균일보다 덜 견고했던 것과 같은 방향이다.

### 2.4 음수 격자 가지치기 확인과 민감도 (§1.4)

- 해석식 가지치기는 **42 작업 모두에서 음수 격자를 뺐다**. 그런데 −20° 스팟 측정(층고 0.4)에서 −20° 가 0° 보다 0.5mm 넘게
  나은 모델이 많았다(구 123/227, 로브 5 종 90~94/136~150, sphere 115/227, funnel 82/942, torus 115/152 등).
  **해석식 가지치기는 툴패스 미지지와 맞지 않는다** — 해석식은 면적 몫이고, 검사기 A 는 페리미터 길이라 같은 순서를 보장하지 않는다.
- 민감도(음수 격자 −2~−44° 전체를 잰 정답지, 층고 0.3 에서 10 모델, 0.4 에서 11 모델): 셀 판정이 **하나도 바뀌지 않는다**.
  후회 중앙값 변화는 0.4·상한에서 고정 20° 3.8 → 4.6 (자동 균일 2.7 그대로, 통과 유지) 뿐이고, 정답이 음수로 옮겨간 것은
  0.4·없음 torus(−12°), 0.4·상한 funnel(−20°)·torus(−12°) 셋이다.

### 3.2 튐은 대부분 '평평한 목적함수 위의 튐' 이다

|Δθ| > 2° 인 경우 60 건(해상도·정렬, 균일+밴드2) 중 **53 건**에서, 교란 메시 위에서 **원래 각도의 J 가 새 최선 J 와 0.4 %p(= k × 격자 한 칸) 안**이었다.
즉 선택이 바뀐 것은 목적함수가 그 근방에서 거의 평평해 격자 위 argmax 가 옮겨 간 것이고, 원래 각도도 여전히 거의 최선이다
(`verification.md` 2026-09-28 의 24°→32° 와 같은 부류로 보인다 — 별도 세션 확인 대상).
평평하지 않은 튐 7 건: funnel(세분화 밴드2 ΔJ 37.9, 기울임 3° 균일 21.7 · 밴드2 50.7), 구(단순화 밴드2 0.62),
허리3 ×1.5(중심 0.5 밴드2 0.73), mushroom(기울임 3° 2.2 · 2.7).
- funnel 은 면 64 개짜리 높이 5mm 의 얕은 원뿔이라 면 하나하나가 서포트 몫을 크게 바꾼다.
- mushroom 은 갓 아랫면이 수평(90° 오버행)이라 0~44° 어느 원뿔로도 못 고친다(기준 0°). 3° 기울이면 갓 아랫면의
  반쪽이 87° 가 되어 44° 원뿔로 일부가 풀리므로 선택이 0° → 44° 로 간다. **형상 자체가 바뀐 경우**라 튐으로 보지 않는다.

### 3.3 세분화 ×4 — 사전 등록한 '결함 신호' (자동 밴드2 에서만)

중점 분할은 곡면을 바꾸지 않는데 **자동 밴드2 의 각도가 8 모델에서 바뀌었다**(그중 > 2° 는 4 모델: 구 20→24°,
허리3 ×1.2 4→0°, ×1.3 [32,14]→[30,10], funnel 22→26°). 자동 균일은 21/21 모두 그대로다.
원인: `varangle.assign_height_bands` 가 밴드 경계를 **면 무게중심 z 의 최소~최대**로 정하고 면을 무게중심으로 배정한다.
면을 쪼개면 무게중심 범위가 실제 모델 높이 쪽으로 넓어져 경계가 움직이고, 경계를 걸친 면이 갈라진다.
즉 **밴드 경계가 삼각분할에 의존한다**(형상 기준이 아니다). 판정식(해석식) 자체의 결함은 아니고, 밴드 배정 규칙의
메시 의존성이다. 고치지 않았다(기본 동작 변경 금지) — 경계를 bounds z 로 정하는 수정 후보로 남긴다.

### 3.4 임계각 — 방향

기대(사전): 임계각↑ → 고른 균일각 비증가, θ(40) ≥ θ(45) ≥ θ(50).
- 자동 균일: **18/21** 이 지켰다. 어긴 3 개: 구 [40, 28, 30], torus [0, 6, 2], mushroom [0, 0, 40].
- 자동 밴드2(평균 |θ|): 14/21.
- 크기: 40° 로 낮추면 균일각이 중앙 6°(최대 12°) 커지고, 50° 로 올리면 중앙 4° 작아진다 — 방향은 대체로 맞다.
- 어긴 사례의 성격: mushroom 은 위 3.2 와 같은 구조다 — 임계각 50° 에서는 갓 아랫면(90°)을 40° 원뿔이
  50° 로 낮춰 **풀 수 있게** 되므로 각도가 오른다. '임계각↑ → 각도↓' 는 필요한 각도가 상한(44°) 안일 때만 성립한다.
  구·torus 는 2° 격자와 선형 각도 벌점의 평평한 J 위에서 생긴 비단조(구 θ(45)=28° → θ(50)=30°, torus θ(40)=0° → θ(45)=6°) 로 보인다.

### 3.5 층고

선택기에는 층고 입력이 없어 각도는 정의상 같다(확인: 기준 행 하나의 선택을 세 층고에 그대로 썼다).
미지지 mm(자동 균일)는 층고에 따라 크게 변한다 — 0.2 / 0.3 / 0.4 의 중앙값이 2.1 / 16.5 / 56.1 mm.
층이 두꺼울수록 같은 각도의 이웃 층 어긋남이 커지는 검사기 A 의 구조 그대로다. **층고가 판정 결과의 크기를 좌우한다**는 점은
보고서의 모든 mm 수치에 층고를 붙여야 하는 이유다.
