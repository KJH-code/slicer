# 균일각의 정확 탐색 — 성질 A′ 를 알고리즘이 실제로 쓰게 한다

상태: **사전 등록 (2026-11-10, 결과 보기 전).** 결과 절은 아래에 나중에 붙인다.
구현: `conical/exact_angle.py` · 재현: `analyze_exact_angle.py` · 테스트: `tests/test_exact_angle.py`

## 1. 성질 A′ 와 그것이 성립하는 범위

판정식(`conical/analytic.py`, 저장소 유일 기준):

```
g_f(θ) = n_z·cosθ + d·n_r·sinθ = R·sin(θ+δ),   R = hypot(n_z, d·n_r),  δ = atan2(n_z, d·n_r)
면 f 서포트 필요  ⟺  g_f(θ) < κ = −sin(임계각)          (엄격 부등호)
S(θ) = Σ_f a_f·[g_f(θ) < κ] / Σ a_f × 100                (면적 가중 %)
```

g_f 는 θ 의 연속함수이므로 면 f 의 판정은 `g_f(θ) = κ` 인 θ 에서만 바뀐다.
[0, MAX] 안의 근은 `θ = asin(κ/R) − δ + 2πn` 과 `θ = π − asin(κ/R) − δ + 2πn` 중
구간에 드는 것들이다(첫 근 θ*, 그리고 더 키우면 다시 실패하는 둘째 근). 따라서 **S 는
계단함수**이고 계단은 이 근들에서만 바뀐다.

### 실제 목적함수 J (코드에서 읽은 그대로)

| 호출 경로 | J | A′ 성립 |
|---|---|---|
| `selector.select_cone` → `evaluate_J` | `S(0) − S(θ) − k·θ`, θ ∈ 격자, 방향 2 | ✅ 그대로 |
| `varangle.best_angle_for_mask` (`select_uniform`, `select_banded` 의 밴드별) | 같은 꼴, 단 S 를 mask 면적으로 정규화 | ✅ (가중치만 다름) |
| `varangle.select_banded_j` 의 **균일 후보** (`profile_objective`, 상수 프로필) | `S(0) − S(θ) − k·평균|θ| − k_blend·0`, 상수 프로필이면 평균|θ| = |θ|, 블렌드 0 | ✅ (부호 있는 θ, `support_fraction_profile` 의 g 가 위와 같은 식) |
| `select_banded_j` 의 **밴드 프로필** | 위 + `k_blend·blend_penalty` (블렌드 슬랩 면적·반경이 θ 에 연속 의존) + 면별 θ(Z′) | ❌ **범위 밖.** 벌점이 계단이 아니고 경계 이동이 끼어든다 |

따라서 이 문서의 주장은 **균일각 선택(모델 전체 또는 mask 하나에 각도 하나)** 에 한정한다.

### 논법 (k > 0)

이웃한 두 근 사이 열린 구간에서 S 는 상수, J 는 `−k·θ` 로 **강하게 감소**한다. 그러므로
구간 안의 상한은 왼쪽 끝 b 로 다가갈 때다. b 가

* **올라가는 근**(g 가 κ 를 아래→위로 통과, 면이 고쳐짐)이면 엄격 부등호 때문에 b 에서 이미
  고쳐진 상태 → b 에서 상한이 **달성된다**.
* **내려가는 근**(둘째 근, 면이 다시 실패)이면 b 에서는 아직 통과 → `S(b) = S(b⁻)` 이고 b 는
  왼쪽 구간의 오른쪽 끝이라 그 구간의 왼쪽 끝보다 J 가 작다 → 후보가 될 수 없다.

⇒ **최적해는 {0°} ∪ {올라가는 근들} (방향 outward/inward 각각) 중에 있다.** MAX_ANGLE 은
근이 아니면 후보가 될 수 없다(앞 근의 J 가 더 크다). 단 구현은 안전을 위해 내려가는 근과
MAX 도 후보에 넣는다(값이 같거나 작으므로 결과를 바꾸지 않는다). k = 0 이면 동률이 생기므로
타이브레이크(아래)가 결과를 정한다.

### 판정식과 맞춘 세부 (analytic.py 와 똑같이)

* **n_r**: `analytic.radial_normal` 을 그대로 쓴다(면 중심 기준, r ≤ 1e-9 이면 0).
* **R ≤ |κ| (φ 방향 법선 등)**: `|g| ≤ R ≤ |κ|` 이므로 `g < κ` 가 절대 성립 안 함 → 근 없음,
  항상 통과. 근을 asin 으로 풀지 않고 이 조건으로 거른다(R = |κ| 접점도 통과 — 엄격 부등호).
* **n_r = 0 이지만 n_z < κ 인 면**: `g = n_z·cosθ` 는 θ 가 커질수록 커진다 → 근이 있을 수 있다
  (예: n_z = −0.8 이면 θ = acos(κ/n_z) ≈ 27.9°). 일반 근 공식이 이를 그대로 잡는다.
  ⚠ `analytic.critical_angle` 은 `b > 0` 일 때만 도달 가능으로 보아 이 면을 '못 고침' 으로
  분류한다 — `support_fraction` 과 어긋난다. 이 작업은 `support_fraction` 을 기준으로 한다
  (그쪽이 J 가 실제로 쓰는 것). `critical_angle` 은 고치지 않고 결과 절에 그 차이를 잰다.
* **바닥면**: `analytic.support_fraction` 은 바닥면을 **빼지 않는다**(n_z = −1 → g = −cosθ,
  [0, 44°] 에서 늘 서포트). 정확 탐색도 빼지 않는다. 바닥면은 S 에 상수로 더해질 뿐 argmax 를
  안 바꾼다.
* **방향 0°**: outward 0° 와 inward 0° 는 같은 점이다.

### 수치 처리

근에서 정확히 평가하면 반올림 때문에 그 면이 아직 실패로 셀 수 있다. 그래서 후보 각도를
`p = b + min(ε, gap/2)` 로 둔다(ε = 1e-7°, gap = 다음 근까지 거리). p 는 근이 아닌 일반점이라
엄격/비엄격 구분이 사라지고, **반환 각도 p 에서 `analytic.support_fraction` 을 다시 부르면
같은 값이 나와야 한다**(기준 b). 대가는 J 에서 최대 k·ε = 2e-8 (k = 0.2).

타이브레이크: 기존 `select_cone` 과 같게 — outward 먼저, 같은 방향에서는 작은 각도 먼저
(`max` 가 첫 최대를 고르는 동작). J 가 1e-12 안에서 같으면 동률로 본다.

## 2. 판정 기준 (결과 보기 전에 고정)

모든 테스트 모델 = 데모 6(`compare_ceiling.demo_models`) + 17(`analyze_blend_ratio.build_specs(asym=True)`;
⚠ 로브 5 개는 축비대칭) + λ 축 10(허리3 `widen`, λ 1.16~1.30). k = DEFAULT_K = 0.2, 임계각 45°,
MAX 44°.

* **(a) 격자를 못 진다**: 모든 모델에서 `J_exact ≥ J_grid(2°) − 1e-6`.
* **(b) 해석식 재측정 일치**: 정확 탐색이 고른 (각도, 방향) 에서 `analytic.support_fraction` 을
  새로 불러 잰 S 와 정확 탐색이 보고한 S 의 차이 ≤ 1e-9 %.
  보조(b′): 정확 탐색이 만든 계단함수를 2° 격자 23 점 × 2 방향에서 읽은 값이
  `support_fraction` 과 전부 1e-9 % 안에서 일치.
* **(c) 미세 격자 전수와 일치**: 0.001° 격자(44,001 점 × 2 방향) 전수 탐색의 J 최댓값 `J_fine` 에 대해
  `J_fine ≤ J_exact + 1e-6` (어떤 격자점도 정확해를 못 이긴다) **그리고**
  `J_exact − J_fine ≤ k·0.001 + 1e-6` (정확해의 계단이 0.001° 격자로 잡힐 때).
  사전 등록한 예외 하나: 정확해의 계단 폭(그 근에서 다음 근까지)이 0.001° 보다 좁으면
  미세 격자가 그 계단을 못 밟을 수 있으므로 둘째 부등식 위반을 실패로 세지 않고
  **따로 보고**한다. 첫째 부등식 위반은 예외 없이 실패다.

통과 = 모든 모델에서 (a)(b)(b′)(c). 하나라도 실패하면 결과 절에 그대로 적고 원인을 찾는다.

## 3. 같이 보는 것 (판정이 아니라 기록)

* 격자 2° 대비 각도·방향·J 가 달라진 모델 수.
* 후보 수(정확: 근의 개수 + 2, 격자: 45 × 2) 와 실행 시간.
* **λ 축**: 2° 격자에서 λ 1.22 → 1.24 에 24° → 32° 로 튄 것(docs/verification.md 2026-09-28)이
  정확 탐색에서도 남는가. **A′ 의 예측은 '남는다'** — S 가 계단이고 벌점이 선형이면 argmax 는
  형상에 대해 불연속으로 뛰는 것이 구조이지 탐색 해상도의 산물이 아니다. 남지 않으면 그
  예측이 틀린 것으로 적는다.
  비교 대상 격자는 `select_banded_j(n=1)` 의 균일 후보(같은 J)와 `select_cone` 둘 다 잰다.
* `analytic.critical_angle` 이 '못 고침' 으로 둔 면 중 실제로는 근이 있는 면의 넓이.
