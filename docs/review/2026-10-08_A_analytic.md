거기에 `g`, `κ`, `θ*` 식이 적혀 있다. 그러므로 **"식 자체"의 재유도는 완전 독립이 아니다.**

## 발견

### F1. `critical_angle` 의 '못 고침' 게이트가 과엄격하다 — 잠재 결함

`conical/analytic.py` `critical_angle`: `reachable = … & (b > 1e-12)` (b = c·n_r).
세 재유도와 관례 회의론자가 각각 같은 반례를 냈다. g'(0) = c·n_r ≤ 0 이면 g 가 처음엔
내려가지만, `n_z·cosθ` 항의 크기가 cosθ 로 줄어 되돌아온다. [0, 90°) 에서 {g ≥ κ} 는 단일
구간이라 정확한 조건은 **θ* ≤ θ_max ⟺ g(θ_max) ≥ κ** 하나다.

- 반례: n_z = −0.75, c·n_r = −0.05 → 코드 NaN, 실제 θ* = 23.6°, g(24°) = −0.7055 > κ
- n_r = 0 인 면(축 위, 또는 접선 방향으로만 기운 면)도 전부 NaN 인데 n_z = −0.866 이면 35.3° 에서 고쳐진다
- **실제 메시 영향: 0면** — 구(1,280) · funnel(64) · lamp(9,856) 모두 코드 놓침 0, 잘못 고침 0.
  축대칭 모델이라 서포트 필요 면의 c·n_r 부호가 한쪽으로 몰려 있어서다
- 쓰이는 곳: `compare_with_teammate.py` 뿐. 주 파이프라인(`needs_support`/`support_fraction`)은
  g 를 매 각도마다 다시 재므로 **무관**하다. 팀메 대조에서 "도달 불가 면 집합 일치"가 나온 것도
  표본에 그런 면이 없어서다
- 같은 코드 안에서 `needs_support` 와 `critical_angle` 이 **다른 답**을 낼 수 있다는 점이 요지다

### F2. cosθ 희석 — 접선 방향 경사면이 '고쳐진다' (실물 필요)

n_r = 0 이고 |n_z| < sin45°/cos44° = 0.983 이면 (수직 기준 **79°** 오버행까지) c 와 무관하게
θ = 44° 에서 g ≥ κ 가 된다. 레이어가 반경 방향으로 기울고 면은 접선 방향으로 기울어 두 기울기가
직교하기 때문이다. 이면각 계산으로는 맞다. 비드가 사선으로 걸치는 적층에서 45° 규칙이 그대로
성립하는지는 식 밖이다. 관례·기하 회의론자 공통 지적. **실물로만 갈린다.**

### F3. 면 중심점 하나로 대표 — 축을 가로지르는 면, 큰 면

`radial_normal` 은 면 중심점의 r̂ 로 n_r 을 잰다. 면이 축을 가로지르면 반대쪽 절반은 n_r 부호가
뒤집혀 국소 오버행이 **θ 만큼 더 나빠지는데**, 중심점이 한쪽에 있으면 전부 '고쳐짐'으로 센다.
메시를 쪼개면 수치가 바뀐다 (분할 불변성 위반). 세 회의론자 모두 지적.
축대칭 데모 모델에서는 안 드러난다. 제안된 시험: 축 가로지르는 기운 판을 삼각형 1/2/4개로 분할해 % 비교.

### F4. c = +1 의 기하적 의미를 문서에 못박을 것

관례 회의론자: c = +1 은 레이어 법선이 +r̂ 쪽으로 기울어 **바깥·아래를 보는 면을 살린다**
(위로 벌어지는 깔때기 밑면: 서포트 ⟺ β < 45° − θ). "노즐이 바깥으로 기운다"로 읽으면 부호가
반대다. 뷰어와 부호가 어긋났던 기록(볼트 팀 통합)이 같은 자리다. 코드는 일관되나, 한 줄 정의가 필요하다.

### 지표가 못 보는 것 — 세 회의론자 교집합

식에 그 변수가 없어서 정교화로는 안 나오는 것들.

- 아래에 무엇이 있나 (베드·모델 자신·브리지 양 끝). 바닥면은 모든 θ 에서 서포트로 센다 (원기둥 r10·h20 → 16.7% 상수)
- 서포트의 양 (높이·부피). 면적 % 만 센다
- 층고·압출폭. 45° 자체가 h·tanα ≤ w/2 에서 온 경험칙인데 둘 다 없다
- 중력 방향. '아래'가 −ẑ 가 아니라 −b̂ 다. 레이어가 기울수록 걸침과 처짐이 갈린다
- 면 내부 변화 (F3). 메시 해상도가 숨은 입력
- 축 선택. 바운딩박스 중심 고정
- θ 를 올리면 **새로 생기는** 오버행 (c·n_r < κ 인 면). 면별 θ* 는 못 보고, 전역 % 재계산만 본다
