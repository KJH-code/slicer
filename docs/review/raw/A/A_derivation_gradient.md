## 가정
- 면 법선 n 은 단위벡터이고, n 과 r̂ 은 삼각형 면의 중심점(centroid)에서 한 번 평가한다. 중심점의 r > 0 이어야 r̂ 이 정의되며, 축을 가로지르거나 방위각으로 넓게 펼쳐진 면에서는 근사가 나빠진다.
- 변환 축 = z 축이고 모델이 축에 센터링되어 있다(변환의 축대칭). 모델 자체의 축대칭은 가정하지 않는다.
- θ 는 면 근방에서 상수다(균일 원뿔 또는 밴드 내부). θ 가 Z' 에 따라 변하는 가변각 프로필에서는 ∇F 에 추가 항이 생기므로 이 g 는 국소 근사다.
- 0 ≤ θ < 90°, 0 ≤ θ_max < 90°. tanθ 유한, cosθ > 0.
- '위 방향' = F 가 증가하는 방향(= 나중에 출력되는 레이어 쪽) = 레이어 곡면의 법선 ∇F/|∇F|. 역변환된 툴패스가 정확히 F = const 곡면 위에 놓인다고 본다.
- 서포트 판정은 면-국소 기준이다: 면 법선과 국소 레이어 법선 사이의 각이 평면 관례와 같은 임계각을 넘는지만 본다. 아래에 받쳐 주는 형상이 있는지(가림), 브리지, 레이어 두께(ΔZ'·cosθ)의 변화, 노즐이 수직인 채로 기운 면에 놓는 데서 오는 효과는 포함하지 않는다.
- κ 는 평면 슬라이싱과 동일한 임계각에서 가져온다: κ = −sin(임계각). 원뿔각에 따라 임계각을 바꾸지 않는다.
- R = √(n_z²+n_r²) = 0 인 면(법선이 순수 방위각 방향)은 n_z = 0 ≥ κ 이므로 정의상 서포트 불필요(θ* = 0)로 둔다.
- θ* 는 면 하나의 양이다. 영역/전역 제약(가역성 c·r_max·tanθ < 1, 층간격 상한, 다른 면의 θ_break)은 별도로 봐야 한다.
- numpy 식에서 np.where 는 양쪽 가지를 모두 계산하므로 마스크되는 항목에서 RuntimeWarning(0 나눗셈 등)이 날 수 있으나 결과값은 영향받지 않는다. np.clip 은 그 경고를 줄이는 용도이며 nz < kappa 인 항목의 값은 바꾸지 않는다.

======================================================================
질문 1. 국소 '위 방향'과 g
======================================================================

1-1. 레이어 곡면과 그래디언트
 F(x,y,z) = z + c·r·tanθ,  r = √(x²+y²),  r̂ = (x,y,0)/r.
 한 레이어 = 등위면 F = Z'_k (상수).
 ∂F/∂x = c·tanθ·x/r,  ∂F/∂y = c·tanθ·y/r,  ∂F/∂z = 1
 ⇒ ∇F = c·tanθ·r̂ + ẑ.
 |∇F|² = tan²θ + 1 = sec²θ ⇒ |∇F| = 1/cosθ  (0 ≤ θ < 90° 이므로 cosθ > 0).
 정규화:  u := ∇F/|∇F| = cosθ·ẑ + c·sinθ·r̂.     … (1)

1-2. 왜 u 가 '국소 위 방향'인가
 (a) 레이어 곡면 F = Z'_k 의 접평면은 ∇F 에 수직이다. 노즐은 이 곡면 위에 비드를 놓고, 다음 레이어 F = Z'_{k+1} 은 이 곡면에서 법선 방향으로 ΔZ'/|∇F| = ΔZ'·cosθ 만큼 떨어져 쌓인다(등위면 사이의 수직거리). 즉 '재료가 쌓이는 방향' = 레이어 곡면의 법선 = ∇F 방향이다. 실제 층두께가 ΔZ'·cosθ 인 것도 이 사실의 따름정리다.
 (b) 부호: F 가 커지는 쪽이 나중에 출력되는 레이어다. 평면 슬라이싱에서 ẑ 가 '나중 레이어 쪽'인 것과 똑같이, +∇F 가 '위'다.
 (c) θ = 0 이면 F = z, ∇F = ẑ, u = ẑ. 평면 관례를 정확히 복원한다.
 (d) 오버행은 '면' 하나의 성질이 아니라 '면과 그 면이 올라앉는 레이어' 사이의 관계다. 평면 슬라이싱에서 n_z 를 보는 이유: 층두께 h 당 윤곽이 레이어 안에서 삐져나오는 양은 h·√(1−n_z²)/|n_z| 이고, 45° 관례 n_z < −sin45° 는 '아래를 보면서 그 삐짐이 h 를 넘는다'와 같다. 레이어가 기울었으면 같은 양을 레이어 법선 u 로 재야 한다: n_z → n·u, √(1−n_z²) → √(1−(n·u)²). 그래서 n·u 가 '그 자리의 국소 레이어에 대해 얼마나 아래를 보는가'다.
 (e) |∇F| = secθ 는 위치에 무관하므로 u 는 r, z 에 무관하고 방위각(r̂)에만 의존한다. 면 중심점 하나에서 r̂ 을 잡아 평가해도 면 전체에서 u 가 (r̂ 의 방위 변화를 빼면) 변하지 않는다.
 (f) 변환공간 (x,y,Z') 에서 각도를 재면 안 된다. (x,y,z) → (x,y,z+c·r·tanθ) 는 전단(shear)이라 등각이 아니다. 변환공간의 45° 는 실공간의 45° 가 아니다. u 는 실공간에서 정의된 벡터라 이 문제가 없다.

1-3. g 의 식
 g := n·u = n_z·cosθ + c·(n·r̂)·sinθ = n_z·cosθ + c·n_r·sinθ.     … (2)
 θ = 0 ⇒ g = n_z ✓.

1-4. κ
 '국소 레이어에 대해 아래를 보는 정도' = −g = −n·u = sin(국소 오버행각). 평면 관례와 같은 임계각을 쓰면
 서포트 필요 ⟺ g < κ,  κ = −sin(임계각) = −sin(threshold_deg·π/180).
 임계각 45° 이면 κ = −1/√2 ≈ −0.7071. θ = 0 에서 n_z < −sin45° 와 정확히 같다 ✓.

1-5. 보조 표현 (질문 2, 3 에 쓴다)
 n = n_r·r̂ + n_t·t̂ + n_z·ẑ (t̂ 은 방위각 방향), n_r² + n_t² + n_z² = 1.
 R := √(n_z² + n_r²), 0 ≤ R ≤ 1 (n_t² = 1 − R²).
 (i) g(θ) = R·sin(θ + ψ),  ψ := atan2(n_z, c·n_r).
   증명: R·sin(θ+ψ) = R·sinθ·cosψ + R·cosθ·sinψ = sinθ·(c·n_r) + cosθ·n_z. (cosψ = c·n_r/R, sinψ = n_z/R)
 (ii) g(θ) = R·cos(θ − φ),  φ := atan2(c·n_r, n_z). (같은 식의 다른 위상 표기)

======================================================================
질문 2. 최소각 θ* 와 '못 고친다'의 정확한 조건
======================================================================

2-1. 정의
 θ* := min{ θ ∈ [0, θ_max] : g(θ) ≥ κ }. 그런 θ 가 없으면 '못 고친다'.
 n_z ≥ κ 이면 θ = 0 이 이미 조건을 만족 ⇒ θ* = 0.
 이하 n_z < κ (< 0) 인 면만 다룬다.

2-2. 닫힌 식
 g(θ) = κ ⟺ sin(θ + ψ) = κ/R.
 n_z < κ < 0 ⇒ |n_z| > |κ| ⇒ R ≥ |n_z| > |κ| ⇒ κ/R ∈ (−1, 0). asin 이 정의된다.
 θ + ψ = asin(κ/R) + 2πk  또는  π − asin(κ/R) + 2πk.
 g'(θ) = R·cos(θ+ψ). 첫째 가지: cos(θ+ψ) = cos(asin(κ/R)) = √(1 − κ²/R²) > 0 ⇒ g 가 κ 를 아래→위로 가로지르는 점. 둘째 가지는 위→아래 교차. '서포트가 필요 없게 되는' 전환은 아래→위 교차이므로 첫째 가지(k = 0; 다른 k 는 θ 를 [0, π) 밖으로 보낸다).
   θ* = asin(κ/R) − atan2(n_z, c·n_r),  R = √(n_z² + n_r²).     … (3)
 범위 확인 (asin(κ/R) ∈ (−π/2, 0), n_z < 0 이므로 ψ ∈ (−π, 0)):
 - c·n_r > 0: ψ ∈ (−π/2, 0) ⇒ θ* ∈ (−π/2, π/2). θ* ≥ 0 ⟺ asin(κ/R) ≥ ψ ⟺ κ/R ≥ sinψ = n_z/R ⟺ κ ≥ n_z. 가정 n_z < κ 에서 θ* > 0 이고 θ* < π/2 는 자동.
 - c·n_r = 0: ψ = −π/2 ⇒ θ* = π/2 + asin(κ/|n_z|) = acos(|κ|/|n_z|) ∈ (0, π/2). (g = n_z·cosθ 를 직접 풀어도 같다.)
 - c·n_r < 0: ψ ∈ (−π, −π/2) ⇒ θ* ∈ (0, π). θ* < π/2 ⟺ c·n_r > κ (2-3 에서).
 검산 예: n_z = −0.9, c·n_r = 0.3 → R = 0.9487, asin(−0.7454) = −0.8411, atan2(−0.9, 0.3) = −1.2490 → θ* = 0.4079 rad = 23.4°; g(23.4°) = −0.9·0.9180 + 0.3·0.3966 = −0.7072 ≈ κ ✓.

2-3. 실현가능 집합이 '단일 구간'임 — 정확한 필요충분조건의 근거
 g = R·cos(θ − φ), φ = atan2(c·n_r, n_z). n_z < 0 ⇒ cosφ = n_z/R < 0 ⇒ |φ| > π/2.
 (A) c·n_r > 0: φ ∈ (π/2, π). θ ∈ [0, π/2) 에서 θ − φ ∈ (−π, 0) 이고 cos 은 이 구간에서 단조증가 ⇒ g 단조증가. 가능집합 = [θ*, π/2).
 (B) c·n_r < 0: φ ∈ (−π, −π/2). θ − φ ∈ (−φ, π/2 − φ) ⊂ (π/2, 3π/2). cos 은 (π/2, π] 에서 감소, [π, 3π/2) 에서 증가 ⇒ g 는 θ_dip = π + φ = atan(|n_r|/|n_z|) ∈ (0, π/2) 까지 감소해 최소값 −R 을 찍고 그 뒤 단조증가. g(0) = n_z < κ 이므로 감소 구간은 전부 κ 미만. 따라서 가능집합 = [θ*, π/2) (θ* < π/2 일 때) 또는 ∅. 증가 구간의 끝값 lim_{θ→π/2} g = c·n_r 이므로 ∅ 가 아님 ⟺ c·n_r > κ.
 (C) c·n_r = 0: g = n_z·cosθ, n_z < 0 ⇒ 단조증가. 가능집합 = [θ*, π/2).
 ⇒ 세 경우 모두 [0, π/2) 안에서 {g ≥ κ} 는 단일 구간 [θ*, π/2) 다.
 따라서 상한 θ_max (< π/2) 가 주어지면
   고칠 수 있다 ⟺ θ* ≤ θ_max ⟺ g(θ_max) ≥ κ ⟺ n_z·cosθ_max + c·n_r·sinθ_max ≥ κ.     … (4)
 왼쪽 두 표현은 구간성 때문에 동치다. 이것이 '필요충분' 조건이다(충분조건이 아니라).

2-4. '어떤 θ 로도 못 고친다' (θ_max → 90°)
 sup_{θ∈[0,π/2)} g = max(g(0), g(π/2⁻)) = max(n_z, c·n_r). n_z < κ 가정하에
   못 고친다 ⟺ c·n_r ≤ κ = −sin(임계각).
 즉 면 법선의 반경 성분이 원뿔 부호 c 와 반대 방향으로 sin(임계각) 이상 기울어 있을 때. 반대로 c·n_r > κ 이면 θ → 90° 근처에서는 언젠가 고쳐지지만, 실제로는 (4) 의 θ_max 가 지배한다.

2-5. 흔한 '간단한 조건'과 갈리는 곳
 (i) "c·n_r ≤ 0 이면 못 고친다" — 너무 엄격해서 틀렸다. 반례: n_z = −0.8, c·n_r = −0.3 → θ* = 54.7° 이므로 θ_max = 60° 면 고쳐진다. n_r = 0 인 면도 θ* = acos(|κ|/|n_z|) 에서 고쳐진다(n_z = −0.866 → 35.3°). 레이어를 반경 방향으로 기울이면 기울임 방향과 무관한(방위각 방향) 아래보기 면도 레이어에 대해서는 덜 아래를 보게 되기 때문이다.
 (ii) "c·n_r > κ 이면 고칠 수 있다" — θ_max → 90° 에서만 맞다. 같은 면이 θ_max = 45° 에서는 못 고친다(θ* = 54.7° > 45°, g(45°) = −0.778 < κ).
 (iii) "g 가 단조라고 치고 g(θ_max) ≥ κ 로 판정" — 결과는 정확하다. g 가 단조는 아니지만(질문 3) 골이 교차점보다 앞에 있고 g(0) < κ 라 구간성이 유지되기 때문.
 (iv) 면 단위 vs 영역 단위: 영역(밴드)에 각도 하나를 주면 모든 면 i 에 대해 θ ∈ ∩_i [θ*_i, θ_break_i] 여야 한다(θ_break 는 질문 3). 면마다 고칠 수 있어도 교집합이 비면 영역은 못 고친다. (3) 만으로는 이것이 안 보인다.

2-6. numpy 한 줄 식
 np.where(nz >= kappa, 0.0, np.where(nz*np.cos(theta_max) + c*nr*np.sin(theta_max) >= kappa, np.arcsin(np.clip(kappa/np.hypot(nz, nr), -1.0, 1.0)) - np.arctan2(nz, c*nr), np.nan))
 - 고칠 수 있음 판정에 g(θ_max) ≥ κ 를 쓴 것은 (4) 의 동치 때문. θ* ≤ theta_max 로 써도 값은 같다.
 - np.clip 은 nz ≥ κ 라서 어차피 0.0 으로 마스크되는 항목에서 |κ/R| > 1 (또는 R = 0) 때문에 arcsin 이 NaN 경고를 내는 것을 막는 용도다. nz < κ 인 항목에서는 κ/R ∈ (−1, 0) 이라 clip 이 값을 바꾸지 않는다.

======================================================================
질문 3. g 의 단조성
======================================================================

 g'(θ) = −n_z·sinθ + c·n_r·cosθ,  g'(0) = c·n_r.
 ⇒ c·n_r < 0 이면 θ = 0 에서 g 는 **감소**한다. 단조증가가 아니다.
 임계점: tanθ_c = c·n_r / n_z.
 - n_z < 0, c·n_r < 0: θ_dip = atan(|n_r|/|n_z|) ∈ (0, π/2) 에서 최소 −R, 그 뒤 증가 (U 자).
 - n_z < 0, c·n_r > 0: [0, π/2) 전 구간 단조증가 (최대는 θ = φ > π/2 에 있다).
 - n_z > 0, c·n_r < 0: φ ∈ (−π/2, 0) ⇒ θ − φ ∈ (0, π) ⇒ [0, π/2) 전 구간 단조감소, g(π/2⁻) = c·n_r.
 - n_z > 0, c·n_r > 0: 증가 후 감소하지만 g > 0 > κ 를 유지(절대 서포트 불필요).

 질문 2 에 미치는 영향
 (1) 서포트가 필요한 면(n_z < κ): 비단조성이 가능집합의 구간성을 깨지 않으므로 'θ* ≤ θ_max' 판정은 그대로 정확하다. 따라오는 것 둘: 닫힌 식에서 상승 교차 가지(asin 가지)를 골라야 한다는 것, 그리고 0 < θ < θ* 의 어중간한 각도는 θ = 0 보다 오버행을 **더 심하게** 만든다는 것(θ_dip 에서 −g = R > |n_z|). 이런 면에는 "조금만 기울이기"가 해롭다 — θ* 는 '넘어야 하는 문턱'이지 '많을수록 좋은' 양이 아니다.
 (2) 서포트가 필요 없던 면(n_z ≥ κ)이면서 c·n_r < κ 인 면은 θ 를 올리면 **새로 오버행이 된다**. 깨지는 각(하강 교차): θ_break = atan2(c·n_r, n_z) + acos(κ/R). 이 면들의 θ* 는 0 이지만, 영역의 θ 가 θ_break 를 넘으면 망가진다. 그래서 면 하나의 '못 고친다'는 θ* > θ_max 지만, 영역 단위로는 ∩_i [θ*_i, θ_break_i] = ∅ 가 정확한 조건이다. 대표적으로 c 와 반대쪽을 보는 수직 벽(n_z ≈ 0, c·n_r ≈ −1)은 원뿔각 θ 에 대해 정확히 θ 만큼의 국소 오버행이 되어 θ > 임계각이면 서포트가 필요해진다.

 숫자 예 (비단조, 고쳐지는 경우): n_z = −0.8, c·n_r = −0.3 (n_t = √0.27 ≈ 0.52), κ = −0.7071, R = √0.73 = 0.8544.
  θ = 0°:      g = −0.800  (오버행 53.1°, 서포트 필요)
  θ = 20.56°:  g = −0.854  (= −R, 골. 오버행 58.7°, θ = 0 보다 나쁨)
  θ = 45°:     g = (−0.8 − 0.3)·0.7071 = −0.778 < κ (여전히 필요)
  θ* = asin(−0.8276) − atan2(−0.8, −0.3) = −0.9748 − (−1.9296) = 0.9548 rad = 54.7° → g = −0.707 = κ
  θ = 60°:     g = −0.400 − 0.260 = −0.660 ≥ κ (고쳐짐)
  ⇒ θ_max = 45°: 못 고침(θ* > θ_max, g(45°) < κ). θ_max = 60°: 고침.
 숫자 예 (깨지는 경우): n_z = 0.10, c·n_r = −0.99 (거의 수직, 원뿔 방향과 반대쪽을 보는 벽). R = 0.9950, φ = atan2(−0.99, 0.10) = −1.4701, acos(κ/R) = acos(−0.7106) = 2.3612 ⇒ θ_break = 0.8911 rad = 51.1°.
  θ = 45°: g = 0.0707 − 0.700 = −0.629 (괜찮음);  θ = 52°: g = 0.0616 − 0.780 = −0.719 < κ (서포트 필요해짐).

 최종 확인: 유도 결과 (2),(3) 은 CLAUDE.md 에 적혀 있던 식과 d ↔ c 치환으로 일치한다.

## 못 고치는 조건
[정확한 조건(필요충분)] n_z < κ 인 면(θ=0 에서 서포트 필요)에 대해, θ ∈ [0, θ_max] 로 못 고친다 ⟺ θ* > θ_max ⟺ g(θ_max) = n_z·cosθ_max + c·n_r·sinθ_max < κ.  (θ* = asin(κ/R) − atan2(n_z, c·n_r), R = √(n_z²+n_r²).) 두 표현이 동치인 이유는 [0, 90°) 안에서 {θ : g(θ) ≥ κ} 가 항상 단일 구간 [θ*, 90°) 이기 때문이다 — c·n_r>0 이면 g 단조증가, c·n_r<0 이면 θ_dip 까지 내려갔다 올라오지만 g(0)<κ 라 내려가는 구간은 어차피 κ 미만, c·n_r=0 이면 단조증가. 상한 없이 θ→90° 까지 허용하면: 못 고친다 ⟺ sup g = max(n_z, c·n_r) < κ ⟺ c·n_r ≤ κ = −sin(임계각) (법선의 반경 성분이 원뿔 부호와 반대쪽으로 sin(임계각) 이상 기운 면).
[흔히 쓸 법한 간단한 조건과의 차이] (i) "c·n_r ≤ 0 이면 못 고친다"는 너무 엄격해서 틀렸다. n_z=−0.8, c·n_r=−0.3 은 θ*=54.7° 라 θ_max=60° 면 고쳐지고, n_r=0 인 면도 θ*=acos(|κ|/|n_z|) (n_z=−0.866 → 35.3°)에서 고쳐진다. (ii) "c·n_r > κ 이면 고칠 수 있다"는 θ_max→90° 에서만 맞다. 같은 면이 θ_max=45° 에서는 못 고친다(g(45°)=−0.778<κ). 즉 (i)은 고칠 수 있는 면을 못 고친다고, (ii)는 못 고치는 면을 고칠 수 있다고 잘못 판정하며, 갈리는 지점은 c·n_r ∈ (κ, 0] 이면서 θ* 가 θ_max 근처인 면들이다. (iii) "g 가 단조라 치고 g(θ_max) ≥ κ" 는 결과적으로 정확하다(구간성 때문). (iv) 면 단위 θ* 는 영역 단위 판정과 다르다: 영역에 각도 하나를 주면 ∩_i [θ*_i, θ_break_i] (θ_break = atan2(c·n_r, n_z) + acos(κ/R), 원래 괜찮던 면이 깨지는 각)가 비어 있지 않아야 하므로, 면마다 고칠 수 있어도 영역은 못 고칠 수 있다.

## 단조성
아니다. g'(θ) = −n_z·sinθ + c·n_r·cosθ 이고 g'(0) = c·n_r 이므로, c·n_r < 0 인 면은 θ = 0 에서 g 가 감소한다. 경우별로: (n_z<0, c·n_r<0) U 자 — θ_dip = atan(|n_r|/|n_z|) 에서 최소 −R 후 증가; (n_z<0, c·n_r>0) [0,90°) 전 구간 단조증가; (n_z>0, c·n_r<0) 전 구간 단조감소(올리면 새로 오버행이 될 수 있음, θ_break = atan2(c·n_r, n_z) + acos(κ/R)); (n_z>0, c·n_r>0) g>0>κ 유지.
질문 2 에의 영향: (1) 서포트가 필요한 면에서는 골이 교차점 앞에 있고 g(0)<κ 라 가능집합이 여전히 단일 구간 [θ*, 90°) 이므로 'θ* ≤ θ_max' 판정은 정확하다. 다만 닫힌 식은 상승 교차 가지(asin 가지)를 골라야 하고, 0<θ<θ* 의 어중간한 각도는 θ=0 보다 오버행을 더 키운다(−g 가 R 까지 커짐). (2) 원래 괜찮던 면(n_z ≥ κ, c·n_r < κ)은 θ > θ_break 에서 깨진다. 면 하나로는 θ* = 0 이지만 영역 단위 판정은 ∩_i [θ*_i, θ_break_i] = ∅ 여부가 정확한 '못 고친다' 조건이다.
숫자 예: n_z = −0.8, c·n_r = −0.3, κ = −0.7071, R = 0.8544. g(0°) = −0.800(오버행 53.1°), g(20.56°) = −0.854(골, 58.7°로 더 나빠짐), g(45°) = −0.778 < κ, θ* = asin(−0.8276) − atan2(−0.8,−0.3) = 0.9548 rad = 54.7° 에서 g = κ, g(60°) = −0.660 ≥ κ. θ_max = 45° 면 못 고치고 θ_max = 60° 면 고친다. 깨지는 예: n_z = 0.10, c·n_r = −0.99 → θ_break = 51.1°; g(45°) = −0.629 괜찮다가 g(52°) = −0.719 < κ 로 서포트가 필요해진다.
