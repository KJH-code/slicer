## 가정
- 면은 충분히 작아 단위 법선 n, r̂, n_r = n·r̂ 을 모두 면 중심점(centroid)에서 한 번 평가한다.
- 레이어 곡면 z = Z₀ − c·r·tanθ 를 면 중심점 근방에서 접평면으로 근사한다(국소 평면 레이어).
- 축대칭: 레이어 곡면이 z 축에 대해 회전대칭이므로 방위각 φ 는 n_r = n·r̂(φ_중심) 하나로만 들어가 소거된다.
- 면 중심점은 축 위에 있지 않다(r > 0). r = 0 에서는 r̂ 이 정의되지 않고 원뿔 꼭짓점이라 접평면이 없다.
- θ 는 면 근방에서 상수(균일 원뿔 또는 밴드 내부). 가변각 프로필의 dθ/dZ' 항은 무시한다.
- 0 ≤ θ < 90° 라 tanθ 유한; 가역성·층간격 제약(c·r·tanθ 관련)은 이 문제 범위 밖으로 둔다.
- '국소 위' = 레이어 접평면의 단위 법선 u = ∇Z'/|∇Z'| = cosθ ê_z + c sinθ r̂. 다음 레이어가 이 방향으로 ΔZ'·cosθ 만큼 균일하게 쌓이므로 적층 방향으로 삼는다.
- 서포트 판정은 평면 FDM 관례와 같은 기하학적 적층 규칙(면 법선과 적층 방향 사이 각)만 쓴다. 노즐/베드를 θ 만큼 기울이는 기계에서는 적층점의 u 가 기계 연직과 일치하므로 중력 관계도 평면과 같다고 본다.
- 면 법선 방식이므로 '아래에 받쳐 주는 것이 있는지', 브리징, 층 두께 효과, 서포트 넓이는 고려하지 않는다.
- n 은 메시의 단위 외향 법선. κ = −sin(임계각), 임계각 ∈ (0°, 90°) 이므로 κ ∈ (−1, 0).
- c = +1 이면 u 가 바깥(+r̂)으로, c = −1 이면 안쪽으로 기운다. 레이어는 c = +1 일 때 z = Z₀ − r·tanθ (우산꼴), c = −1 일 때 z = Z₀ + r·tanθ (깔때기꼴).
- θ_max 가 주어지면 θ* ≤ θ_max 인 면만 '고칠 수 있다'로 본다. 구현식의 R 하한 1e-12 와 arcsin 인자 클립은 R = 0 가지(어차피 θ* = 0 분기)의 경고 방지용이며 수학적 값을 바꾸지 않는다.

## 유도
## 0. 기호와 설정

- 실공간 점 (x, y, z). r = √(x²+y²), 방위각 φ. 단위벡터 r̂ = (cosφ, sinφ, 0), φ̂ = (−sinφ, cosφ, 0), ê_z = (0,0,1). (r̂, φ̂, ê_z) 는 오른손계이므로
  r̂×φ̂ = ê_z, φ̂×ê_z = r̂, ê_z×r̂ = φ̂ (따라서 ê_z×φ̂ = −r̂).
- 면의 단위 외향 법선 n 을 면 중심점의 (r̂, φ̂, ê_z) 로 분해: n = n_r r̂ + n_φ φ̂ + n_z ê_z, n_r²+n_φ²+n_z² = 1. 여기서 n_r = n·r̂.
- t ≡ tanθ (0 ≤ θ < 90° 이므로 t 유한), c ∈ {+1, −1}.
- 변환 Z' = z + c·r·t. 실공간에서 한 레이어 = 레벨셋 {z + c r t = Z₀}.

## 1. 질문 1 — g 의 유도

### 1-1. 레이어 곡면의 매개변수화
Z₀ 레이어: z = Z₀ − c r t. (r, φ) 로 매개변수화하면
  P(r, φ) = (r cosφ, r sinφ, Z₀ − c r t).
축대칭: 식에 φ 가 r̂(φ) 를 통해서만 들어간다.

### 1-2. 접벡터
  ∂P/∂r = (cosφ, sinφ, −c t) = r̂ − c t ê_z
  ∂P/∂φ = (−r sinφ, r cosφ, 0) = r φ̂

### 1-3. 접평면의 법선
  N = ∂P/∂r × ∂P/∂φ = (r̂ − c t ê_z) × (r φ̂)
    = r (r̂×φ̂) − c t r (ê_z×φ̂)
    = r ê_z − c t r (−r̂)
    = r (ê_z + c t r̂).
성분으로 검산: (cosφ, sinφ, −ct) × (−r sinφ, r cosφ, 0)
  = ( sinφ·0 − (−ct)(r cosφ),  (−ct)(−r sinφ) − cosφ·0,  cosφ·r cosφ − sinφ·(−r sinφ) )
  = ( c t r cosφ,  c t r sinφ,  r ) = r (c t r̂ + ê_z). ✓

### 1-4. 단위 법선 (= 국소 '위')
|N| = r √(1+t²) = r / cosθ. 따라서
  u ≡ N/|N| = cosθ ê_z + c sinθ r̂.
z 성분 cosθ > 0 이므로 위를 향한다. θ = 0 이면 u = ê_z.

### 1-5. 왜 u 가 '국소 위 방향' 인가
(a) 스칼라장 Z'(x,y,z) = z + c r t 의 기울기 ∇Z' = ê_z + c t r̂ 는 u 와 평행하다. 다음 레이어(Z₀+ΔZ')는 현재 레이어에서 ∇Z' 방향, 즉 u 방향으로 떨어져 있고, 그 실공간 거리(층 두께)는 ΔZ'/|∇Z'| = ΔZ'·cosθ 로 위치와 무관하게 균일하다. 즉 레이어는 u 방향으로 평행하게 쌓인다. 적층 방향 = 레이어 접평면의 법선.
(b) 면 중심점 근방에서 레이어는 u 를 법선으로 하는 평면으로 근사되고, 그 위에 다음 층이 u 방향으로 올라온다. 이는 평면 슬라이싱에서 ê_z 가 하던 역할을 u 가 정확히 그대로 하는 상황이다. 평면 관례 "n_z < −sin45°" 는 사실 "n·(위 방향) < −sin45°" 이므로, 위 방향만 ê_z → u 로 바꾸면 된다.
(c) 변환공간 (x, y, Z') 에서 각도를 재면 안 된다. 변환은 등각(conformal)이 아니라서 변환공간의 각도는 실제 물리 각도가 아니고, θ = 0 에서만 일치한다. 층간 겹침/접착은 실공간에서 일어난다.
(d) 노즐 또는 베드를 θ 만큼 기울이는 원뿔 프린터에서는 적층 지점에서 u 가 기계 프레임의 연직(노즐 축)과 일치하므로, 중력과 레이어의 관계도 평면 출력과 동일하다. 즉 u 는 '그 자리의 국소 위' 가 문자 그대로 맞다.

### 1-6. g
  g ≡ n·u = n_z cosθ + c (n·r̂) sinθ = n_z cosθ + c n_r sinθ.
축대칭 덕에 φ 는 n_r = n·r̂(φ_면중심) 하나로만 들어가 소거된다. θ = 0 에서 g = n_z. ✓
기하적 의미: g = cos(n 과 u 사이 각). 국소 오버행각 ψ_loc 를 "면이 국소 수직(u 에 평행한 벽)에서 기울어진 각" 으로 정의하면 g = −sin ψ_loc.

### 1-7. κ 와 서포트 조건
평면 관례: n_z < −sin(임계각). 같은 꼴을 유지하려면
  κ = −sin(임계각),   서포트 필요 ⟺ g < κ.
임계각 45° 면 κ = −1/√2 ≈ −0.70711. 임계각 ∈ (0°, 90°) 이므로 κ ∈ (−1, 0).

### 1-8. 검산 (n_φ = 0 인 특수 경우)
n_z = −sinψ₀, c n_r = cosψ₀ (평면 오버행각 ψ₀, 기울임 방향과 같은 쪽) 이면
  g = −sinψ₀ cosθ + cosψ₀ sinθ = −sin(ψ₀ − θ).
즉 기울인 만큼 오버행각이 정확히 θ 줄어든다. 직관과 일치.

## 2. 질문 2 — θ* 와 '못 고친다' 조건

### 2-1. 진폭–위상 꼴
A ≡ n_z, B ≡ c n_r, R ≡ √(A²+B²) = √(n_z²+n_r²) = √(1−n_φ²) ∈ [0, 1], δ ≡ atan2(A, B) = atan2(n_z, c n_r). 그러면
  g(θ) = R sin(θ + δ)
(검산: R sin(θ+δ) = R sinθ cosδ + R cosθ sinδ = B sinθ + A cosθ ✓).

### 2-2. 이미 자기지지인 면
n_z ≥ κ 이면 θ = 0 에서 g = n_z ≥ κ → θ* = 0. (R = 0, 즉 n = ±φ̂ 인 면은 n_z = 0 ≥ κ 라 여기에 속한다. 분모 R = 0 문제는 이 가지에서 걸러진다.)

### 2-3. n_z < κ 인 면
n_z < κ < 0 이므로 R ≥ |n_z| > |κ| → κ/R ∈ (−1, 0). σ ≡ asin(κ/R) ∈ (−π/2, 0) 로 두면
  sin ψ ≥ κ/R ⟺ ψ ∈ [σ, π − σ] (mod 2π)   … '좋은 구간', 길이 π − 2σ > π.
n_z < 0 이므로 δ ∈ (−π, 0). 또 sin δ = n_z/R < κ/R 이므로 δ 는 나쁜 구간 (−π − σ, σ) 안에 있다 (sin(−π−σ) = sinσ 확인).
θ 를 0 에서 올리면 ψ = θ + δ 가 δ 에서 단조 증가하며 처음으로 좋은 구간에 들어가는 지점은 ψ = σ. 따라서
  θ* = σ − δ = asin(κ/R) − atan2(n_z, c n_r),   R = √(n_z²+n_r²).
- 양수성: δ < σ 이므로 θ* > 0.
- 범위: δ > −π − σ 이므로 θ* < π + 2σ < π.

### 2-4. 한 번 넘으면 다시 안 떨어진다 ([0, π/2) 안에서)
좋은 구간의 오른쪽 끝 ψ = π − σ 는 θ = π − σ − δ 인데 σ < 0, δ < 0 이므로 이 값은 π 보다 크다. 즉 [0, π/2) 안에서는 {θ : g(θ) ≥ κ} = [θ*, π/2) (θ* < π/2 일 때) 또는 공집합. 집합이 구간이므로 "최소 θ" 가 곧 "유일한 교차점" 이다.

### 2-5. 못 고친다 — 정확한 조건 (필요충분)
(i) 각도 상한 θ_max (< π/2) 가 있을 때:
  못 고친다 ⟺ θ* > θ_max ⟺ n_z < κ 이고 g(θ_max) = n_z cosθ_max + c n_r sinθ_max < κ.
  증명: (⇐) g(θ_max) < κ 면 θ_max 는 좋은 집합 [θ*, π/2) 밖 → θ_max < θ*. (⇒) θ* > θ_max 면 θ_max ∈ [0, θ*) 는 좋은 집합 밖 → g(θ_max) < κ. 2-4 의 '구간' 성질이 핵심.
(ii) θ_max 없이 0 ≤ θ < 90° 전부 허용할 때:
  못 고친다 ⟺ θ* ≥ π/2 ⟺ n_z < κ 이고 c·n_r ≤ κ.
  증명: θ → π/2⁻ 에서 g → c n_r. 좋은 집합이 [θ*, π/2) 꼴의 구간이고 g 가 θ_min 이후 단조증가(3절)이므로, [0, π/2) 에서 비어 있을 필요충분조건은 sup g = c n_r ≤ κ.
  경계 검산: n_z = −0.8, κ = −0.6, c n_r = −0.6 → R = 1, σ = asin(−0.6) = −0.6435, δ = atan2(−0.8, −0.6) = −(π − atan(4/3)) = −2.2143, θ* = −0.6435 + 2.2143 = 1.5708 = π/2 ✓.

### 2-6. 흔히 쓸 법한 간단한 조건과 어디서 갈리나
(가) "기울임 방향과 오버행 방향이 맞아야(c·n_r > 0) 고칠 수 있다; c·n_r ≤ 0 이면 못 고친다" — 틀렸다. 정확 조건은 c·n_r ≤ κ 이지 ≤ 0 이 아니다. κ < c·n_r ≤ 0 인 면은 g 가 처음엔 내려가지만 결국 올라와 θ* < π/2 에서 고쳐진다.
  예: n_z = −0.9, n_r = −0.1, c = +1, κ = −sin45°. c n_r = −0.1 ≤ 0 이라 (가) 는 '못 고침' 이라 하지만 θ* = 45.0° (3절에 상세 계산). θ_max = 60° 면 실제로 고쳐진다.
(나) "c·n_r ≤ κ 면 못 고친다" — θ_max 가 없으면 정확(2-5 ii) 하지만, θ_max < 90° 가 주어지면 충분조건일 뿐 필요조건이 아니다. c·n_r > κ 여도 θ* > θ_max 면 못 고친다.
  예: 같은 면, θ_max = 30°: g(30°) = −0.9·0.8660 − 0.1·0.5 = −0.8294 < κ → 못 고침. 그런데 c n_r = −0.1 > κ 라 (나) 는 '고칠 수 있다' 쪽으로 빠진다.
(다) "g 가 θ 에 단조라고 보고 g'(0) = c·n_r 의 부호로 판정" — (가) 와 같은 오류. 3절 참조.
정확한 판정은 반드시 θ* ≤ θ_max (동치: g(θ_max) ≥ κ) 로 한다.

### 2-7. 최종 식
  θ* = 0                                  (n_z ≥ κ)
  θ* = asin(κ/R) − atan2(n_z, c n_r)      (n_z < κ, 그리고 이 값 ≤ θ_max)
  θ* = NaN(못 고침)                        (n_z < κ, 이 값 > θ_max)
numpy: np.where(nz >= kappa, 0.0, np.where(ts <= theta_max, ts, np.nan)), ts = np.arcsin(kappa/R) − np.arctan2(nz, c*nr). 구현에서는 R = 0 가지(어차피 첫 번째 분기로 빠짐)의 0 나눗셈 경고를 막으려고 R 에 하한 1e-12 를 두고 arcsin 인자를 [−1, 1] 로 클립했다 — 수학적 값은 바뀌지 않는다.

## 3. 질문 3 — 단조성

g'(θ) = −n_z sinθ + c n_r cosθ, g'(0) = c·n_r. g = R sin(θ+δ) 의 극값은 θ + δ = ±π/2 에서.
분류 ([0, π/2) 구간):
- c n_r > 0, n_z < 0 (δ ∈ (−π/2, 0)): 최대점 θ = π/2 − δ > π/2 → 전 구간 단조증가.
- c n_r = 0: g = n_z cosθ, n_z < 0 이면 단조증가.
- c n_r < 0, n_z < 0 (δ ∈ (−π, −π/2)): θ_min = −π/2 − δ = atan((c n_r)/n_z) ∈ (0, π/2) 에서 g_min = −R 까지 내려갔다가 올라온다 → **비단조**. 즉 0 < θ < θ* 사이에서는 평면보다 오버행이 더 심해진다.
- c n_r < 0, n_z ≥ 0 (δ ∈ [π/2, π)): 전 구간 단조감소 — 멀쩡하던 면이 큰 θ 에서 새 오버행이 될 수 있다. c n_r < κ 면 θ_break = π − σ − δ 에서 g = κ 를 아래로 통과한다.
- c n_r > 0, n_z > 0: 올라갔다 내려오지만 g ≥ min(n_z, c n_r) > 0 ≥ κ 라 서포트 판정에 무관.
결론: g 는 반드시 단조증가가 아니다. 기울임 방향과 반대쪽 반경 성분을 가진 면(c·n_r < 0) 에서 비단조다.

질문 2 판정에 미치는 영향:
(1) θ* 식은 '첫 교차점' 이고, 교차는 항상 θ_min 이후의 단조증가 구간에서 일어나므로(g(θ_min) ≤ g(0) < κ) 식 자체는 그대로 정확하다. 교차 뒤 [0, π/2) 안에서 다시 떨어지지 않는다(2-4).
(2) 그러나 '못 고친다' 를 g'(0) 의 부호나 "단조니까 중간 어디서든 좋아지겠지" 로 판정하면 틀린다. 반드시 g(θ_max) ≥ κ (⟺ θ* ≤ θ_max) 로 판정해야 한다.
(3) 비단조 면은 θ* 에 못 미치는 각에서는 더 나빠지므로, 밴드/프로필에서 어중간한 각을 고르면 이 면들을 해친다. 각을 고를 땐 "θ ≥ θ*" 인 면들만 좋아진다는 걸 염두에 둬야 한다.
(4) 반대편(n_z ≥ 0, c n_r < κ) 면들은 큰 θ 에서 새로 서포트가 필요해진다. "이 면을 고칠 수 있다" 와 별개로 "다른 면을 망치지 않는다" 검사가 필요하다.

숫자 예 (비단조 + 간단조건이 갈리는 예):
n_z = −0.9, n_r = −0.1, c = +1 (n_φ = ±√0.18 ≈ ±0.4243), 임계각 45° → κ = −0.70711.
- g(0) = −0.9 < κ: 서포트 필요.
- g'(0) = c n_r = −0.1 < 0: 처음엔 더 나빠진다.
- θ_min = atan(0.1/0.9) = 6.34°, g_min = −√0.82 = −0.9055 (평면보다 심한 오버행).
- g(30°) = −0.8294 (여전히 평면보다 나쁨).
- R = 0.90554, σ = asin(−0.70711/0.90554) = asin(−0.78087) = −0.89607 rad (−51.34°), δ = atan2(−0.9, −0.1) = −(π − atan 9) = −1.68145 rad (−96.34°).
- θ* = σ − δ = 0.78538 rad ≈ 45.0°. 검산: g(45°) = (−0.9 − 0.1)/√2 = −0.70711 = κ ✓. g(50°) = −0.9·0.6428 − 0.1·0.7660 = −0.6551 > κ ✓.
- θ_max = 30° → 못 고침, θ_max = 60° → 고침. "c·n_r ≤ 0 이면 못 고친다" 는 이 면에서 틀리고, "c·n_r ≤ κ 면 못 고친다" 는 θ_max = 30° 에서 반대로 틀린다.

비교용 단조 예: n_z = −0.8, n_r = +0.6, c = +1 → R = 1, σ = −π/4, δ = atan2(−0.8, 0.6) = −0.9273, θ* = 0.1419 rad = 8.13°; 검산 g(8.13°) = −0.8·0.98995 + 0.6·0.14143 = −0.70711 ✓ (ψ₀ = 53.13°, 53.13° − 45° = 8.13° 와 일치).

## 4. 메모
- 도구는 하나도 호출하지 않았다(답 제출용 StructuredOutput 호출 제외). 모든 수치는 손 계산이다.
- 컨텍스트의 CLAUDE.md(프로젝트 지침)에 g, κ, θ* 의 최종 식이 적혀 있었다. 위 유도는 그것을 참조하지 않고 접평면에서 출발해 독립적으로 전개했고, 결과는 d = c 로 두면 일치한다. CLAUDE.md 에는 R 의 정의, '못 고친다' 의 정확 조건, 비단조성은 없었다.

## 못 고치는 조건
정확한(필요충분) 조건:
- θ_max 가 주어졌을 때: 못 고친다 ⟺ n_z < κ 이고 g(θ_max) = n_z·cosθ_max + c·n_r·sinθ_max < κ. 이는 θ* = asin(κ/R) − atan2(n_z, c·n_r) > θ_max (R = √(n_z²+n_r²)) 와 동치다. 근거: [0, π/2) 안에서 {θ : g ≥ κ} 는 구간 [θ*, π/2) 이므로 θ_max 가 그 안에 있는지만 보면 된다.
- θ_max 없이 0 ≤ θ < 90° 전부 허용할 때: 못 고친다 ⟺ n_z < κ 이고 c·n_r ≤ κ (⟺ θ* ≥ π/2). 근거: θ → 90° 에서 g → c·n_r 이고 g 는 θ_min 이후 단조증가라 sup g = c·n_r.

흔히 쓸 법한 간단한 조건과의 차이:
(가) "c·n_r ≤ 0 (기울임 방향과 오버행 방향이 안 맞음) 이면 못 고친다" — 틀림. 정확한 경계는 0 이 아니라 κ 다. κ < c·n_r ≤ 0 인 면은 g 가 처음엔 내려가도 결국 올라와 θ* < 90° 에서 고쳐진다. 예: n_z = −0.9, n_r = −0.1, c = +1, κ = −sin45° → θ* = 45.0°; θ_max = 60° 면 고쳐지는데 (가) 는 못 고친다고 한다.
(나) "c·n_r ≤ κ 면 못 고친다" — θ_max 가 없으면 정확하지만, θ_max < 90° 가 있으면 충분조건일 뿐 필요조건이 아니다. 같은 면에 θ_max = 30° 를 주면 g(30°) = −0.8294 < κ 라 못 고치는데, c·n_r = −0.1 > κ 라 (나) 는 고칠 수 있다 쪽으로 빠진다.
(다) "g'(0) = c·n_r 부호로 판정" 또는 "g 가 단조라고 가정" — (가) 와 같은 오류. 비단조성(질문 3) 때문에 반드시 g(θ_max) 또는 θ* 로 판정해야 한다.

## 단조성
아니다. g(θ) = n_z cosθ + c n_r sinθ = R sin(θ+δ), g'(0) = c·n_r 이므로 기울임 방향과 반대쪽 반경 성분을 가진 면(c·n_r < 0)에서는 θ 를 올릴 때 g 가 먼저 내려간다.
- c·n_r > 0, n_z < 0: [0, 90°) 전 구간 단조증가.
- c·n_r < 0, n_z < 0: θ_min = atan((c n_r)/n_z) 에서 g_min = −R = −√(n_z²+n_r²) 까지 내려갔다가(평면보다 더 심한 오버행) 다시 올라온다 → 비단조.
- c·n_r < 0, n_z ≥ 0: 전 구간 단조감소 → 멀쩡하던 면이 큰 θ 에서 새 오버행이 될 수 있다 (c n_r < κ 면 θ_break = π − asin(κ/R) − atan2(n_z, c n_r) 에서).
질문 2 에 미치는 영향: (1) θ* 는 첫 교차점이고 교차는 항상 θ_min 이후 단조증가 구간에서 일어나므로 θ* 식은 그대로 유효하며, [0, 90°) 안에서 다시 떨어지지 않는다. (2) 하지만 '못 고친다' 를 g'(0) 부호나 단조 가정으로 판정하면 틀린다 — g(θ_max) ≥ κ 로 판정해야 한다. (3) 0 < θ < θ* 사이의 어중간한 각은 이 면을 평면보다 더 나쁘게 만든다. (4) 반대편 면들이 새로 서포트가 필요해질 수 있어 "다른 면을 망치지 않는다" 검사가 따로 필요하다.
숫자 예: n_z = −0.9, n_r = −0.1, c = +1, κ = −sin45° = −0.70711. g(0) = −0.9(서포트 필요), g'(0) = −0.1 < 0, θ_min = 6.34° 에서 g_min = −0.9055, g(30°) = −0.8294(아직 평면보다 나쁨), θ* = asin(−0.70711/0.90554) − atan2(−0.9, −0.1) = −0.89607 + 1.68145 = 0.78538 rad = 45.0° (검산 g(45°) = (−0.9−0.1)/√2 = −0.70711 = κ), g(50°) = −0.6551 > κ. θ_max = 30° 면 못 고치고 θ_max = 60° 면 고친다.
