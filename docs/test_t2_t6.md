## 1. T2 — 층간격 식을 실제 G-code 에서 잰다 (증명 B)

### 1.1 검산할 식

층 k 는 변환높이 Z′ₖ 의 평면을 역변환한 원뿔면 z = Z′ₖ − c·r·tanθₖ (c=+1, 부호 각도 규약).
같은 r 에서 이웃 층의 수직 간격은

    Δz_pred(r) = (Z′ₖ₊₁ − Z′ₖ) − r·(tanθₖ₊₁ − tanθₖ)        ( = h − r·Δtan )

### 1.2 표본 (이 브랜치 코드, 내장 슬라이서, `--mode xyz`, 층고 0.3 · 0.4 둘 다)

| 이름 | 모델 | 프로필 | 종류 |
|---|---|---|---|
| lamp_band2 | `examples/lamp.stl` | `--auto-bands 2` (CLI 가 고른 것) | 블렌드 |
| sphere_28_20 | 구 r=10 (`analyze_blend_ratio._sphere`) | 밴드 [28, 20] (`analyze_gap_sample.profile_from`) | 블렌드(팽창) |
| waist3x2_42_36 | 허리3 ×2 (`widen(waisted_model(3), 2)`) | 밴드 [42, 36] | 블렌드(팽창) |
| sphere_10_30 | 구 r=10 | 밴드 [10, 30] | 블렌드(압축) — 추가 |
| ctrl_sphere_20 | 구 r=10 | 상수 20° | 대조군 |
| ctrl_lamp_25 | `examples/lamp.stl` | 상수 25° | 대조군 |

프로필은 G-code 의 `;CONICAL_META` 에서 **다시 읽어** 예측에 쓴다(생성 쪽 객체를 쓰지 않는다).

### 1.3 측정 방법

1. `; layer N z=…` 주석으로 층을 나눈다. 주석의 z 가 그 층의 Z′ₖ 다(내장 슬라이서가 변환공간에서 내는 노즐 높이).
   Z′ₖ₊₁ − Z′ₖ 가 층고와 같은지도 따로 확인한다(빈 층이 건너뛰어지면 그 쌍은 뺀다).
2. 각 층의 **압출 이동 끝점**(E 증가)만 쓴다. 트래블·리트랙트는 뺀다.
3. 이웃 층 쌍 (k, k+1) 마다 층 k+1 의 점 p₂ 를 최대 300 개 무작위로 고르고, 층 k 에서 반경이 가장 가까운
   점 p₁ 을 찾는다. |r₂ − r₁| ≤ 0.1 mm 인 쌍만 쓴다.
4. **주 측정 M1 (판정 대상)**: 층 k 의 z 를 r₂ 로 옮겨 잰다 —
   Δz_meas = z₂ − [z₁ + b̂ₖ·(r₂ − r₁)], b̂ₖ 는 층 k 의 모든 끝점에 맞춘 직선 z = âₖ + b̂ₖ·r 의 기울기(측정값).
   예측은 r₂ 에서 Δz_pred(r₂). 비 ρ = Δz_meas / Δz_pred.
   - 이유(결과 보기 전에 적음): ±0.1 mm 창 안에서 r 이 다르면 층 자체의 기울기 tanθ 때문에 z 가
     최대 0.1·tan42° ≈ 0.09 mm(층고 0.3 의 30%) 달라진다. 이건 식이 아니라 창의 성질이라 보정한다.
     보정량은 G-code 에서 잰 기울기로만 만든다(예측식을 쓰지 않는다).
5. **보조 측정 M2 (보고만)**: 보정 없는 z₂ − z₁ 대 Δz_pred((r₁+r₂)/2).
6. **보조 확인 (보고만)**: 층마다 측정 기울기 b̂ₖ 대 −tanθₖ(META), 직선 맞춤 잔차 최대값 — 층이 정말 원뿔인가.

### 1.4 사전 기준

- 블렌드 표본 전체 쌍에서 ρ 의 중앙값 ∈ [0.98, 1.02], 2.5~97.5 백분위 ⊂ [0.95, 1.05] → **통과**
- 같은 기준을 **블렌드 안 쌍만**(|Δtan| > 1e-9) 따로도 적용한다. 블렌드 밖은 예측이 h 라 쉬운 쌍이므로,
  섞어서만 보면 블렌드에서의 어긋남이 묻힐 수 있다
- 대조군(상수각): 모든 쌍에서 Δz_meas = h (ρ 기준 위와 같음). Δtan ≡ 0 임을 META 에서 확인
- 벗어나면: 벗어난 쌍의 r, 층 번호, Z′, 블렌드 경계까지 거리, |r₂−r₁| 을 JSON 에 남기고 원인을 적는다
  (현 분할 오차 / 블렌드 경계 / 좌표 반올림 0.001 mm / 기타)
- 테스트로 고정할 것: ① 상수각에서 이웃 층 간격 = h ② 블렌드 프로필에서 간격 = h − r·Δtan
  (작은 원기둥으로 내장 슬라이서를 돌리는 빠른 테스트)

## 2. T6 — 증명 A · E(iii)

### 2.1 증명 A: 유효 오버행 = 원래 오버행 − θ, 그리고 g(θ)

- 정의: 오버행각 ω = atan2(−n·b, |n − (n·b)b|) (0° = 수직벽, 90° = 아래를 보는 수평면). b 는 층의 위쪽 법선.
  원래 오버행 ω₀ 는 b = ẑ.
- **실제 원뿔 층**: 점 p 에서 Z′ = `AngleProfile.solve_forward` 로 층을 찾고, 그 층(변환공간의 평면 Z′)을
  역변환식 x = X·cosθ, z = Z′ − R·sinθ 으로 실공간에 만든 곡면의 (R, φ) 중앙차분 두 접벡터의 외적으로
  층 법선 b_num 을 구한다. 닫힌 식(sinθ, cosθ)을 쓰지 않는다.
- 표본: 무작위 회전체 프로필 10 개(매끈한 r(z), 시드 고정). 각 프로필마다 무작위 가변각 프로필
  (부호 있는 θ, −30°~45°, `AngleProfile`)을 하나씩.
  - (A1) 해석적 표본점(경선 평면 안의 법선, n_t = 0): 프로필 곡선 위 점 + 무작위 방위각.
    바깥을 보는 면(n_r > 0)은 ω_eff 대 ω₀ − θ, 안을 보는 면(n_r < 0)은 ω₀ + θ (같은 식의 부호 바꿈)
  - (A2) 회전체 **메시의 모든 면**(n_t ≠ 0 포함): ω_eff(b_num) 대 asin(−g(θ)) 의 오버행각,
    g(θ) = n_z·cosθ + c·n_r·sinθ
- **사전 기준**: A1 · A2 모두 최대 차 < 0.01°.

### 2.2 증명 E(iii): 곡면 층과 접하는 원뿔의 높이 오차

- 층 z = Z′ − a·r − b·r² (축대칭). 접하는 원뿔을 **수치로**(값과 기울기를 중앙차분으로 맞춘 1차 근사) 만든다:
  - (E1) 축(r=0)에서 접하는 원뿔 → 오차 e(r) 를 r 에 대해
  - (E2) r₀ > 0 에서 접하는 원뿔 → 오차 e 를 |r − r₀| 에 대해
- 매개변수: a ∈ {0, 0.364(=tan20°)}, b ∈ {0.002, 0.01, 0.05} /mm, r ∈ [0.1, 20] mm 로그 격자, r₀ = 8 mm
- 일반 곡선 하나 더: f(r) = a·r + β·(cosh(r/L) − 1) (2차가 아닌 층) — 작은 거리에서 e ≈ f″(r₀)/2·Δ²
- **사전 기준**:
  - E1·E2(2차 층): 로그-로그 최소제곱 기울기 2 ± 0.01, e / (b·Δ²) = 1 ± 1e-3
  - 일반 곡선: Δ ∈ [0.01, 0.5] mm 에서 기울기 2 ± 0.05, e / (f″/2·Δ²) → 1 (Δ = 0.01 에서 1 ± 0.01)
- 그림 `docs/figures/t6_e3_tangent_cone.png`: 왼쪽 단면(곡면 층과 접하는 원뿔), 오른쪽 로그-로그(기울기 2 기준선)
- 해석: 이건 식 검산이고 "밴드 무한 ≈ 곡면 슬라이싱" 비유를 **가정**으로 쓸 때의 조건
  (층의 경선 곡률이 작을 것: 오차 ≈ 곡률 × 거리² / 2)을 보이는 그림 재료일 뿐이다. 실제 곡면 슬라이서의
  층 곡률은 S4 세션이 낸다.

| 층 | 접점 | 로그-로그 기울기 | e / (계수 × 거리²) | 판정 |
|---|---|---|---|---|
| 2차 z = Z′ − a·r − b·r², a ∈ {0, tan20°}, b ∈ {0.002, 0.01, 0.05} | 축 (E1), r 0.1~20 | 2.00000 (6 경우 전부) | 1 ± 4e-6 | 통과 |

- 2차 층에서는 높이 오차가 **정확히 b·(거리)²** 다(1차 근사의 나머지가 2차 항 하나뿐). 일반 층에서는 작은
  거리에서 f″(r₀)/2·(거리)² 로 수렴하고, 3차 항 때문에 안쪽/바깥쪽 기울기가 2 에서 ±0.007 갈라진다.
- 그림 오른쪽의 점선(층고 0.3 mm)을 보면 b = 0.01 /mm 일 때 접점에서 약 5.5 mm, b = 0.05 /mm 이면
  약 2.4 mm 떨어지면 원뿔과 곡면 층의 높이 차가 층고 하나를 넘는다. "밴드 무한 ≈ 곡면 슬라이싱" 을
  가정으로 쓸 때의 조건이 이 수치다 — 층의 경선 곡률(≈ 2b, 기울기가 작을 때)이 작을 것.
  실제 곡면 슬라이서 층의 b 는 S4 세션 값을 넣어야 한다.
