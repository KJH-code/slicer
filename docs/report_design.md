> 차이가 없었다. 직접 개조한 5축 프린터로 램프 모델을 [조건]으로 출력한 결과

### Ⅱ. 이론적 배경 (2p)
1. **원뿔 변환** (RotBot): f(x,y,z) = (x/cosθ, y/cosθ, z + c·r·tanθ), 변환→평면 슬라이스→역변환 — [Fig. 1] 개념도
2. **해석식 판정**: g(θ) = n_z·cosθ + d·n_r·sinθ, 서포트 필요 ⟺ g < −sin(임계각). 비등각 함정 예시(funnel: 변환공간 53° vs 물리 26°) — [Fig. 2]
3. **가변각 θ(Z′)**: tanθ 선형 보간 이유, 가역성 c·r_max·s < 1, 층간격 배율 m = 1 − c·r·s, 블렌드 폭 하한 유도 (짧은 유도 3줄)
4. **각도 선택 목적함수** J = ΔS − k·평균|θ| − k_blend·블렌드 벌점, k 의 의미(서포트–왜곡 교환비)
5. **5축 기구학(REP5X)**: 헤드 회전식, RTCP, B = θ(Z′), C = 방위각, 축 통과 시 B 부호 반전 — [Fig. 3] 구조 사진/도식

### Ⅲ. 연구 방법 및 절차 (2p)
1. **시스템 구성** — [Fig. 4] 파이프라인: STL → 메시 검사 → 각도 결정(균일/밴드) → 왜곡 → PrusaSlicer → 역변환 → REP5X 자세 변환 → 사전 점검 → G-code
2. **검증 계층** — 해석식 예측 → 툴패스 검사기(진짜 오버행, 낙관/비관 지지) → 퇴적 복원 IoU → **실물(이번에 새로 연 층)**
3. **k 학습** — 50개 STL·2,300개 IoU 레이블, MLP+Softplus 로 형상별 k 예측, 3 시드 (2차 발표 7·8장 내용)
4. **계산 실험** — 허리 축(목 반경 r=1~7)·구·램프, 균일 vs 밴드 N=1~6, 0~44° 4° 격자 전수 (576회)

## 5. 오늘의 실물 실험 설계

### 5.1 원칙
- **판정 기준은 출력 전에 커밋한다.** 아래 5.5 를 오늘 첫 출력 전에 커밋하고 그 해시를 보고서에 적는다.
- **첫 출력은 작고 싼 것으로.** 5축은 사고가 쉽다. 램프를 바로 걸지 않는다.
- 램프(16×16×30mm)는 기구학 하한 5~7분/개, 가속을 넣으면 그 1.8~2.1배 → **개당 15~20분 예상.** 하루에 10개 넘게 뽑을 수 있다 → **반복(n=2)이 가능하다.**
- 조건 간 공통: 같은 필라멘트 롤, 같은 노즐 온도·속도·인필, 서포트 끔, 같은 위치.

## 7. 실물 결과로 새로 쓸 수 있는 내용

1. **검증 계층의 '⑥ 실물' 층 개설** — 해석식 → 툴패스 → 퇴적 복원 → 실물 네 층이 같은 순위를 내는지 표 하나로 (Table 6 확장)
2. **지지 모델 확정** — 저장소 기본값(`require_supported_below`)을 실물 근거로 정함. "계산으로는 못 좁혔던 것을 실물이 좁혔다"는 서술
3. **AI(k 학습) 목적함수 판정** — IoU 기준과 오버행 기준이 램프에서 반대를 고르는데, 실물이 어느 쪽 편인지. AI·정보 분야로서 가장 중요한 연결고리
4. **기구학 예측 검증** — 출력 시간 비율, 축 근처 C 급회전의 실제 영향(느려짐/흔들림)
5. **(선택) 치수 오차의 원인 분리** — 링 실험으로 반경 비례(회전축) vs 일정(열수축)
6. **철회·수정 기록** — 예측이 틀린 항목은 정정 표시와 이유를 남김. 이 연구가 해 온 방식 그대로이며, 과제 수행 과정의 문제해결 절 재료가 된다
