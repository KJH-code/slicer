### 1.1 T3 — 밴드 수 N 의 최선해

**탐색 공간 (N = 1, 2, 3 은 모두 같은 후보 집합에서 뽑는다 → 포함 관계가 정확히 성립)**

- 경계 후보 B: 면 중심 높이 범위 [z_lo, z_hi] 의 i/12 (i = 1..11) 11 점 + **허리 위치** 1 점
  (`RadiusProfile` 의 높이별 최대 반경이 최소인 높이, 범위의 10~90% 안에서). 최대 12 점.
  N 밴드 = B 에서 경계 N−1 개를 고른 모든 조합.
- 각도 후보 A: 부호 있는 4° 격자 {0, ±4, …, ±44}. **제한:** 방향 d 의 각도는 그 방향의
  `critical_angle` 이 θ* > 0 인 면(= 그 방향 각도로만 풀리는 면)이 하나라도 있을 때만 넣는다.
  예상: 17 모델·sphere·funnel·mushroom 은 outward 만(12 값), torus 는 양방향(23 값).
  이 제한이 최선해를 바꾸지 않는지 **3 모델에서 N=2 를 23 값 전수로 다시 돌려 대조**한다.
- 포함 관계: N 밴드 해 (경계 b₁..b_{N−1}, 각 θ) 는 N+1 밴드에서 아무 경계 b′ 를 더하고 양쪽에
  같은 각을 주면 `_merge_bands` 가 합쳐 **같은 프로필**이 된다. 그래서 N+1 의 최선이 N 의 최선보다
  나쁠 수 없다(증명 E(i)). 
- **N = 4 는 제한 탐색이다** (전수 12⁴ × C(12,3) 는 모델당 수 시간): N=3 최선해(각 목적)의 한 밴드를
  B 의 한 점으로 둘로 나누고, 나뉜 두 밴드는 A 전수, 나머지 두 밴드는 그 해의 각도 ±4° 안에서 전수.
  이 공간도 N=3 최선해를 포함한다(나눈 두 밴드에 같은 각). N=4 는 'N=3 에서 더 쪼개서 이득이 남나'
  를 보는 **국소 확인**이지 전수 최선이 아니다 — 결과 문장에서 그렇게 적는다.

**두 목적 (각 N 마다 따로)**

- ① **서포트 최소**: 해석식 서포트 % 가 가장 작은 것, 동점(차 ≤ 1e-9 %p)은 평균 |θ| 작은 쪽,
  그래도 동점이면 각도 튜플 사전순.
- ② **같은 서포트에서 평균 |θ| 최소**: 해석식 서포트가 기준선 (a)(J 균일)의 서포트 이하
  (+1e-9)인 해 중 평균 |θ| 최소. 동점 처리는 ① 과 같은 순서.
  ("같은 서포트" 의 기준을 (a) 로 둔 이유: 보고서 4.1 의 "밴드는 같은 미지지를 더 작은 기울기로 낸다"
  를 최선해로 다시 재는 것이다.)

**툴패스 확인**: 각 (모델, N, 목적) 의 최선해 + 기준선 (a)·(b) 만 툴패스로 잰다(층고 0.3·0.4).

**사전 기준**

1. **단조성 (E(i))**: N = 1, 2, 3 에서 목적 ① 의 최선 해석식 서포트가 비증가, 그리고
   (서포트, 평균|θ|) 사전순 최선값이 비증가. 목적 ② 의 최선 평균 |θ| 도 비증가.
   **한 건이라도 어기면 탐색 구현 결함**으로 보고 결과를 쓰지 않는다(고친 뒤 다시).
   N = 4(제한)는 N=3 해를 포함하므로 같은 성질을 확인만 한다.
2. **포화 N\***: 목적·층고마다, N → N+1 에서 (툴패스 미지지 감소 < 0.5mm) **그리고**
   (평균 |θ| 감소 < 1°) 인 첫 N. 감소가 음수(악화)여도 '< 0.5' 에 든다(쪼개서 나빠지면 포화로 본다).
   N = 3 에서도 포화하지 않으면(N=4 에서 여전히 이득) "N\* ≥ 4" 로 적는다.
   결과 문장: "모델 X 개 N\* = 1, Y 개 N\* = 2, …" (목적 ① 을 본문, ② 를 부록).
3. **참고 대조**: 최선해 N=2 대 (a)·(b) 의 승패(0.5mm 무승부) — `gap_audit.md` §9.3 의
   J 선택 밴드2 표와 나란히 적는다.

### 1.2 T5 — 메시 예측 대 G-code 측정

- 모델마다 균일 outward 0, 4, …, 44° (12 각) 의 해석식 서포트 % (`support_fraction`) 대
  툴패스 진짜 오버행 미지지 길이 mm → **스피어만 ρ** (동순위 평균). 층고 0.3·0.4 따로.
  (torus 는 inward 가 유효하므로 inward 0~44° 도 따로 한 줄 더 적는다. 중앙값에는 outward 만.)
- 어느 한쪽이 12 각에서 상수(전부 0 등)면 ρ 는 정의되지 않는다 → **중앙값에서 빼고 개수를 따로**
  적는다.
- **사전 기준**: 층고마다 모델별 ρ 중앙값 ≥ 0.8 이면 "예측 단계가 G-code 결과를 대표한다".
  두 층고 모두 넘어야 통과.
- ρ < 0.8 인 모델은 원인을 기록한다: 미지지 중 바닥 1mm 안 몫, 해석식이 0 이 된 뒤에도 남는
  툴패스 미지지, 해석식은 줄어드는데 툴패스는 커지는 각도 구간.

### 2.1 T3 — 밴드 수 N 의 최선해

**사전 기준 1 (단조성, E(i)) — 통과.** 21 모델 × 두 목적 × N = 1→2→3→4 에서 위반 **0 건**.
빠른 평가기와 저장소 판정식(`support_fraction_profile`, `profile_objective` 의 평균|θ|) 차는 최대 1.8e-15.
탐색 규모: 모델당 N=3 에서 114,048 후보(torus 803,022), 그중 대부분이 층간격 제약으로 실현 불가.
N=3 탐색 시간 모델당 117~386 s, torus 1,523 s (4 코어 병렬).

**부호 제한 대조 — 3 모델 중 1 건 다름 (적용 범위).** 허리 r=3 · 허리3 로브0.2 는 23 값 전수와 같은 최선해.
**구 의 N=2 목적 ① 은 전수에서 `[44, −44]`(방향 전환) 가 평균|θ| 23.81° 로 제한판 `[44, 0]` 23.96° 보다
0.15° 작다**(서포트 둘 다 0). 즉 outward-only 제한은 엄밀히 무해하지 않다 — 방향을 뒤집는 블렌드가
평균|θ| 를 조금 줄이는 해가 있다. 차이가 0.15° 라 N\* 판정(1° 문턱)에는 영향이 없을 것으로 보지만
확인은 3 모델뿐이다.

**최선해의 모양.** 목적 ① 은 17 축대칭 모델 + 데모 sphere 전부 N=1 이 **44°**(서포트 0), N≥2 는 아랫밴드 44°
+ 윗밴드 0° 로 내려간다. 목적 ② 는 아랫각이 J 균일각 근처(16~36°)이고 위가 0°.
mushroom 은 어떤 원뿔로도 서포트가 안 줄어 전부 0°(28.27%), funnel 은 [28, 24, 0], torus 는 서포트가

**읽기 — N\* ≥ 4 는 '밴드를 늘릴수록 좋다' 가 아니다.** 포화 정의가 "미지지 감소 < 0.5mm **그리고** 각 감소 < 1°"
라서, 평균|θ| 가 계속 1° 넘게 줄면 툴패스가 **나빠져도** 포화로 보지 않는다. 실제로 그랬다:

- 목적 ① 의 평균|θ| 는 44 → 16.8 → 10.8 → 9.7° 로 계속 줄지만, 툴패스 미지지 중앙값은 층고 0.4 에서
  0.0 → 1.3 → **68.9** mm 로 커진다. 해석식 서포트는 N 마다 같은데(대부분 0) G-code 는 나빠진다.
- 원인(구·sphere·허리3 ×1.3·×2·허리 r=2 를 열어 봄): N=3 최선해의 첫 블렌드(44°→32/36°)를 계획기가 반경이
  작은 **바닥 극점**(Z′ 0.01~1.6mm)으로 옮기고, 둘째 블렌드(32/36°→0°)는 길게 깔린다. 두 블렌드가 바닥
  오버행 면 위에 놓이고 층간격 배율(≤ 1.5)이 층고 0.4 에서 미지지를 만든다(미지지 z 범위 0.4~4.4mm).
  `gap_audit.md` §9.3 읽기 3 과 같은 현상이다 — **해석식(판정식에 m 이 없다)은 이것을 모른다.**
- 즉 "해석식 최선 = 전수 최선" 은 N 이 커질수록 G-code 최선과 멀어진다. 해석식으로 N 을 늘리면
  기울기는 줄지만 그 이득은 **툴패스 미지지로 되갚아진다.**

**사전 기준 3 (N=2 최선해 대 기준선, 0.5mm 무승부, 밴드 · 균일 · 무승부).**

| 비교 | 층고 0.3 | 층고 0.4 |
|---|---|---|
| ① 최선 N=2 대 (a) J 균일 | 14 · 4 · 3 | 19 · 1 · 1 |
| ① 최선 N=2 대 (b) 같은 아랫각(44°) 균일 | 12 · 0 · 9 | 1 · **10** · 10 |
| ② 최선 N=2 대 (a) J 균일 | 1 · **16** · 4 | 1 · **19** · 1 |
| ② 최선 N=2 대 (b) 같은 아랫각 균일 | 1 · **16** · 4 | 0 · **20** · 1 |

- ① 이 (a) 를 이기는 것은 아랫각 44° 덕이다(같은 44° 균일과는 층고 0.4 에서 오히려 10 건 진다).
  층고 0.3 의 (b) 12 승은 차가 1mm 안팎(중앙 1.7 대 1.0mm)인 바닥 극점 신호다.
- ② 는 **해석식 서포트가 J 균일 이하인데도 툴패스에서 16~20/21 진다.** 보고서 4.1 의 "밴드는 같은 미지지를
  더 작은 기울기로 낸다(J 선택 밴드2, 중앙 8.3°)" 는 J 선택 해에서 잰 것이고, 기울기를 **최대로** 줄인
  최선해(평균|θ| 중앙 4.6°)에서는 성립하지 않는다 — 해석식이 같다고 본 서포트가 G-code 에서는 같지 않다.

**4.2 에 넣을 문장 (제안).** "증명 E(i) 대로 전수 최선해의 해석식 서포트는 N 에 비증가했다(위반 0/21).
그러나 해석식 최선해를 G-code 로 내보내면 N ≥ 3 에서 블렌드 층의 층간격 팽창이 바닥 오버행 위에 놓여
미지지가 커진다(층고 0.4 중앙 0 → 69mm). 해석식만으로는 밴드 수가 포화하지 않으며(목적 ① 17/21 이
N\* ≥ 4), 이는 판정식이 층간격을 모르기 때문이다 → 밴드 수는 툴패스 검사로 상한을 둔다."

### 2.2 T5 — 메시 예측 대 G-code 측정

**사전 기준 — 통과.** 모델별 스피어만 ρ(outward 0~44°, 12 각) 중앙값: **층고 0.3 에서 0.956, 층고 0.4 에서 0.998**
(정의된 20 모델; mushroom 은 해석식이 12 각 모두 28.27% 로 상수라 정의 안 됨). 0.8 미만은 **torus 하나**
(−0.73 / 0.01). 18 개(17 축대칭 + sphere)가 0.94 이상, funnel 0.86.

| 모델 | ρ 0.3 | ρ 0.4 | 미지지 중 바닥 1mm 안 (0.3 / 0.4) |
|---|---|---|---|
| 17 축대칭 + sphere | 0.94 ~ 0.99 | 0.98 ~ 1.00 | 0.34~0.77 / 0.22~0.48 |
| funnel | 0.86 | 0.86 | 0.03 / 0.02 |
| torus (outward) | **−0.73** | **0.01** | 0.91 / 0.72 |
| torus (inward, 참고) | 0.69 | 0.59 | 0.55 / 0.39 |
| mushroom | 정의 안 됨 | 정의 안 됨 | 0.01 / 0.01 |

**원인 기록.**
- **torus**: 아랫면이 바깥쪽(outward 로 풀림)과 안쪽(inward 로 풀림) 두 방향 오버행을 같이 가진다. 해석식 넓이는
  outward 각이 커질수록 24.96 → 18.65% 로 줄지만, 툴패스 미지지는 0~20° 에서 줄다가 40~44° 에서 322~373mm 로
  커진다(층고 0.3, 그중 89~91% 가 바닥 1mm 안 — 베드에 닿는 고리 부분). 넓이 합(해석식)과 길이(툴패스)가
  두 방향 효과를 다르게 가중한다. 축대칭 단일 방향 오버행이라는 예측기의 전제가 깨지는 형상이다.
- **mushroom**: 수평 아랫면은 어떤 원뿔각으로도 안 풀려 해석식이 상수다. 그런데 툴패스 미지지는 94.7 → 583mm
  (0° → 44°)로 6 배 커진다 — **각도가 오히려 해롭다는 것을 해석식은 못 본다.** ρ 가 정의되지 않는 것이 곧
  "예측기가 순위를 못 낸다" 는 뜻이다(보고서 Table 3 mushroom 행과 같은 결론).
- 공통 잔차: 17 축대칭 모델 대부분이 44° 에서 해석식 0% 인데 툴패스 > 0.5mm(바닥 극점 신호, G3), 그리고 40→44°
  구간에서 해석식은 줄고 툴패스는 는다. 순위 상관은 높지만 **꼭대기 각도 근처의 미세 순위는 예측이 못 가린다.**
- 기존 `compare_prediction_vs_toolpath.py`(데모 구 subdiv3 + 세분화, 6 각, 전체 미지지 %) 는 다른 지표라
  여기 숫자와 섞지 않는다.

**신뢰성 총정리에 넣을 문장.** "균일 원뿔 0~44° 의 해석식 예측 순위는 G-code 툴패스 미지지 순위와 모델별 ρ
중앙 0.96(층고 0.3)·1.00(0.4)로 일치했다(20 모델). 예외는 두 방향 오버행(torus)과 원뿔로 못 푸는 수평
아랫면(mushroom)으로, 둘 다 예측기의 전제(단일 방향, 원뿔로 풀리는 오버행) 밖이다."

## 4. 적용 범위 · 한계

- T3 최선해는 **해석식** 최선이다. N ≥ 3 의 해석식 최선은 G-code 에서 나빠진다(§2.1) — "최선해" 를 툴패스로 다시 고르는
  탐색(비용 수 시간)은 하지 않았다.
- T3 의 N=4 는 국소 이웃이다. 각도 격자 4°, 경계 후보 12 점(계획기가 ±0.25H 안에서 다시 옮긴다).
- 부호 제한은 3 모델로만 대조했다(1 건 다름).
- 표본 21 개 중 17 개가 '구 + 목 + 나팔' 계열이라 바닥 모양이 같다(G3). 미지지 신호의 33~77% 가 바닥 1mm 안이다(T5).
