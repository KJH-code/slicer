### 1.1 T3 — 밴드 수 N 의 최선해

**탐색 공간 (N = 1, 2, 3 은 모두 같은 후보 집합에서 뽑는다 → 포함 관계가 정확히 성립)**

- 경계 후보 B: 면 중심 높이 범위 [z_lo, z_hi] 의 i/12 (i = 1..11) 11 점 + **허리 위치** 1 점
  (`RadiusProfile` 의 높이별 최대 반경이 최소인 높이, 범위의 10~90% 안에서). 최대 12 점.
  N 밴드 = B 에서 경계 N−1 개를 고른 모든 조합.
- 각도 후보 A: 부호 있는 4° 격자 {0, ±4, …, ±44}. **제한:** 방향 d 의 각도는 그 방향의
  `critical_angle` 이 θ* > 0 인 면(= 그 방향 각도로만 풀리는 면)이 하나라도 있을 때만 넣는다.
  예상: 17 모델·sphere·funnel·mushroom 은 outward 만(12 값), torus 는 양방향(23 값).
  이 제한이 최선해를 바꾸지 않는지 **3 모델에서 N=2 를 23 값 전수로 다시 돌려 대조**한다.
- 포함 관계: N 밴드 해 (경계 b₁..b_{N−1}, 각 θ) 는 N+1 밴드에서 아무 경계 b′ 를 더하고 양쪽에
  같은 각을 주면 `_merge_bands` 가 합쳐 **같은 프로필**이 된다. 그래서 N+1 의 최선이 N 의 최선보다
  나쁠 수 없다(증명 E(i)). 
- **N = 4 는 제한 탐색이다** (전수 12⁴ × C(12,3) 는 모델당 수 시간): N=3 최선해(각 목적)의 한 밴드를
  B 의 한 점으로 둘로 나누고, 나뉜 두 밴드는 A 전수, 나머지 두 밴드는 그 해의 각도 ±4° 안에서 전수.
  이 공간도 N=3 최선해를 포함한다(나눈 두 밴드에 같은 각). N=4 는 'N=3 에서 더 쪼개서 이득이 남나'
  를 보는 **국소 확인**이지 전수 최선이 아니다 — 결과 문장에서 그렇게 적는다.

**두 목적 (각 N 마다 따로)**

- ① **서포트 최소**: 해석식 서포트 % 가 가장 작은 것, 동점(차 ≤ 1e-9 %p)은 평균 |θ| 작은 쪽,
  그래도 동점이면 각도 튜플 사전순.
- ② **같은 서포트에서 평균 |θ| 최소**: 해석식 서포트가 기준선 (a)(J 균일)의 서포트 이하
  (+1e-9)인 해 중 평균 |θ| 최소. 동점 처리는 ① 과 같은 순서.
  ("같은 서포트" 의 기준을 (a) 로 둔 이유: 보고서 4.1 의 "밴드는 같은 미지지를 더 작은 기울기로 낸다"
  를 최선해로 다시 재는 것이다.)

**툴패스 확인**: 각 (모델, N, 목적) 의 최선해 + 기준선 (a)·(b) 만 툴패스로 잰다(층고 0.3·0.4).

**사전 기준**

1. **단조성 (E(i))**: N = 1, 2, 3 에서 목적 ① 의 최선 해석식 서포트가 비증가, 그리고
   (서포트, 평균|θ|) 사전순 최선값이 비증가. 목적 ② 의 최선 평균 |θ| 도 비증가.
   **한 건이라도 어기면 탐색 구현 결함**으로 보고 결과를 쓰지 않는다(고친 뒤 다시).
   N = 4(제한)는 N=3 해를 포함하므로 같은 성질을 확인만 한다.
2. **포화 N\***: 목적·층고마다, N → N+1 에서 (툴패스 미지지 감소 < 0.5mm) **그리고**
   (평균 |θ| 감소 < 1°) 인 첫 N. 감소가 음수(악화)여도 '< 0.5' 에 든다(쪼개서 나빠지면 포화로 본다).
   N = 3 에서도 포화하지 않으면(N=4 에서 여전히 이득) "N\* ≥ 4" 로 적는다.
   결과 문장: "모델 X 개 N\* = 1, Y 개 N\* = 2, …" (목적 ① 을 본문, ② 를 부록).
3. **참고 대조**: 최선해 N=2 대 (a)·(b) 의 승패(0.5mm 무승부) — `gap_audit.md` §9.3 의
   J 선택 밴드2 표와 나란히 적는다.

### 1.2 T5 — 메시 예측 대 G-code 측정

- 모델마다 균일 outward 0, 4, …, 44° (12 각) 의 해석식 서포트 % (`support_fraction`) 대
  툴패스 진짜 오버행 미지지 길이 mm → **스피어만 ρ** (동순위 평균). 층고 0.3·0.4 따로.
  (torus 는 inward 가 유효하므로 inward 0~44° 도 따로 한 줄 더 적는다. 중앙값에는 outward 만.)
- 어느 한쪽이 12 각에서 상수(전부 0 등)면 ρ 는 정의되지 않는다 → **중앙값에서 빼고 개수를 따로**
  적는다.
- **사전 기준**: 층고마다 모델별 ρ 중앙값 ≥ 0.8 이면 "예측 단계가 G-code 결과를 대표한다".
  두 층고 모두 넘어야 통과.
- ρ < 0.8 인 모델은 원인을 기록한다: 미지지 중 바닥 1mm 안 몫, 해석식이 0 이 된 뒤에도 남는
  툴패스 미지지, 해석식은 줄어드는데 툴패스는 커지는 각도 구간.
