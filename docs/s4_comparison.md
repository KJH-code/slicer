# S4 곡면 슬라이서 vs 원뿔족 사다리

원뿔족 사다리의 마지막 칸: **평면 → 균일 원뿔 → 밴드 → 원뿔족 천장 → 곡면(S4)**.

S4 Slicer(github.com/jyjblrd/S4_Slicer, GPL-3.0)는 저장소에 넣지 않는다. 스크래치에 클론해
`tools/s4_compare.py --s4 <클론 경로>` 로 노트북 셀을 헤드리스로 실행한다.

---

## 1. 사전 등록 (결과를 보기 전에 적고 커밋함, 2026-11-10)

### 1.1 평가 지표 (S4 와 원뿔족을 같은 함수로)

- S4 결과는 G-code 없이 평가한다. 사면체마다 변형 기울기 `F = D_y · D_x⁻¹` (변을 열로 쌓은
  행렬, 원본 x → 변형 y). 층 함수 z′(x) = y_z(x) 의 기울기는 F 의 3행(= Fᵀẑ),
  빌드 방향 `d = ∇z′/|∇z′|`.
- 표면 삼각형마다 자기를 포함하는 사면체의 d 를 쓴다. `g = n·d < κ = −sin45°` 면 서포트 필요.
  면적 가중 비율(%).
- 원뿔족 쪽 d 는 `analytic.py` 와 같다: `c·sinθ·r̂ + cosθ·ẑ`. 평면·균일·밴드·천장은
  **S4 와 같은 사면체 표면 메시**에서 `analytic.support_fraction`·`plan_bands`/
  `evaluate_band_plan`·`adaptive_ceiling` 으로 잰다(같은 면, 같은 면적).
  `g = n·d` 함수에 원뿔 d 를 넣으면 `analytic.support_fraction` 과 같은 값이 나오는지를
  실행마다 검산해 JSON 에 남긴다.
- **바닥면 규칙**: 1차 지표는 저장소 규칙 그대로(**제외 없음** — compare_ceiling 의
  mushroom 28.3% 는 기둥 바닥 원판을 포함한 값). 2차 지표로 베드 접촉면
  (`n_z < −0.99` 이고 centroid z < z_min + 0.3 mm, S4 의 bottom 판정 0.3 mm 와 같은 폭)을
  **모든 열에서 똑같이** 뺀 값을 함께 낸다. S4 가 바닥을 45° 넘게 기울이면 1차 지표에서
  바닥 원판이 '공짜로' 빠지는 인공물이 생길 수 있어서다.

### 1.2 S4 실행 조건

- 노트북 셀: 2(사면체화·속성), 3(경로·평면 맞춤), 4(초기 회전장 + `optimize_rotations`,
  파라미터 블록 직전까지), 7(`calculate_deformation`, `ITERATIONS = 1000` 줄 직전까지).
  메시 로드는 open3d 대신 trimesh. 플로터는 아무것도 안 하는 더미. GIF 끔.
- **한 번만 돈다**(노트북의 '변형 결과를 다시 입력으로' 반복은 하지 않음).
- 변형 단계 `ITERATIONS = 1000` (노트북 값).
- 입력 메시는 `meshio.center_on_axis` 로 맞춘 뒤 넘긴다(S4 의 자체 센터링과 같은 규칙이라
  무동작). 원뿔 축 = S4 회전장의 기준 축 = z 축.
- 해상도 2단계: tetgen `minratio=1.5, mindihedral=10, maxvolume = V_bbox / N`,
  **R1: N = 1500, R2: N = 4000**. 표면 메시는 데모 생성기 그대로.
- 파라미터 2세트(안정성 판정용):
  - **P1** = 노트북 기본값 (NEIGHBOUR_LOSS_WEIGHT=20, MAX_OVERHANG=30, ROTATION_MULTIPLIER=2,
    SET_INITIAL_ROTATION_TO_ZERO=False, INITIAL_ROTATION_FIELD_SMOOTHING=30, ITERATIONS=100,
    STEEP_OVERHANG_COMPENSATION=True)
  - **P2** = P1 에서 NEIGHBOUR_LOSS_WEIGHT=10 만 바꿈 (평활 가중 절반 — 섭동)
  - (탐색용, 판정 제외) **P3** = P1 에서 MAX_OVERHANG=45 (우리 임계각과 맞춤)

### 1.3 '깔끔한 결과' 기준 (조건 = 모델 × {R1,R2} × {P1,P2} 네 실행)

1. **수렴**: 회전장·변형 두 `least_squares` 모두 `status ≥ 1`. `status = 0`(반복 상한)이면
   미수렴으로 적는다. cost 는 전부 기록.
2. **뒤집힌 사면체 0개**: `det F ≤ 0` 인 사면체 수 = 0.
3. **안정성**: 1차 지표 S4 서포트%가 R1↔R2 에서 **|Δ| ≤ 2.0 %p**, P1↔P2 에서
   **|Δ| ≤ 3.0 %p**.
4. **평면 대비 감소**: S4 ≤ 평면 − 1.0 %p. 못 줄이면 그 자체를 결과로 적는다.

1~3 을 네 실행 모두에서 만족하면 그 모델·조건을 '깔끔'으로 친다. 4 는 '깔끔'과 별개로
결과 칸에 적는다(못 줄이는 것도 깨끗한 결과일 수 있다).

### 1.4 곡률 가설 (가정)

"축대칭 곡면 층 z = Z′ − f(r) 의 1차 근사가 원뿔이므로, 층의 경선 곡률이 작으면 원뿔족 극한이
곡면에 가깝다." 재는 양:

- 사면체마다 부호 있는 기울기각 `θ = atan2(d·r̂, d_z)`. 정점 평균 → P1 기울기 `∇θ`.
  층 경선 접선 `τ = d_z·r̂ − d_r·ẑ`(정규화) 방향 도함수 `κ_m = ∇θ·τ` [rad/mm] =
  층면의 경선 곡률. 원뿔 층은 0. 축 근처(r < 0.05·r_max) 사면체는 r̂ 가 불안정해서 뺀다.
- 무차원 `κ_m·r_max` 의 부피가중 중앙값·90분위, 그리고 층 내 θ 산포(변형공간 z′ 를 1 mm
  층으로 묶어 층마다 θ 의 부피가중 표준편차, 평균).
- 축대칭성 점검: 접선 성분 `|d·t̂|` 의 부피가중 평균 (S4 회전은 접선축 회전이라 0 에 가까워야 함).
- 예측: 곡률·산포가 작은 모델일수록 |S4 − 천장| 이 작다. 표본이 5개라 상관계수는 내지 않고
  표로만 본다.
