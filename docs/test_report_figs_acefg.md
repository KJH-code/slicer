### 1.4 F — 층고와 블렌드 팽창

**식 (결과 전에 유도).** 실공간 층 z = Z′ − r·T(Z′) (outward, T = tanθ). ∂z/∂Z′ = m = 1 − r·s, ∂z/∂r = −T.
연직에서 φ 만큼 밖으로 누운 벽 r = r₀ + z·tanφ 위에서 이웃 층의 교점 사이:

  Δz = m·h / (1 + T·tanφ),   Δr = Δz·tanφ

검사기 A(연직 프레임)는 앞 층 점이 수평 ≤ w(0.45mm), 수직 (0, 1.5h] 안에 있으면 지지로 친다. 그래서

- **수직 창 조건** Δz ≤ 1.5h ⟺ m ≤ 1.5(1 + T·tanφ). **h 가 양변에서 지워진다** — 층고와 무관하고,
  계획기가 m ≤ 1.5 로 묶으므로 넘지 않는다. ⇒ **수직 창은 층고 의존성을 설명하지 못한다** (예측).
- **수평 폭 조건** Δr ≤ w ⟺ tanφ·(m·h − w·T) ≤ w. 검사기의 실효 임계 오버행각
  φ*_chk = atan( w / (m·h − w·tanθ) ) (m·h ≤ w·tanθ 면 90°).
  해석식(선택기)의 임계는 φ_sel = θ + 45°. **검사기가 선택기보다 엄격해지는 경계**:

  m·h > w·( cot(θ + 45°) + tanθ )    ⟺    h > h_c(θ, m) = w·f(θ)/m,  f(θ) = cot(θ+45°) + tanθ

  θ = 0 (밴드2 의 윗밴드 0° 쪽 블렌드 끝): h_c = w/m → m=1.5 에서 **0.30 mm**, m=1 에서 0.45 mm.
  f 의 최소는 θ≈22° 에서 ≈0.83 → 균일(m=1) 경계 ≈ 0.37 mm, 블렌드(m=1.5) 경계 ≈ 0.25 mm.

**예측과 판정 (재실행 데이터, 현재 코드)**

- 재실행: `analyze_layer_height.py` 그대로 (램프=허리 r=2, 허리 r=3, 구) → 진짜 오버행 %p.
  serene-cray exp2 (수정 전) 와 나란히 적는다 — 판정이 바뀐 칸을 센다.
- 추가 측정 `report_fig_layer_blend.py`: 같은 세 모델 × 층고 0.20 · 0.25 · 0.30 · 0.35 · 0.40 · 0.45 · 0.50,
  밴드2 프로필의 낙관 미지지 mm 를 **블렌드 층(닫힌 식 lo − r·tanθ₁ ≤ z ≤ hi − r·tanθ₂) 안/밖**으로 가르고,
  블렌드 안 미지지 점의 m(점별 `spacing_factor`)을 잰다. 균일(J) 프로필도 같은 층고로 잰다.
- **판정 F1**: 밴드2 를 쓰는 모델(밴드가 실제로 둘로 갈린 모델)마다 블렌드 안 미지지가
  h ≤ 0.30 에서 ≤ 0.5mm 이고 h = 0.40 에서 > 0.5mm 이면 "경계식이 0.4mm 의 실패를 설명한다".

- **판정 F2**: 블렌드 안 미지지 점의 m 중앙값이 1.0 보다 크다 (팽창 자리에서 실패한다). 아니면 적는다.
- **판정 F3 (반증 조건)**: 블렌드 안 미지지가 h ≤ 0.30 에서도 0.5mm 를 넘는 모델이 있으면 "수평 폭 경계만으로는
