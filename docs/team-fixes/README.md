## 이 패치가 고치지 않은 것 (결정이 필요한 것)

- **LC·C축 범위** — slicer(`conical/rep5x.py`: LC 1.6mm, C ±360° 되감기) 와
  `FIBR3DEmul-Rep5x`(LC 0mm, C 연속 회전)가 다르다. 어느 쪽이 맞는지는 조립한 기계의
  실제 펌웨어 설정으로 정해야 해서 손대지 않았다.
- **발표 구성** — 10분 기준 새 장 A(가변각이 균일을 넘는 조건)·B(두 연구가 만나는 곳)
  추가, 2장 삭제, 12장 부록화 제안은 통합 검토 문서에만 있다. 디자인 규칙은 재혁이 정한다.
