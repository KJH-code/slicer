## 2. 본문 상세

### 국문 초록 (400자 내외) 초안
> 원뿔 슬라이싱은 층을 원뿔면으로 쌓아 서포트 없이 오버행을 출력하는 방법으로, 곡면
> 슬라이싱보다 자유도가 작아 계산이 가볍고 방사 대칭 형상에 효과적이다. 그러나 원뿔각은
> 지금까지 사용자가 정해 왔다. 본 연구는 STL 의 면 법선에서 서포트 필요 여부를 닫힌 식으로
> 판정하고, 이를 바탕으로 원뿔각과 높이 구간별 각도를 자동으로 결정하는 알고리즘을 제안한다.
> 각도를 높이에 따라 바꿀 때 층이 교차하거나 벌어지지 않는 조건을 유도해 알고리즘에 넣었다.
> 축대칭 17개 모델에서 [대표 결과 — 기준선 결정 후], 구간 수를 늘린 최선해는 단조 감소함을
> 보였다. 판정식은 독립 구현과 10⁻¹⁴° 수준에서 일치했고, 퇴적 복원 IoU 는 반복 실행에서
> 재현되었다.

주제어: 원뿔 슬라이싱, 원뿔각 자동 결정, 가변 원뿔각, 서포트 저감, 다축 3D 프린팅

### Ⅱ. 이론적 배경 (2.5p)

**1. 원뿔 변환** (RotBot 차용, 식만) — 변환 → 평면 슬라이스 → 역변환. [Fig. 1]

**2. 증명 A — 판정식** (0.7p)
- 축을 지나는 단면에서 원뿔 층의 위쪽 방향 = 수직을 바깥으로 θ 돌린 벡터 (sinθ, cosθ)
- 면 법선과 내적: g(θ) = n_z·cosθ + n_r·sinθ, 서포트 필요 ⇔ g < −sin45°
- 법선이 단면 안에 있으면 **유효 오버행 = 원래 오버행 − θ** (예: funnel 70.3° → 26° 에서 44.3°)
- 면별 임계각 θ* = 원래 오버행 − 45° (일반 면은 합성 공식, 각주)
- 의미: 변환된 메시를 다시 재지 않아도 된다. 변환 공간에서 재면 틀리는 이유(비등각) 한 줄
- (⏸ A′) 서포트 면적은 θ* 들에서만 바뀌는 계단함수 → 유한 후보만으로 정확한 최적

**3. 증명 B — 층간격과 가역성** (0.7p)
- 층 k: z = Z′ₖ − r·tanθₖ. 같은 r 에서 이웃 층의 간격 = **h − r·(tanθₖ₊₁ − tanθₖ)**
- 간격 > 0 ⇔ 층이 교차하지 않음 / 간격 ÷ h = 층간격 배율 m / m ≤ 1.5 ⇒ 블렌드 최소 폭
- θ 가 아니라 **tanθ 를 보간하는 이유**: 식에 들어가는 양이 tanθ → 블렌드 안 간격 일정
- 상수각(RotBot)이면 간격 ≡ h → 이 제약은 가변각에서만 생긴다 = 이 연구의 확장
- [Fig. 2] 램프 밴드2 의 층 단면(블렌드 구간의 층 벌어짐)

**4. 압출 보정** (결과식만, 3줄) — 역변환 시 압출량 × cos²θ·m (부피비, 방향 무관). 어느 압출
모형이 실물과 맞는지는 실물 시험(L4)으로 판정한다고 한 줄.

**4.5 경량성** — 각도 결정 시간: 모델당 2~45ms (해석식). S4 시간(⏸)과 비교

### Ⅴ. 고찰 (1p)
1. 자동 결정이 주는 이득의 원천: 바닥 각도 선택 vs 구간 분할의 고유 효과(기울기 절감)
2. 원뿔족의 적용 범위: 방사 대칭에서 천장 도달, 수평 아래면(mushroom)은 곡면의 영역 — 가정 E(iii)
3. 한계: 축대칭 표본, 기하 판정(중력·냉각 없음), 기계 값 추정, 실물 0건(⏸)
