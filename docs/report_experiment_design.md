# 보고서용 실험 설계 — 형상 적응형 원뿔 슬라이싱은 **균일 원뿔**을 이기는가

2026-11-10. R&E 최종 보고서의 '실험' 장을 이 문서 하나로 쓸 수 있게 짰다.
`experiment_plan.md`(실물 첫 출력 계획)와 `verification.md`(지금까지의 계산 결과)를
**보고서 형식(가설 → 변인 → 절차 → 판정 기준 → 결과 표)**으로 다시 묶은 것이고,
빠져 있던 두 가지를 더했다 — **일반화(보류 모델) 실험**과 **실물 실험의 반복·블라인드 평가**.

> 프린터 상태와 관계없이 보고서가 완결되도록 **두 트랙**으로 나눴다.
> 실험 1~3 은 계산만으로 지금 끝낼 수 있고, 실험 4 는 프린터가 돌면 얹는다.
> 실험 4 를 못 하면 **"판정 불가, 이 실험이 판정할 것"** 으로 쓰고 끝낸다 — 그것도 결론이다.

## 0. 연구 질문과 가설

**연구 질문.** STL 을 분석해 높이별로 원뿔 각도를 바꾸는 가변각(밴드) 슬라이싱이,
모델 전체에 각도 하나를 쓰는 **균일 원뿔**보다 서포트가 필요한 오버행을 줄이는가?
줄인다면 **어떤 형상에서, 어떤 가정 아래에서** 그런가?

⚠ 비교 기준은 평면이 아니라 **균일 원뿔**이다(CLAUDE.md 규칙 2). 평면 행은 표에
'참고'로만 넣고, 평면 대비 감소율은 이 연구의 성과로 쓰지 않는다.

| | 가설 | 이 가설이 틀렸다고 판정하는 관찰 (결과 보기 전에 고정) |
|---|---|---|
| **H1** | 높이에 따라 반경이 크게 변하는 **허리형**에서 밴드가 균일보다 오버행이 적다 | 허리형 표본에서 밴드 승 < 패 |
| **H2** | 반경 변화가 매끈한 **구형**에서는 이득이 없다(무승부 또는 패) | 구에서 밴드가 tie 기준을 넘어 승 |
| **H3** | 밴드의 이득은 **지지 모델 가정**과 **층고**에 의존한다 | 낙관/비관 두 모델에서 승패가 모든 층고에서 같다 |
| **H4** | 각도 선택 규칙(J, k)은 **튜닝에 안 쓴 모델**에서도 H1 의 경향을 유지한다 | 보류 모델에서 승률이 튜닝 표본보다 확연히 낮다(아래 4절 기준) |
| **H5** *(실물)* | 실제 출력물의 처짐은 **낙관/비관 중 한쪽** 예측과 맞는다 | 실험 4 판정표 |

H3 은 이미 계산으로 반쯤 나와 있다(17 모델에서 밴드 우세 **11/17 → 0/17**).
보고서에서 이 사실을 **숨기지 말고 중심에 둔다** — 이 연구가 정직하게 말할 수 있는
최대치가 "가정 X 아래에서는 이기고 가정 Y 아래에서는 진다, 그 갈림이 층고 ~0.3mm" 이다.

## 1. 공통 조건 (모든 실험에 고정)

| 항목 | 값 | 근거 |
|---|---|---|
| 판정식 | `analytic.py` 해석식 (`g(θ) = n_z cosθ + d n_r sinθ`, `g < −sin(임계각)`) | 규칙 1. `sweep.py`/`metrics.py` 금지 |
| 측정 지표 | 툴패스 검사기의 **진짜 오버행 %p** (`classify_unsupported`, 희소 인필 위 제외) | 옛 지표는 위로 좁아지는 형상에서 순위를 뒤집었다 |
| 측정 대상 | **실제로 뽑은 G-code** (예측값 아님) | 예측과 툴패스가 어긋난 사례가 있다(`experiment_plan.md` 1-bis) |
| 압출 폭 / 둘레 수 | 0.45 mm / 2 | 내장 슬라이서 기본 |
| 층고 | 실험 1·3: **0.3 mm**, 실험 2: 0.20~0.50 mm 스윕 | 0.3 은 두 지지 모델이 같은 답을 내는 쪽 |
| 임계각·MAX_ANGLE·k·k_blend | `config.py` 현재값을 **실험 시작 커밋 해시와 함께** 기록 | 결과 뒤에 손잡이를 돌리면 사후 튜닝이 된다 |
| 균일 기준각 | 같은 지표로 0°~MAX 를 훑어 고른 **최선의 균일각** | 약한 기준선을 이기는 건 의미가 없다 |
| tie(무승부) 기준 | \|Δ\| < **0.10 %p** | 임의로 정한 값이다. **결과 전에 고정**하고, 0.05·0.20 에서도 승패 수를 같이 보고한다 |

Δ = (밴드 오버행) − (균일 오버행). **음수면 밴드 승.**

## 2. 실험 1 — 형상 의존성 (주 실험, 계산)

**목적:** H1·H2. 어떤 형상에서 밴드가 균일을 이기나.

**독립변인:** 형상. 이미 정의된 17 모델 계열을 쓴다 — 축이 셋이라 '어느 성질이 이득을 만드나'를 분리할 수 있다.

| 계열 | 모델 | 바뀌는 것 |
|---|---|---|
| 대조 | 구 | 허리 없음 |
| 허리 깊이 | 허리 r = 1, 2(=램프), 3, 4, 5, 7 | 목 반경 (r=7 은 허리 없음) |
| 허리 비율 | 허리3 × 1.1, 1.2, 1.3, 1.5, 2 | 세로 늘임 |
| 표면 굴곡 | 허리3 로브 0.1, 0.15, 0.2, 0.3, 0.4 | 둘레 방향 요철 |

**조건(처리):** 평면(참고) · 균일 최선각 · 밴드2 · 밴드 N\*(J 가 고른 수)

**종속변인:** 진짜 오버행 %p (주), 평균 왜곡각 ⟨|θ|⟩, 블렌드 구간 길이, 레이어 수.
3축으로 뽑을 경우 노즐 간섭 %(참고 — `HotendProfile` 이 추정치라 경향만).

**절차**
```
python3 compare_bands.py sphere --waist-sweep        # 허리 깊이 축
python3 analyze_checker_assumptions.py               # 17 모델 전체, 낙관/비관 동시
python3 analyze_j_vs_optimum.py                      # (θ₁,θ₂) 격자 전수 — 대각선 θ₁=θ₂ 가 균일
```

⚠ **균일 기준선을 따로 확인해야 한다.** `compare_bands.py` 의 N=1 행은 **J 가 고른**
균일각이지 오버행이 최소인 균일각이 아니다. 기준선이 약하면 밴드가 쉽게 이긴다.
- 4 대표 모델은 `analyze_j_vs_optimum.py` 격자의 대각선에서 최선 균일각을 읽는다
- 17 모델 전체는 각도를 훑어 낙관값을 직접 잰다 (예: 0~44°, 4° 간격)
  ```
  for a in 0 4 8 12 16 20 24 28 32 36 40 44; do
    python3 conical_slice.py model.stl --angle $a --direction outward --layer-height 0.3 -o out_$a.gcode
    python3 toolpath_check.py out_$a.gcode --layer-height 0.3 --export-json out_$a.json
  done
  ```
  비관값은 CLI 에 옵션이 없다 — `conical.toolpath.check_support(..., require_supported_below=True)`
  를 부르는 짧은 스크립트가 필요하다 (`analyze_checker_assumptions.py` 가 하는 방식).
- J 가 고른 균일각과 최선 균일각이 다르면 **두 행을 다 표에 넣는다.**

**결과 표 (보고서 표 1)**

| 모델 | 평면(참고) | 균일 최선 (θ) | 밴드2 | Δ | 승/무/패 |
|---|---|---|---|---|---|
| 구 | | | | | |
| 허리 r=1 | | | | | |
| … | | | | | |
| **합계** | | | | 중앙값 (범위) | ○승 ○무 ○패 |

**분석:** Δ 를 형상 파라미터(허리 깊이, 비율, 로브)에 대해 그린다 — 이게 보고서의
핵심 그림이다. 17 개는 독립 표본이 아니라 세 계열이므로 p 값 대신 **승/무/패 수와
Δ 의 중앙값·범위**로 보고한다. 부호검정 값을 붙이려면 "계열 내 상관 때문에 참고용"
이라고 단서를 단다.

**판정:** H1 — 허리 계열에서 승 > 패. H2 — 구에서 승이 아님. 지면 진 것으로 적는다.

## 3. 실험 2 — 가정 민감도 (계산)

**목적:** H3. 실험 1 의 결론이 검사기 가정에 얼마나 기대고 있나.

**독립변인 (2요인):**
- **지지 모델** — 낙관(처진 비드도 위층을 받친다, 현재 기본) / 비관(`require_supported_below=True`, 지지된 재료만 지지)
- **층고** — 0.20, 0.25, 0.30, 0.35, 0.40, 0.45, 0.50 mm

**모델:** 램프(허리 r=2), 허리 r=3, 구. (실험 1 의 세 대표)

**통제:** 층고를 바꿀 때 밴드 프로필을 **다시 고르지 않는다** — 층간격 제약이 비율이라
층고에 무관하다. 그래서 바뀌는 것은 층고 하나다. 검사기 `layer_height` 는 같이 맞춘다.

**절차**
```
python3 analyze_layer_height.py
python3 analyze_checker_assumptions.py      # 지지 창 1.2~1.8 스윕 포함
```

**결과 그림 (보고서 그림 2):** 가로 층고, 세로 Δ, 선 두 개(낙관/비관), 모델별 한 칸.
Δ=0 선을 가로지르는 점이 **판정 경계**다.

**이미 알려진 값(재현 대상):** 램프 비관 경계 0.30~0.35 mm, 허리 r=3 은 0.30~0.40 mm,
구는 전 범위 무승부. 낙관 판정은 층고에 거의 둔감.

**판정:** 경계가 다시 나오면 H3 채택 — 보고서 결론은 "층고 ~0.3 mm 이하에서는 두 가정
모두 밴드 승, 그 위에서는 가정에 따라 갈린다" 가 된다.
지지 창(1.2~1.8)을 바꿔도 판정이 그대로인 것도 같은 표에 넣는다 — '검사기와 계획기가
같은 1.5 를 공유한다' 는 비판에 대한 답이다.

## 4. 실험 3 — 일반화 (보류 모델, 계산) ★새로 추가

**왜 필요한가.** 17 모델은 우리가 손으로 설계한 계열이고, k·k_blend 도 이 모델들을
보면서 정했다. 같은 표본으로 고르고 같은 표본으로 평가하면 **과적합**을 못 가린다.
심사에서 가장 먼저 나올 질문이다.

**설계**
1. 실험 1 을 돌리기 전 상태의 `config.py` 를 **동결**한다 (커밋 해시 기록)
2. 튜닝에 쓰지 않은 모델로 같은 비교를 한다:
   - 실물 STL: `examples/funnel.stl` (+ 손에 넣을 수 있는 실제 STL 몇 개 — 화병, 컵, 램프갓처럼 축대칭에 가까운 것. 선정 기준을 **결과 보기 전에** 적는다)
   - 무작위 생성 모델: 팀 저장소 `wjd` 의 `tools/run_random_validation.py` 로 **STL 만**
     만들어 쓴다 (그 도구 자체는 균일각 선택기 검증용이라 밴드 비교를 하지 않는다).
     ```
     python tools/run_random_validation.py --count 30 --seed 20261110 --output-dir results/heldout
     ```
     `cases.jsonl` 의 STL 경로를 이 저장소의 `compare_bands.py <경로>.stl` 에 넣는다.
     시드를 미리 정해 적고, **생성된 모델은 결과가 나빠도 빼지 않는다.**
3. 각 모델에 대해 균일 최선각 vs 밴드2 의 Δ (낙관·비관 둘 다)

**판정 기준 (결과 전에 고정):**
- 보류 표본에서 밴드 승률(낙관)이 튜닝 표본(11/17 ≈ 65%)의 **절반 이하**로 떨어지면 → H4 기각. "규칙이 튜닝 표본에 맞춰져 있다" 로 적는다
- 승패가 형상 성질(허리 유무)로 갈리면 → 실험 1 의 형상 의존성이 **일반화된다** 는 근거

⚠ 무작위 모델은 대부분 허리형이 아닐 수 있다. 그 경우 "무승부가 많다" 는 H2 와
일관된 결과다 — 승률만 보지 말고 **허리 깊이별로 나눠서** 본다.

## 5. 실험 4 — 실물 판정 (프린터가 있을 때)

**목적:** H5. 실험 2 에서 계산으로 못 좁힌 **지지 모델**을 실물로 고른다.
이 실험 하나가 "밴드 우세 주장을 유지하나 / 전면 철회하나" 를 가른다.

**설계: 2×2 요인 + 반복**

| | 균일 24° | 밴드2 [30°, 0°] |
|---|---|---|
| **층고 0.3 mm** | 두 모델 다 → 밴드 승 예측 | |
| **층고 0.4 mm** | 낙관 → 밴드 승 / 비관 → **균일 승** | |

- 모델: 램프. G-code 는 이미 뽑혀 있다 (`examples/lamp_expA_*_lh03/04[_rep5x].gcode`)
- **반복 n = 2** (가능하면 3). 한 번씩만 뽑으면 우연한 실패와 조건 차이를 구분 못 한다 → 최소 8 출력
- **출력 순서 무작위화** — 같은 조건을 연달아 뽑으면 노즐 마모·실 습도 같은 시간 효과가 조건 효과로 섞인다. 순서를 미리 정해(예: 동전/난수) 적어 둔다
- 서포트 **끔**, 재료·온도·속도·냉각 전부 동일, 같은 스풀

**측정 — 블라인드 평가**

출력물 바닥에 코드(A1, B2 …)만 적고, 어느 조건인지 모르는 **팀원 2명**이 독립 평가한다.

| 측정 | 방법 | 대상 구역 |
|---|---|---|
| **처짐 등급 (주)** | 0 깨끗 · 1 비드 늘어짐 보이나 연속 · 2 층 분리/구멍 일부 · 3 무너짐/실패 | 블렌드 구간 z ≈ 16.3~18.7 mm 와 그 위 아래보기 면 |
| 최대 처짐량 | 캘리퍼스 또는 스케일 넣은 사진. 설계 대비 최대 편차 (mm) | 같은 구역 |
| 출력 성공 여부 | 끝까지 갔는가 | 전체 |

사진은 **같은 각도·같은 비스듬한 조명**으로 찍는다. 두 평가자 등급이 갈리면 둘 다 보고한다.

**판정표 (실험 전에 고정 — `experiment_plan.md` 1-bis 와 같다)**

| 관찰 | 결론 |
|---|---|
| 0.3 에서 밴드2 가 나쁨 | **두 지지 모델이 다 틀렸다** — 판정식 자체를 다시 봐야 한다 |
| 0.3 밴드2 좋음, 0.4 에서 밴드2 가 균일보다 **좋음** | **낙관 모델 채택.** 밴드 우세 주장 유지 |
| 0.3 밴드2 좋음, 0.4 에서 밴드2 가 균일보다 **나쁨** | **비관 모델 채택.** 밴드 우세 주장을 0.3 mm 이하로 **한정** |
| 차이가 등급 1 미만 | 이 모델에서는 구별 불가 — 그것도 결과로 적는다 |

**출력 전 필수 (안 하면 기계가 상한다)** — `experiment_plan.md` 0절: 축 부호 눈 확인,
기계 Z 영점/소프트리밋, 핫엔드 실측, 기계 프로파일의 온도·호밍·프라임 값 교체,
`rep5x_check.py` 통과. **첫 출력은 램프가 아니라 작고 싼 시험편으로.**

**(선택) 같은 판에 얹는 싼 실험 — 치수 링:** r = 5, 10, 20, 40 mm 동심 링의 직경을
캘리퍼스로 잰다. 오차가 반경에 비례하면 회전축 분해능/백래시, 일정하면 다른 원인.

## 6. 타당성 위협 — 보고서 '한계' 절에 그대로 쓴다

| 위협 | 어떻게 다뤘나 |
|---|---|
| 약한 기준선(평면)과 비교 | 균일 최선각을 기준으로 한다 |
| 검사기와 계획기가 가정을 공유 | 실험 2 에서 지지 모델·지지 창을 끊어 봤다. 끊으면 결론이 바뀐다는 사실을 그대로 보고 |
| 튜닝 표본으로 평가 | 실험 3 보류 모델 |
| 사후 판정 기준 | 모든 판정 기준·tie 값·시드를 **결과 전에** 이 문서에 고정 (커밋 시각이 증거) |
| 기계 치수가 추정치 | 노즐 간섭 수치는 경향으로만. 실측 전 결론에 쓰지 않는다 |
| 물리(브리징·수축·냉각)가 계산에 없음 | 실험 1~3 의 결론은 '시뮬레이션 경향' 으로만 쓴다. 실험 4 가 유일한 물리 근거 |
| 실물 표본 수가 작음 | 반복 n=2~3, 블라인드 2인 평가. 통계적 유의성은 주장하지 않는다 |

## 8. 보고서 결론의 틀 (결과에 따라 고른다)

- **실험 4 까지 했을 때:** "가변각 원뿔 슬라이싱은 허리형 모델에서 균일 원뿔보다 오버행을 줄인다(○/17, 보류 ○/○). 실물 출력은 ○○ 지지 모델을 지지했고, 따라서 이 이득은 [모든 / 0.3 mm 이하] 층고에서 성립한다."
- **실험 1~3 만 했을 때:** "가변각의 이득은 지지 모델 가정에 달려 있으며(낙관 11/17 승, 비관 0/17 승), 두 가정이 갈리는 경계는 층고 약 0.3 mm 이다. 어느 가정이 맞는지는 계산으로 좁혀지지 않으며, 이를 판정할 실물 실험(5절)을 설계해 G-code 까지 준비했다."
