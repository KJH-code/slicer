# k 스윕 — 각도 비용 k 가 자동 결정의 성패를 어떻게 바꾸는가

> 보고서 초안(`claude/clever-lovelace-6cn1th` `docs/report/report_draft.md`) 식 (7)
> J(θ) = ΔS(θ) − k·|θ| (k = 0.2 %p/°) 의 **k 를 흔든다.** 출발점은 T1 불통과(`docs/test_t1_t4.md` §2):
> 베드 상한이 없으면 고정 45° 가 자동(J)을 이기고, 사후 최적은 30~44° 에 몰리는데 J 는 약 22° 에서 멈춘다.
> **§1 은 k 스윕 결과를 보기 전에 커밋한다.** 결과는 §2 이후에 붙이고, 기대와 반대여도 기준을 고치지 않는다.

## 1. 사전 등록 (결과 보기 전)

### 1.0 공통 (T1 과 같은 것)

- 판정 지표: 툴패스 검사기 A(낙관 지지)의 **미지지 페리미터 길이 mm**, 0.5 mm 안은 무승부.
  측정 경로 `analyze_gap_sample.measure`. 해석식 서포트는 `conical/analytic.py` 하나(`support_fraction`, `support_fraction_profile`).
  `sweep.py`·`metrics.py` 는 쓰지 않는다.
- **재사용**: `t1_conventional_results.json` 의 각도별 툴패스 값(균일 0~44° 2° 격자 + 15·25·45°, 일부 모델의 음수 격자)을

- 팔(k 마다):

  - 자동 밴드2 = `select_banded_j(N=2, k)` / 상한 판은 `select_capped` 의 밴드2
  - 균일(밴드2 아랫각) — 기준선 (b)
  - 고정 15·20·25·45° (k 와 무관, 상한 판에서 25·45 는 실현 불가)
- 선택은 층고와 무관하다(선택기에 층고 입력이 없다). 모델·k·상한 판마다 한 번 고르고 두 층고에서 잰다.
  확인용: k = 0.2 의 선택이 T1 에 기록된 선택과 같아야 한다. 다르면 구현 차이로 적는다.
- **사후 최적(정답지)**: T1 의 후보 집합 ∪ 이 스윕에서 어떤 k 로든 고른 균일각 전부. k 와 무관한 정답지 하나로
  모든 k 의 후회를 잰다(그래야 k 사이 비교가 공정하다). 상한 판은 |θ| ≤ 22.79° 만. 음수 격자 민감도는 T1 §2.4 에서
  판정이 안 바뀐 것을 확인했으므로 여기서는 쓰지 않는다.
- 후회 = 팔의 mm − 사후 최적 mm. 21 모델 중앙값.

### 1.1 질문 (i) — 어느 k 범위에서 자동이 모든 관례각보다 나은가

- 셀·k 마다: **자동 균일의 후회 중앙값 < 실현 가능한 모든 고정각의 후회 중앙값(엄격)** 이면 그 (셀, k) 통과. T1 과 같은 기준이다.
- 보고: 4 셀 모두 통과하는 k 의 집합. 비어 있으면 "그런 k 는 없다" 로 적는다.
- **미리 알고 있는 구조적 제약**: T1 에서 층고 0.4·상한 없음 셀의 고정 45° 후회 중앙값이 **0.0** 이다. 균일 팔의 후회는 ≥ 0 이므로
  자동 균일은 이 셀에서 엄격 기준을 **어떤 k 로도 통과할 수 없다**(기껏해야 동률). 그래서 이 셀은 보조 기준을 하나 더 적는다:
  **보조 (i′)**: 자동 후회 중앙값 ≤ 최선 고정각 후회 중앙값 + 0.5 mm. 판정은 엄격 기준이고 보조는 그 옆에 적는다.
- 자동 밴드2 에도 같은 기준을 따로 적용해 적는다(보조, 밴드2 후회는 음수 가능).
- 예측(적어만 둔다): 상한 없는 셀에서 k 를 줄이면 자동 균일 각이 커져 후회가 줄고, 상한 셀은 k ≤ 0.2 에서 이미 상한 끝이라
  k 를 줄여도 거의 같다. 4 셀 모두 통과하는 k 는 **없을 것**(위 구조적 제약).

### 1.2 질문 (ii) — k → 0 이면 자동이 45° 쪽으로 가는가

- 상한 없는 판, k = 0 에서 자동 균일 각의 21 모델 중앙값과 분포를 k = 0.2 와 나란히 적는다.
- **"45° 쪽으로 간다"** = k = 0 의 중앙값 ≥ 36° 이고, 21 모델 중 사후 최적(층고 0.4, 상한 없음) 과의 차가 ≤ 4° 인 모델이
  k = 0.2 보다 많다. 아니면 "가지 않는다" 로 적고 이유를 해석식 S(θ) 곡선으로 본다.
- 미리 적는 우려: k = 0 이면 J = ΔS 이고 해석식 S(θ) 는 계단함수라 평평한 구간이 길다. 동점이면 선택기는 작은 |θ| 를 고르므로
  "S 가 바닥에 닿는 가장 작은 각" 에서 멈출 수 있고, 그 각이 툴패스 최적(30~44°)보다 작을 수 있다.

### 1.3 교환 곡선 (파레토)

- 층고마다·상한 판마다, x = **모델 평균 |θ| 의 21 모델 평균**(`mean_abs_angle`, 면적 가중), y = **미지지 mm 의 21 모델 합**.
- 고정각 팔: 균일 0~44°(2°) 의 곡선(상한 판은 0~22°). 자동 균일·밴드2: k 마다 점 하나.
- **판정(교환 곡선)**: 자동 점의 y 가 같은 x 에서 고정각 곡선의 선형보간 값보다 **21 × 0.5 = 10.5 mm 넘게 작으면** "같은 평균 기울기 예산에서
  자동이 낫다" (그 k 에서). 10.5 mm 안이면 무승부, 넘게 크면 "진다". x 가 곡선 범위 밖이면 판정하지 않는다.
- 보조: 고정각 중 x 가 자동 이하이면서 y 가 자동 + 10.5 이하인 것이 있으면 자동 점은 "지배당함".
- 합은 큰 모델이 좌우하므로, 모델별로 같은 비교를 한 승/무/패 수(모델마다 자기 평균|θ| 에서 그 모델의 고정각 곡선 보간과 비교, 0.5 mm)를 같이 적는다.
- **암시 k**: `claude/serene-cray-u07dzk` 의 `report/exp5_angle_cost.json` 에서 균일 4~44° 의 출력 시간을 각도에 선형 맞춤해
  '1° 당 분' 을 구하고, k = 0.2 %p/° 를 "서포트 1 %p = 5° = ○분" 으로 번역해 적는다. 0° → 4° 의 시간 점프(5축 전환 고정비)는 기울기에서 뺀다.
  이것은 해석이지 판정이 아니다.

### 1.4 funnel 이 상한 아래에서 0° 를 고르는 원인

가설 H-f: 해석식 S(θ) 는 면이 θ* 를 넘을 때만 변하는 계단함수(초안 식 (4))이고, funnel 의 오버행 면은 θ* 가 모두 상한 22.79° 보다 크다
→ [0, 22.79] 에서 ΔS = 0 → J = −k|θ| → 0°. 반면 툴패스 미지지는 θ 에 따라 연속으로 준다.

확인 항목 (모두 수치로):
1. funnel 의 S(θ) 를 0~44° 0.1° 간격으로 계산 — [0, 22.79] 에서 S 가 상수인가(차 ≤ 1e-9 %p).
2. 오버행 면(0° 에서 서포트 필요)의 θ* 를 **식 (4) 를 따로 옮겨** 계산 — 최소값이 22.79° 보다 큰가, 그리고 S(θ) 가 처음 변하는 각과 일치하는가(±0.1°).
3. 툴패스 미지지 mm(T1 값)가 0~22° 에서 0.5 mm 넘게 줄어드는가.

판정:
- 1·2·3 모두 참 → **H-f 성립, '이진 판정 모형의 한계'** (해석식은 맞게 구현됐고, 지표가 계단이라 상한 아래 개선을 못 본다).
- 2 에서 독립 계산과 S(θ) 의 변화각이 어긋나면 → **구현 결함 후보**로 적고 원인을 찾는다.
- 1 이 거짓(상한 아래에서도 S 가 줄어드는데 0° 를 고름) → k 스케일 문제로 분류.

ring · topopt · armadillo (S³ 데이터셋 모델, `claude/modest-wozniak-rftjyb` 의 `tools/fetch_s3_dataset.sh`·`conical/s3io.py`):
네트워크로 받을 수 있으면 같은 S(θ) 곡선을 계산하고 다음으로 가른다.
- **계단 문제**: [0, 44] 전체에서 ΔS(θ) ≤ 0 (어떤 k 로도 0° 가 최선).
- **k 스케일 문제**: 어떤 θ 에서 ΔS(θ) > 0 이지만 모든 θ > 0 에서 ΔS(θ) < 0.2·θ. 이때 0° 를 벗어나게 하는 임계 k* = max_θ ΔS(θ)/θ 를 적는다.
툴패스는 이 모델들에서 재지 않는다(축비대칭·대형, 검사기 A 의 범위 밖 — 사다리 실험과 같은 이유). 받을 수 없으면 "확인 못 함" 으로 적는다.

### 1.5 사후 민감도 (판정 밖 — 기본 동작은 바꾸지 않는다)

이 절의 결과는 어떤 판정에도 쓰지 않는다. 균일만, 선택을 스크립트 안에서 따로 계산한다(`conical/` 은 건드리지 않는다).
- (A) 연속 대리 지표: 면 유효 오버행각 φ = asin(max(0, −g(θ))) (g 는 식 (2)), C(θ) = 면적 가중 평균 max(0, φ − 45°) [°].
  J_C = (C(0) − C(θ)) − k_C·|θ|, k_C 를 스윕. 고른 각의 후회.
- (B) 모델 정규화 k: J_rel = 100·ΔS(θ)/S(0) − k′·|θ| (그 모델 자신의 서포트 몇 % 를 없앴나). k′ 스윕. 고른 각의 후회.
- 각각 상한 판도 같이(|θ| ≤ 22°).

### 2.2 질문 (ii) — k → 0 이면 45° 쪽으로 가는가: **간다**

상한 없는 판의 자동 균일 각 중앙값: k = 0 **44°**, 0.02 42°, 0.05 40°, 0.1 34°, 0.15 30°, 0.2 22°, 0.3 12°, 0.5 이상 0°.
k = 0 에서 21 중 17 모델이 격자 끝 44° 를 고른다(예외: 구 42°, funnel 26°, torus 40°, mushroom 0°).
사후 최적과 4° 안인 모델 수(층고 0.4, 상한 없음): k = 0.2 **1** → k = 0 **12**. 사전 기준(중앙 ≥ 36°, 근접 모델 증가) 충족.
§1.2 에 적은 우려(계단 S 의 평평한 바닥에서 일찍 멈춤)는 funnel 한 모델에서만 나타났다(26° = θ* 25.26° 바로 위, 툴패스 최적은 45°).
층고 0.3 에서는 k = 0 이 오히려 지나간다 — 사후 최적 중앙이 32° 인데 44° 를 골라 후회 1.7(k = 0.05 의 0.2 보다 나쁘다).

  가장 큰 폭은 0.3·없음 k = 0.2: 같은 평균 23° 에서 미지지 합 **48% 감소**(1133 → 588 mm), 0.4·없음 k = 0.2: **33% 감소**(3118 → 2089).
- 각도를 거의 최대로 쓰는 k ≤ 0.1 에서는 0.4·없음에서 진다 — 고정 40° 가 이 표본·층고의 최적인데 자동은 44° 쪽으로 넘친다(합 1186 vs 573).
  즉 "모델마다 다른 각도" 의 이득은 **각도 예산이 빠듯할 때(중간 k)** 나오고, 예산이 사실상 무제한이면 큰 고정각 하나가 이긴다.
- 상한 0.3 셀의 패배는 funnel 한 모델 탓이다(§3) — funnel 을 빼고 20 모델로 다시 보면 k = 0.2 에서 19.0°, 1150 mm vs 고정 곡선 1564 mm 로 **자동 승**이 된다(참고 계산, 판정 밖).
- 모델별 승/무/패(0.5 mm): 자동 **균일**은 정의상 그 모델의 고정각 곡선 위의 점이라 21/21 무승부다(이 비교는 밴드2 에만 의미가 있다).
  자동 밴드2 는 k = 0.1~0.3 에서 10~19 모델이 자기 고정각 곡선보다 낫고 패는 0~3 모델이다.

### 2.4 암시 k — '1° 당 시간' (`analyze_k_time.py` → `k_time_results.json`)

exp5 (REP5X G-code, 층고 0.3) 균일 4~44° 출력 시간의 선형 기울기: 램프 0.525, 허리 r=3 0.531, 구 0.636 분/° (평균 **0.56 분/°**, 4° 시간의 2.3~2.9 %/°).
0° → 4° 점프 15.0~16.6 분은 5축 전환 고정비라 기울기에서 뺐다.

J 의 k 를 이 기울기로 번역하면 "해석식 서포트 1 %p 를 없애는 데 낼 수 있는 출력 시간":
k = 0.2 → **2.8 분**, 0.15 → 3.8 분, 0.1 → 5.6 분, 0.05 → 11.3 분, 0.02 → 28 분.
§2.1 의 통과 범위 k ∈ [0.05, 0.15] 는 "서포트 1 %p ≈ 4~11 분" 에 해당한다. 서포트 1 %p 를 실제로 찍는 시간·제거 비용은 재지 않았으므로
**이 번역은 k 를 고르는 근거가 아니라 k 의 단위를 사람이 읽을 수 있게 한 것**이다.

## 3. funnel 이 상한 아래에서 0° 를 고르는 원인 (`analyze_k_funnel.py` → `k_funnel_results.json`, `funnel_cap.png`)

### 3.1 사전 확인 항목 — H-f **성립**

1. S(θ) (0~44°, 0.1°): **[0, 22.79°] 에서 51.514 % 로 상수**(차 0). ✔
2. funnel 의 오버행 면(0° 에서 면적 51.5 %) **전부가 같은 θ* = 25.26°** 를 갖는다(식 (4) 를 따로 옮긴 계산). S(θ) 가 처음 변하는 각 25.3° 와 일치,

### 3.2 가설의 '연속' 부분은 틀렸다 (사후 관찰, 판정 밖)

과제 설명과 가설에 쓴 "툴패스 미지지는 θ 에 따라 연속으로 준다" 는 funnel 에서 **사실이 아니다.** 툴패스도 계단이다(그림 (b)):
층고 0.3 은 16° → 18° 에서 966 → 27 mm, 층고 0.4 는 28° → 30° 에서 504 → 10 mm 로 한꺼번에 떨어진다.
벽의 평면 오버행각 φ₀ = θ* + 45° = 70.26° 로 환산하면 검사기 A 의 **실효 임계각이 층고 0.3 에서 약 53°, 0.4 에서 약 41°** 다.
즉 어긋남의 본질은 "이진 대 연속" 이 아니라 **해석식의 고정 45° 문턱과 검사기의 층고 의존 문턱의 위치 차**다:
- 층고 0.3: 툴패스는 18° 에서 풀리는데(상한 안) 해석식은 25.26° 에서야 풀린다(상한 밖) → 상한 판에서 0° 를 골라 **734 mm 를 놓친다.**
- 층고 0.4: 툴패스도 30° 에서야 풀린다(상한 밖) → 해석식의 0° 는 크게 틀리지 않다(0° 942 vs 사후 최적 6° 523 mm; 그 차는 계단이 아닌 잡음성 변동).
- 면 64 개짜리 얕은 원뿔이라 모든 오버행 면이 한 각도에서 같이 풀린다. 면 방향이 다양한 다른 모델에서는 계단이 많이 겹쳐 곡선이 매끈해 보일 뿐이다.

### 3.3 ring · topopt · armadillo — **k 스케일 문제** (계단 문제 아님)

S³ 데이터셋(github.com/zhangty019/S3_DeformFDM @ a77ef04 의 `.tet`, 저장소 밖에 받음, 해석식만):

| 모델 | S(0) % | 최대 ΔS (%p) @ θ | k* = max ΔS/θ | k 별 자동 균일 각 (0 / 0.02 / 0.05 / 0.1 / 0.15 / 0.2) | 분류 |
|---|---|---|---|---|---|
| ring | 12.45 | 3.14 @ 22° | **0.164** @ 16° | 22 / 22 / 22 / 16 / 16 / **0** | k 스케일 |
| topopt_new4 | 19.16 | 3.14 @ 44° | **0.097** @ 18° | 44 / 44 / 22 / **0** / 0 / 0 | k 스케일 |
| armadillo4 | 11.08 | 4.04 @ 44° | **0.153** @ 6° | 44 / 44 / 44 / 8 / 6 / **0** | k 스케일 |

- 세 모델 모두 ΔS(θ) > 0 인 각이 있지만 모든 θ 에서 ΔS < 0.2·θ 라 k = 0.2 에서 0° 가 최선이다. k* 가 0.10~0.16 이므로 **k ≤ 0.05 면 셋 다 0° 를 벗어난다.**
- 즉 funnel(계단 위치)과 S³ 모델(각도 비용 크기)은 **다른 원인**이다. S³ 모델의 ΔS 곡선은 매끈하게 올라가지만 1° 당 이득의 최대(k* = 0.10~0.16 %p/°)가
  k = 0.2 보다 작다 — 오버행 면적 비율이 큰 데모 모델에서 맞춘 k 가 이 모델들의 '1° 당 서포트 이득' 보다 크다.
  (참고: `verification.md` 의 "큰 모델" 이라는 표현은 정확하지 않다. 크기가 아니라 **1° 당 ΔS 의 크기**가 문제다 — S 는 면적 비율이라 크기에 불변이다.)

## 6. 보고서에 넣을 문장 (초안)

1. 각도 비용 k 를 0~1 %p/° 로 바꿔 21 모델·층고 2·베드 상한 유무 4 조건에서 다시 고른 결과, **4 조건 모두에서 관례 고정각(15·20·25·45°)보다 후회 중앙값이 엄격히 작은 k 는 없었다**; 베드 상한이 없으면 고정 45° 의 후회가 0 에 가까워 자동은 기껏해야 동률이며, 동률을 허용하면 k = 0.05 하나만 네 조건을 모두 통과했다.
2. 현재 값 k = 0.2 는 베드 상한이 있을 때만 관례각을 이겼고, 상한이 없는 조건에서는 k = 0.05~0.15(층고 0.3)가 자동을 사후 최적의 1 mm 안으로 데려왔다 — k 가 작아질수록 자동 균일각의 중앙값은 22° 에서 44° 로 커졌다.
3. 같은 평균 기울기 예산에서 비교하면 모델마다 다른 각도를 고르는 자동 결정이 한 각도를 모든 모델에 쓰는 것보다 미지지가 적었다(k = 0.2, 평균 23°: 층고 0.3 에서 48 %, 0.4 에서 33 % 감소). 다만 각도를 거의 제한 없이 쓰는 k ≤ 0.1 에서는 고정 40° 가 더 나았다.
4. funnel 이 베드 상한 아래에서 0° 를 고르는 것은 구현 결함이 아니라 판정 모형의 한계다: funnel 의 오버행 면은 전부 같은 임계각 25.26° 를 가져 상한 22.79° 아래에서 해석식 서포트가 변하지 않지만, 툴패스 검사기의 실효 임계각은 층고 0.3 에서 약 53° 라 18° 에서 이미 풀린다.
5. ring·topopt·armadillo 에서 0° 를 고르는 것은 다른 원인이다 — 이 모델들의 1° 당 서포트 감소(최대 0.10~0.16 %p/°)가 k = 0.2 보다 작아서다. k 를 출력 시간으로 번역하면 k = 0.2 는 "서포트 1 %p = 약 2.8 분", 통과 범위 0.05~0.15 는 "약 4~11 분" 에 해당한다(REP5X 균일각 출력 시간 기울기 0.56 분/°).
