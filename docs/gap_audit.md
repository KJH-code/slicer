## 1. 판정식이 재는 것 — 층 기준인가, 중력 기준인가

### 기하

outward 원뿔 층은 `z = Z′ − r·tanθ(Z′)`. 층 법선과 층 면(내리막) 방향은

```
b = sinθ·r̂ + cosθ·ẑ        t = cosθ·r̂ − sinθ·ẑ
```

`analytic.py:41-53` 의 g = n·b 는 **면 법선과 층 법선의 내적**이다. 서포트 필요 ⟺
층 기준 오버행각 α_L = asin(−g) > 45°. **식에 중력이 없다.** 층고·압출폭·층간격 배율도 없다.

이웃 두 층에서 벽이 옮겨가는 양을 층 좌표로 쓰면 (t_n = h·m·cosθ 는 층 법선 방향 두께)

```
D = u·t + t_n·b,      u = t_n·tanα_L        ← 비드가 층 면을 따라 밀리는 양
```

### 어느 프레임이 맞나

| 물리 | 맞는 프레임 | 근거 |
|---|---|---|
| 새 비드 밑에 앞 층이 있는가(접착) | **층(=노즐 축)**. REP5X 는 B=θ(Z′) 라 노즐 축이 −b | 비드는 노즐 축 방향으로 눌린다. 다축 선행연구(S³ 등)의 '국소 출력 방향' 기준과 같은 정의 |
| 못 받친 부분이 처지는 방향 | **중력** | 부품이 고정이고 헤드가 기운다 |

즉 식의 프레임은 접착에 대해서는 옳다. 그러나 고정 κ 는 **평면 출력에서 온 수**이고,
평면에서는 아래 셋이 전부 자동으로 성립했다. 원뿔에서는 아니다.

**(a) 중력이 층에 수직이 아니다 — 헤드 틸트식에서만.**
층 좌표에서 중력은 `−g·cosθ·b + g·sinθ·t`. 층을 누르는 성분은 줄고(24° 0.91g, 30° 0.87g,
44° 0.72g), 층 면을 따라 **바깥으로 끄는 성분**이 생긴다(0.41g, 0.50g, 0.69g). outward 원뿔이
구제하는 면은 바깥을 보는 오버행이므로, 이 성분은 **구제되는 면의 자유단 쪽**을 향한다 —
부호가 체계적으로 불리하다. 베드 틸트식(Open5x)에서는 이 항이 0 이다. **같은 G-code 가
두 기계에서 다른 물리를 겪는데 예측식은 구별하지 못한다.**
크기는 계산으로 모른다. 비드 규모 본드 수는 약 0.06(ρ≈1100, γ≈0.035N/m, L=0.45mm —
문헌값 대입 어림, 미검증)이라 접착이 중력을 이긴다는 쪽이 유력하고, RotBot(45° 기운
노즐, 직립 부품)이 층 기준으로 출력한 것도 같은 쪽 근거다(원문 재확인 안 함).
→ **실물로만 갈린다.** 지금 실험 A 에는 이걸 가를 대조군(평면 0°)이 없다.

**(b) 층 두께가 다르다.** 45° 규칙의 실체는 '한 층에 비드가 폭의 몇 % 밀리나' 다
(u/w). 같은 밀림을 주는 한계각은 `tanα* = tan45°/(m·cosθ)`:

| | 균일 24° | 균일 30° | 균일 44° | 블렌드 m=1.5 | 실제 m=2.6 | 압축 m=0.67 |
|---|---|---|---|---|---|---|
| 한계각 α* | 47.6° | 49.1° | 54.3° | 34.6° | 23.5° | 57~60° |
| 고정 45° 대비 | 보수적 | 보수적 | 보수적 | **낙관적** | **낙관적** | 보수적 |

**(c) 45° 가 뜻하는 겹침이 층고마다 다르다.** 45° 에서 못 받친 폭은 h/w — 층고 0.3 에서
67%, 0.4 에서 89%. 층고 0.4·폭 0.45 에서 고정 45° 는 낙관적이다.

### G2 — 압출량

역변환의 체적 야코비안은 `cos²θ·m` 이다(유한차분과 상대오차 2.4e-10 으로 일치). 방향과
무관하다. `backtransform.py` 가 의도한 보정은 `실길이/변환길이`(둘레 cosθ, 반경 1)라
그 자체로 1/cosθ ~ 1/cos²θ 만큼 많다. 그런데 **그 보정조차 걸리지 않는다**:

```python
dE = (mv.e - e_prev)      # backtransform.py:86 — mv.e 는 입력 절대 E
...
e_prev = acc              # :131 — acc 는 출력(보정된) 절대 E
```

입력에서 출력을 빼므로 앞 이동에서 줄인 양이 다음 이동에 도로 붙는다. 누적으로는 상쇄된다.

|---|---|---|---|---|---|

## 8. 살아남는 것

* 변환·역변환의 기하(왕복 오차, 층 = 각도 하나짜리 원뿔), 블렌드 폭 하한의 **유도**.
  틀린 것은 r 을 조회한 높이다.
* 예측식의 프레임(층 법선)은 노즐이 층에 수직인 기계에서 접착 판정으로 옳다.
* 페리미터 경로의 현 오차(≤ 0.024mm).
* "밴드는 같은 오버행을 더 작은 평균 각도로 낸다" — 메시 예측에서는 어떤 문턱에서도 성립.
  다만 그 '같은 오버행' 을 주는 균일각과 비교해야 하고(J1), 각도의 값어치가 정해져야 한다(J2).
