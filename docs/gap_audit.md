## 1. 판정식이 재는 것 — 층 기준인가, 중력 기준인가

### 기하

outward 원뿔 층은 `z = Z′ − r·tanθ(Z′)`. 층 법선과 층 면(내리막) 방향은

```
b = sinθ·r̂ + cosθ·ẑ        t = cosθ·r̂ − sinθ·ẑ
```

`analytic.py:41-53` 의 g = n·b 는 **면 법선과 층 법선의 내적**이다. 서포트 필요 ⟺
층 기준 오버행각 α_L = asin(−g) > 45°. **식에 중력이 없다.** 층고·압출폭·층간격 배율도 없다.

이웃 두 층에서 벽이 옮겨가는 양을 층 좌표로 쓰면 (t_n = h·m·cosθ 는 층 법선 방향 두께)

```
D = u·t + t_n·b,      u = t_n·tanα_L        ← 비드가 층 면을 따라 밀리는 양
```

### 어느 프레임이 맞나

| 물리 | 맞는 프레임 | 근거 |
|---|---|---|
| 새 비드 밑에 앞 층이 있는가(접착) | **층(=노즐 축)**. REP5X 는 B=θ(Z′) 라 노즐 축이 −b | 비드는 노즐 축 방향으로 눌린다. 다축 선행연구(S³ 등)의 '국소 출력 방향' 기준과 같은 정의 |
| 못 받친 부분이 처지는 방향 | **중력** | 부품이 고정이고 헤드가 기운다 |

즉 식의 프레임은 접착에 대해서는 옳다. 그러나 고정 κ 는 **평면 출력에서 온 수**이고,
평면에서는 아래 셋이 전부 자동으로 성립했다. 원뿔에서는 아니다.

**(a) 중력이 층에 수직이 아니다 — 헤드 틸트식에서만.**
층 좌표에서 중력은 `−g·cosθ·b + g·sinθ·t`. 층을 누르는 성분은 줄고(24° 0.91g, 30° 0.87g,
44° 0.72g), 층 면을 따라 **바깥으로 끄는 성분**이 생긴다(0.41g, 0.50g, 0.69g). outward 원뿔이
구제하는 면은 바깥을 보는 오버행이므로, 이 성분은 **구제되는 면의 자유단 쪽**을 향한다 —
부호가 체계적으로 불리하다. 베드 틸트식(Open5x)에서는 이 항이 0 이다. **같은 G-code 가
두 기계에서 다른 물리를 겪는데 예측식은 구별하지 못한다.**
크기는 계산으로 모른다. 비드 규모 본드 수는 약 0.06(ρ≈1100, γ≈0.035N/m, L=0.45mm —
문헌값 대입 어림, 미검증)이라 접착이 중력을 이긴다는 쪽이 유력하고, RotBot(45° 기운
노즐, 직립 부품)이 층 기준으로 출력한 것도 같은 쪽 근거다(원문 재확인 안 함).
→ **실물로만 갈린다.** 지금 실험 A 에는 이걸 가를 대조군(평면 0°)이 없다.

**(b) 층 두께가 다르다.** 45° 규칙의 실체는 '한 층에 비드가 폭의 몇 % 밀리나' 다
(u/w). 같은 밀림을 주는 한계각은 `tanα* = tan45°/(m·cosθ)`:

| | 균일 24° | 균일 30° | 균일 44° | 블렌드 m=1.5 | 실제 m=2.6 | 압축 m=0.67 |
|---|---|---|---|---|---|---|
| 한계각 α* | 47.6° | 49.1° | 54.3° | 34.6° | 23.5° | 57~60° |
| 고정 45° 대비 | 보수적 | 보수적 | 보수적 | **낙관적** | **낙관적** | 보수적 |

**(c) 45° 가 뜻하는 겹침이 층고마다 다르다.** 45° 에서 못 받친 폭은 h/w — 층고 0.3 에서
67%, 0.4 에서 89%. 층고 0.4·폭 0.45 에서 고정 45° 는 낙관적이다.

### G2 — 압출량

역변환의 체적 야코비안은 `cos²θ·m` 이다(유한차분과 상대오차 2.4e-10 으로 일치). 방향과
무관하다. `backtransform.py` 가 의도한 보정은 `실길이/변환길이`(둘레 cosθ, 반경 1)라
그 자체로 1/cosθ ~ 1/cos²θ 만큼 많다. 그런데 **그 보정조차 걸리지 않는다**:

```python
dE = (mv.e - e_prev)      # backtransform.py:86 — mv.e 는 입력 절대 E
...
e_prev = acc              # :131 — acc 는 출력(보정된) 절대 E
```

입력에서 출력을 빼므로 앞 이동에서 줄인 양이 다음 이동에 도로 붙는다. 누적으로는 상쇄된다.

|---|---|---|---|---|---|

## 8. 살아남는 것

* 변환·역변환의 기하(왕복 오차, 층 = 각도 하나짜리 원뿔), 블렌드 폭 하한의 **유도**.
  틀린 것은 r 을 조회한 높이다.
* 예측식의 프레임(층 법선)은 노즐이 층에 수직인 기계에서 접착 판정으로 옳다.
* 페리미터 경로의 현 오차(≤ 0.024mm).
* "밴드는 같은 오버행을 더 작은 평균 각도로 낸다" — 메시 예측에서는 어떤 문턱에서도 성립.
  다만 그 '같은 오버행' 을 주는 균일각과 비교해야 하고(J1), 각도의 값어치가 정해져야 한다(J2).

### 10.1 무엇을 쟀나

**프로필 족** (전부 outward, tanθ 선형 블렌드): `θ(Z′) = 22° (Z′ ≤ z0) → 블렌드(폭 w) → θ_top`.
θ_top ∈ {0, 10, 20, 24, 28, 32, 36, 40}°, z0 ∈ {0.3, 0.6, 1.0, 2.0}mm. θ_top < 22° 는 '아래가 높고 위가 낮은'
밴드와 같은 방향(팽창 블렌드, m > 1), θ_top > 22° 가 올라가는 램프(압축 블렌드, m < 1)다.

* **폭 w = 계획기가 허용하는 최소 폭.** `profile._required_width` 와 같은 규칙(바닥값 0.5mm, 가역성 여유
  1.5·r_max·Δtan, 층간격 배율 m ∈ [1/1.5, 1.5], 반경은 `RadiusProfile.max_in_slab`)이고, 블렌드의 중심이 아니라
  **시작점 z0 을 고정**한다는 것만 다르다. 만든 프로필 전부가 `check_spacing` 을 통과한다(위반 0).
* **베드 상한**: 프로필이 `bed_safe_profile` 을 **그대로 통과**해야 이 기계에서 쓸 수 있다. 통과 못 한 칸은
  '베드 불가' 로 적고 재지 않았다(§10.2).

**항상 같이 잰 팔**

**지표** (팔마다, 층고 0.3·0.4, 17 모델): 검사기 A 진짜 오버행의 mm·%p 를 **두 프레임**으로 —
연직(기본, §9 와 같은 경로)과 공구(`layer_frames` → `check_support(tool_up=, layer=)` →
`classify_unsupported(tool_up=, layer_thickness=)`. `support_breakdown` 의 `overhang_pct` 와 같은 수다).
그리고 평균|θ|, 실제 m 의 최대·최소, t_n, 블렌드의 Z′ 구간과 실공간 z 구간, 미지지 길이의 위치.

**압축 효과를 떼는 법 — 'm 보정 창'** (§1 (b)). 검사기 A 의 창은 고정이다(수평 ≤ 압출폭 w, 수직 (0, 1.5h]).
압축 블렌드의 층은 m̄ 배로 얇아서 같은 벽 기울기가 한 층에 m̄ 배만큼만 옆으로 밀린다 — 각도 덕이 아니라
층이 얇아서 창을 통과하는 몫이 섞인다. 그래서 **창을 그 점의 m̄ 으로 줄인(팽창이면 늘린) 판정**을 같이 냈다:
수평 ≤ w·m̄, 수직 (0, 1.5h·m̄]. "그 층이 같은 각도의 균일 원뿔 두께였어도 통과했겠는가" 와 같은 물음이다
(통과 조건이 두 프레임 모두 m 에 비례한다, §1). 균일 팔은 m ≡ 1 이라 두 판정이 같다.

* m̄ = (그 점의 층과 **바로 아랫층** 사이의 실제 수직 간격) ÷ 층고 = `1 − r·(T(Z′) − T(Z′−h))/h`. 미분 배율
  m = 1 − r·s 가 아니다. 블렌드의 첫 층은 아랫층이 블렌드 밖이라 미분 m 보다 덜 얇다 — 폭 0.5mm 블렌드는 층
  두 개가 전부라 이 차이가 결과를 바꾼다(처음에 미분 m 으로 쟀다가 고쳤다).
* 층 두께는 **세는 쪽**에도 들어 있다. 미지지 '길이' 는 고리를 세므로, 같은 높이 구간이라도 층이 얇으면
  고리가 많아 길이가 늘고 두꺼우면 준다. 그래서 m 보정 창에는 **층고 환산 길이 Σ(길이·m̄)** 도 적었다.
* ⚠ 이 판정이 '옳다' 는 뜻이 아니다. 얇은 층이 실제로 오버행을 더 잘 받는다면 **기본 창이 맞는 쪽**이고,
  그것은 실물로만 갈린다(J5·J7, 사다리 L5 는 층고가 하나라 이 물음을 못 가른다).
* 구현: `toolpath.py` 를 안 건드리고, `check_support` 의 판정 규칙을 m̄ ≠ 1 인 페리미터 점에만 다시 적용한다
  (`support_scaled`).

**검산** (`--selfcheck`, 세 프로필 × 두 프레임, 전부 통과): ① `check_support` 의 배치 크기를 바꿔도 판정이 같다
② 단면 캐시를 끄고 부른 `classify_unsupported` 와 같다 ③ 창 배율 1 로 전 페리미터를 다시 판정하면
`check_support` 와 불일치 0/81,184 점 ④ `support_breakdown` 의 `overhang_pct` 와 같다 ⑤ '바뀔 수 있는 점만
다시 보는' 지름길이 전수 재판정과 같다. 그리고 **§9.3 의 수치가 그대로 나온다**: 그 절의 '균일 요청+램프' 와
'밴드2(상한)' 미지지 길이 68 개(17 모델 × 두 층고 × 두 팔)와 최대 0.05mm 차(반올림)다.

표의 칸은 **승·무·패**(그 팔이 비교 상대보다 미지지 길이가 0.5mm 넘게 짧으면 승). 열 이름의 '연직'·'공구' 는

  22° 이하만 쓰는 팔(밴드2(상한), 내려가는 족)은 기본 창에서 많아야 8 승이다.

  (구 `[20,16]`, 허리 r=7 `[18,16]`, r=5 `[20,2]`, r=3 `[20,0]`).
* **균일 θ_bed\*** — 램프 없이 각만 0.79°(층고 0.3)·1.38°(0.4) 올린 진짜 균일 — 가 균일 22° 를
  16·0·1 / 12·5·0 / 16·1·0 / 17·0·0 으로 이긴다. 모델 중앙값으로 미지지 길이가 0.83·0.84 배(층고 0.3 연직·공구),
  0.96·0.94 배(0.4)다. 1 패는 허리3 ×2 다(293.3 → 310.9mm, 고리 단위 양자화 — G12).
* **자동 램프**는 요청각 다섯 개 모두 17·0·0(연직), 15·2·0(층고 0.3 공구), 17·0·0(0.4 공구)이다.
