**국문 초록**

원뿔 슬라이싱은 층을 원뿔면으로 쌓아 서포트 없이 오버행을 출력하는
방법으로, 곡면 슬라이싱보다 설계변수가 적어 계산이 가볍고 방사 대칭
형상에 효과적이다. 그러나 원뿔각은 지금까지 사용자가 정해 왔다. 본
연구는 STL 의 면 법선에서 서포트 필요 여부를 닫힌 식으로 판정하고, 이를
바탕으로 원뿔각과 높이 구간별 각도를 자동으로 결정하는 알고리즘을
제안한다. 각도를 높이에 따라 바꿀 때 층이 교차하거나 벌어지지 않는
조건을 유도해 알고리즘에 넣었다. 축대칭 17개 모델에서
**<span class="mark">【보류: 대표 결과】</span>**. 구간 수를 늘린
최선해는 단조 감소하였고, 구간 분할의 고유 효과는 같은 서포트에서 평균
기울기를 줄이는 것이었다. 판정식은 독립 구현과 10⁻¹⁴° 수준에서 일치했고,
퇴적 복원 IoU 는 반복 실행에서 재현되었다.

주제어: 원뿔 슬라이싱, 원뿔각 자동 결정, 가변 원뿔각, 서포트 저감, 다축
3D 프린팅

**Ⅰ. 서론**

**1. 연구의 필요성**

FDM(Fused Deposition Modeling) 3D 프린팅은 모델을 수평면으로 잘라
아래층부터 쌓는다. 이때 아래를 향해 일정 각도(관례상 45°) 이상 기운 면은
받쳐 줄 아래층이 없어 서포트가 필요하다. 서포트는 재료와 출력 시간을
늘리고, 떼어 낸 자리의 표면을 손상시킨다. 빌드 방향이 모델 전체에 대해
수직 하나로 고정되어 있다는 것이 이 문제의 원인이다.

다축 3D 프린팅은 출력 방향을 바꾸어 이 문제를 푼다. 곡면
슬라이싱\[3,4\]은 모델 내부의 위치마다 출력 방향을 정하는 방향장을
최적화해 높은 효율을 얻지만, 설계변수가 위치마다 존재해 자유도가 매우
크고 대규모 최적화나 신경망 학습이 필요하다. 원뿔 슬라이싱\[1,2\]은 층
전체를 원뿔 반각 θ 하나로 기술한다. 모델을 원뿔 좌표로 변환한 뒤 평면
슬라이서로 자르고 G-code 를 되돌리면 층이 원뿔면이 되며, 기존 평면
슬라이서를 그대로 쓸 수 있다. 자유도가 작은 대신 방사 대칭인 형상에서
바깥으로 벌어진 오버행을 효과적으로 줄인다(Table 1).

그러나 원뿔각은 지금까지 사람이 정했다. RotBot\[1\]은 45° 틸트 노즐에
맞춘 고정각을 쓰고, 3축 프린터용 원뿔 슬라이서\[5,6\]는 사용자가 15~25°
등의 상수각을 입력한다. CNC Kitchen\[7\]은 구역마다 이상적인 슬라이싱
각도를 자동으로 고르는 알고리즘을 다음 과제로 꼽았다. 조사 범위 내에서,
원뿔 슬라이싱 계열에서 형상으로부터 원뿔각을 자동 결정하고 그 효과를
정량 비교한 연구는 확인되지 않았다.

**2. 연구 목적**

본 연구는 STL 모델에서 원뿔각과 높이 구간별 각도를 자동으로 결정하는
알고리즘을 만들고 다음 세 질문에 답한다. RQ1. STL 만으로 원뿔각을 자동
결정할 수 있는가. RQ2. 그 결정은 믿을 만한가. RQ3. 높이 구간(밴드)의
개수를 늘리면 어떻게 되며, 몇 개를 써야 하는가. 평면 대비 서포트 감소는
원뿔 슬라이싱 일반의 성과이므로, 비교 기준은 평면이 아니라 모델 전체에
각도 하나를 쓰는 균일 원뿔로 한다. 원뿔 변환식은 RotBot\[1\]의 것을
차용하였고, 각도의 자동 결정과 높이별 가변각 및 그 안전 조건이 본 연구가
더한 부분이다.

**Ⅱ. 이론적 배경**

**1. 원뿔 변환**

축(z축)에 정렬한 모델의 점 (r, φ, z)를 다음과 같이 변환한다\[1\]. c = +1
은 꼭짓점이 위인 바깥(outward) 원뿔, c = −1 은 안쪽(inward) 원뿔이다.

R = r / cosθ, φ′ = φ, Z′ = z + c·r·tanθ

변환한 모델을 평면 슬라이서가 Z′ = 상수로 자르고 역변환하면, 각 층은
실공간에서 z = Z′ − c·r·tanθ 인 원뿔면이 된다(\[Fig. 1\]).

**2. 서포트 판정식**

원뿔 층 위에 쌓이는 면이 아래층에 받쳐지는지는 '그 자리 층의 위쪽
방향'과 면 법선의 관계로 정해진다. 축을 지나는 단면(r–z 평면)에서 원뿔
층의 위쪽 단위 방향은 수직 방향을 바깥으로 θ 만큼 돌린 벡터 b = (c·sinθ,
cosθ) 이다. 면 법선 n = (n_r, n_φ, n_z) 과의 내적은 b 에 φ 성분이
없으므로

g(θ) = n · b = n_z·cosθ + c·n_r·sinθ

이다. θ = 0 이면 g = n_z 이고, 평면 슬라이서의 45° 규칙은 'n_z ≥ −sin45°
이면 서포트 불필요'이다. 같은 기준을 기울어진 층에 적용하면 서포트 필요
⇔ g(θ) \< −sin45° 이다. 변환된 메시를 다시 잴 필요 없이 원본 법선만으로
판정할 수 있다.

법선이 단면 안에 있는 면(축대칭 형상의 면)에서 오버행 각을 α(수직면에서
아래로 기운 각)라 하면, 바깥을 향한 면의 법선은 n = (cosα, −sinα) 이다.
대입하면

g(θ) = −sinα·cosθ + c·cosα·sinθ = −sin(α − c·θ)

이므로 c = +1 에서 g ≥ −sin45° ⇔ α − θ ≤ 45° 이다. 즉 **유효 오버행 =
원래 오버행 − θ** 이며, 면이 서포트 없이 서는 최소 각(면별 임계각)은 θ\*
= α − 45° 이다. 안쪽을 향한 면(n_r \< 0)은 같은 계산에서 c = −1 일 때
각이 줄어들므로, 각도와 함께 방향(outward/inward)도 같은 식에서
결정된다. 예를 들어 벽 오버행 70.3° 인 funnel 은 θ = 26° 에서 유효
오버행 44.3° 가 되어 서포트가 필요 없다. 법선이 단면 밖으로 기운 일반
면은 R = √(n_r² + n_z²) 로 g = R·sin(θ + atan2(n_z, c·n_r)) 이 되어 θ\*
= asin(κ/R) − atan2(n_z, c·n_r) (κ = −sin45°) 로 같은 방식으로 풀린다.

한편 원뿔 변환은 XY 를 1/cosθ 배로 늘리는 비등각 사상이라 변환 공간에서
잰 각은 실제 각과 다르다. funnel 의 벽은 변환 공간 45° 기준을 통과하려면
θ = 53° 가 필요하지만 실제로는 26° 로 충분하다. 본 연구가 판정을 해석식
하나로 통일한 이유이다.

**<span class="mark">【보류: 정확 선택 세션 결과에 따라 — 서포트 면적은

비례하는 목적함수의 최적해는 유한 개의 임계각 후보 안에 있다】</span>**

**3. 가변 원뿔각과 층간격**

각도를 높이(Z′)의 함수로 두면 층 k 는 각도 θ_k 하나짜리 원뿔 z_k(r) =
Z′\_k − c·r·tanθ_k 이다. 층고를 h 라 하면, 같은 반경 r 에서 이웃한 두
층의 간격은 두 식의 차로 바로 얻어진다.

Δz(r) = z\_{k+1}(r) − z_k(r) = h − c·r·(tanθ\_{k+1} − tanθ_k)

이 한 식에서 네 가지가 나온다. (1) 모든 r ≤ r_max 에서 Δz \> 0 이어야
층이 서로 교차하지 않는다. (2) Δz / h = m 이 실공간의 층간격 배율이다.
(3) 각도가 바뀌는 블렌드 구간의 폭을 w, tanθ 의 총 변화를 ΔT 라 하고
tanθ 를 Z′ 에 대해 직선으로 바꾸면 층마다 tanθ 변화는 h·ΔT / w 로
일정하므로 m = 1 − c·r·ΔT / w 가 블렌드 전체에서 일정하다. θ 가 아니라
tanθ 를 보간하는 이유가 이것이다. (4) 1/1.5 ≤ m ≤ 1.5 로 두면 블렌드
최소 폭은 층이 벌어지는 쪽에서 w ≥ 2·r_b·\|ΔT\|, 좁아지는 쪽에서 w ≥
3·r_b·\|ΔT\| 이다(r_b: 블렌드가 지나는 높이 구간의 최대 반경).
상수각이면 ΔT = 0 이라 m ≡ 1 이므로, 이 제약은 균일 원뿔에는 없고
가변각에서만 생긴다(\[Fig. 2\]).

**4. 압출량 보정**

평면 슬라이서는 변환 공간에서 '층고 × 비드 폭 × 길이'의 부피를 압출한다.
역변환의 부피비(야코비안)는 방향과 무관하게 cos²θ·m 이므로 역변환 시
압출량에 이 값을 곱한다. 22° 균일 원뿔로 생성한 G-code 에서 벽 1mm 당
압출량 비는 0.9271 로 cos22° = 0.9272 와 일치한다. 이 모형이 실제 비드와
맞는지는 실물 시험(단벽 원기둥 L4)으로 판정한다.

**1. 원뿔각 자동 결정 알고리즘**

알고리즘은 다음 순서로 STL 에서 G-code 를 만든다(\[Fig. 3\]). ① STL 을
읽어 원뿔 축에 정렬한다. ② 모든 면에 대해 Ⅱ.2 의 판정식으로 각도별
서포트 면적을 계산한다. ③ 균일각 결정: 평면 대비 서포트 면적 감소량
ΔS(θ)(%p)에서 각도 비용을 뺀 J(θ) = ΔS(θ) − k·\|θ\| 를 최대로 하는 θ 와
방향을 고른다. k(기본 0.2 %p/°)는 각도 1° 를 서포트 몇 %p 와 바꿀지를
정하는 교환비이다. ④ 구간(밴드) 결정: 높이를 N 개 구간으로 나누어
구간마다 각도를 고르고, 구간 사이 블렌드는 Ⅱ.3 의 최소 폭으로 잡으며
블렌드 면적을 J 에서 비용으로 뺀다. ⑤ 모델을 변환해 평면 슬라이서로
자르고, 역변환하면서 압출량을 보정하고 곡선 경로를 오차 0.05mm 이내로
잘게 나눈다. ⑥ 5축 출력에서는 헤드 틸트 B = θ(Z′), 회전 C = 방위각으로
두고 회전 속도 상한과 베드 안전각(약 22.8°)을 적용한다. ⑦ 내보낸 G-code
는 사전 검사기를 통과해야 출력한다.

**2. 구간(밴드) 개수 (RQ3)**

N 개 구간으로 만들 수 있는 각도 프로필은 N+1 개 구간으로도 만들 수 있다.
한 구간을 같은 각도로 둘로 나누면 되기 때문이다. 따라서 가능한 프로필의
집합이 N 에 대해 포함 관계를 이루고, 그 안의 **최선해**의 서포트는 N 이
늘수록 줄거나 같다. 아래로 유계인 단조 감소 수열이므로 N → ∞ 에서
수렴하며, 그 극한은 높이에 따라 연속적으로 변하는 원뿔각 θ(Z′) 의
최선이다.

측정 결과, 각도 비용을 0 으로 두면 밴드의 해석식 서포트 이득은 같은 아래
구간 각도의 균일 대비 17개 모델 모두에서 0 이었다. 구간을 나누는 것의
가치는 서포트 감소가 아니라 기울기 감소에서 나온다. 또 구간 수 N 을 J 의
크기로 고르면 7개 모델 모두에서 오버행이 달성 가능한 최소보다 나빴다.
따라서 구간 수는 J 로 고르지 않고 지정하거나 최선해 곡선으로 정해야
한다. **<span class="mark">【보류: 최선해 곡선과 포화 구간 수 N\* 분포 —
T3】</span>**

**Ⅴ. 고찰**

첫째, 자동 결정의 이득은 대부분 형상에 맞는 아래 구간 각도를 고르는 데서
나온다. 같은 아래 구간 각도의 균일과 비교하면 구간 분할의 서포트 이득은
사라지고, 남는 고유 효과는 같은 서포트를 더 작은 평균 기울기로 내는
것이다. 기울기가 작으면 노즐 기울임과 회전축 동작이 줄어들지만, 그 실물
가치(표면, 치수, 출력 시간)는 실물 출력으로 확인해야 한다.
**<span class="mark">【보류: 베드 안전각 아래에서 위로 올라가는 가변각의
결과를 넣을지】</span>**

둘째, 원뿔족의 적용 범위는 방사 대칭 형상이다. 구, funnel, torus 에서
구간 분할은 원뿔족의 천장에 도달했지만, 수평 아래면을 가진 mushroom 은
원뿔족으로 풀 수 없었다. 이는 원뿔을 곡면 층의 1차 근사로 보는 가정이
층의 휨이 클 때 깨진다는 것과 일치한다. 자유도를 줄인 대가가 어디에서
나타나는지를 형상으로 구분할 수 있다는 뜻이다.

셋째, 한계가 있다. 표본이 축대칭 형상이고, 판정은 45° 문턱의 기하
판정으로 중력·처짐·냉각을 반영하지 않는다. 5축 기계의 핫엔드 치수와 베드
안전각은 공개 자료에서 얻은 추정값이며, 실물 출력 결과는 아직 반영되지
않았다.

**Ⅵ. 결론**

본 연구는 원뿔 슬라이싱의 원뿔각을 STL 에서 자동으로 결정하는 알고리즘을
만들었다. RQ1: 원본 면 법선만으로 서포트를 판정하는 해석식을 유도하고,
이를 이용해 원뿔각과 방향, 구간별 각도를 자동으로 결정하였다.
**<span class="mark">【보류: 기준선 결정 후 대표 결과 한 문장】</span>**
RQ2: 판정식은 독립 구현과 일치했고, 선택한 각도의 G-code 는 퇴적
복원에서 재현되었다. RQ3: 구간 수를 늘린 최선해는 단조 감소하며, 구간
분할의 고유 효과는 기울기 감소이다. 구간 수는 J 로 고르지 말고 최선해
곡선으로 정해야 한다. 향후 제작한 5축 프린터로 사전 등록한 시험 출력을
수행하고, 곡면 슬라이싱과의 정량 비교와 비축대칭 형상으로 연구를 넓힐
것이다.
