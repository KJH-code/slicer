# 연구 요약 — 형상 적응형 원뿔 슬라이싱 (2026-11-10)

이 저장소의 현재 상태를 한 장으로 정리했다. 세부 근거는 각 줄의 링크에 있다.

- **실물 출력: 0건.** 아래의 수치는 전부 계산이고, 검증 수단은 툴패스 검사기·독립 구현·가상 프린터다
- 표기: **[확정]** 코드·테스트로 고정됨 · **[조건부]** 가정에 따라 바뀜 · **[추정]** 실기 확인 전 · **[철회]** 틀린 것으로 밝혀짐

## 1. 무엇을 하나

원뿔 슬라이싱의 각도를 **높이마다 다르게(가변각 θ(Z′))** 자동으로 정한다. 비교 기준은 평면이 아니라 **균일 원뿔**(모델 전체에 각도 하나, RotBot 방식)이다. 균일을 못 이기면 진 것으로 적는다.

파이프라인: STL → 축 센터링 → 각도 결정 → 정변환 → 평면 슬라이싱 → 역변환 → 5축 변환(REP5X) → 검사

## 2. 이론 — 무엇이 서 있나

| 내용 | 상태 | 근거 |
|---|---|---|
| 판정식 `g(θ) = n_z·cosθ + d·n_r·sinθ`, 서포트 ⟺ g < −sin45° | [확정] 구현 일치 (재유도 3회, 팀원 독립 구현 1.42e-14°) | `conical/analytic.py`, `docs/verification.md` |
| 판정식의 기준축은 층 법선이다. 노즐이 층에 수직인 기계(REP5X)에서 **접착** 판정으로는 옳다. 다만 헤드가 기울면 중력이 층 면을 따라 바깥으로 끄는 성분(24°에서 0.41g)이 생기는데, 식에는 없다 | [조건부] | `docs/gap_audit.md` §1, G10 |
| 가변각은 tanθ를 Z′에 대해 선형 보간한다. 가역성 `c·r·s < 1`, 층간격 배율 m ∈ [1/1.5, 1.5] | [확정] | `conical/profile.py` |
| 블렌드 반경은 블렌드가 **실제로 차지하는 실공간 높이 구간** 전체에서 찾는다 (2026-11-10 수정, G1). 예전에는 높이 하나에서만 찾아서, 명목 1.5인 실제 m이 2.6이었다 | [확정] | `conical/meshio.py`, `tests/test_blend_spacing.py` |
| 압출 배율은 역변환의 야코비안 `cos²θ·m` (G2). 예전에는 보정이 상쇄돼 늘 1.000배였다 → 균일 24°에서 1.198배 과압출 | [확정] 유도 + 유한차분 검증. 실물 확인은 [추정] | `conical/backtransform.py`, `tests/test_backtransform_extrusion.py` |
| 평가함수 `J = ΔS − k·평균|θ| − k_blend·P_blend` | [조건부] 선형 가중합이라 볼록 껍질의 꼭짓점만 고른다. 정규화 방식(G13)과 형태는 미정 | `conical/varangle.py`, `docs/gap_audit.md` J10 |

## 3. 결과 — 무엇이 남고 무엇이 무너졌나

| 주장 | 상태 |
|---|---|
| 밴드는 균일과 같은 오버행을 평균 각도 약 15° 적게 낸다 (메시 예측) | [조건부] 메시 예측으로는 어떤 문턱에서도 성립한다. **단 "같은 오버행을 주는 균일각"과 비교해야 한다** (G4·J1) |
| 밴드 우세 11/17 모델 (균일 24°와 비교) | [조건부 → 사실상 철회] 밴드2의 아랫각과 같은 균일 원뿔과 비교하면 동률 16, 균일 우세 1, **밴드 우세 0** (G4). 우세의 원인은 밴드가 아니라 아랫각이다 |
| 표본(축대칭 17개)에 "각도 하나로 못 푸는" 모델이 없다 | [확정] 각도 비용을 0으로 두면 균일과 이상적 밴드의 예측이 17/17 같다 (G5) |
| 연쇄(비관) 지지 모형을 켜면 밴드 우세가 0 | [조건부] 비관 모형이 퇴화해 있다. 페리미터 미지지 99.6~99.8%, 즉 전체 붕괴를 예측한다 (G7) |
| funnel은 inward가 유리 | [철회] 왜곡공간 45° 판정의 산물 (`sweep.py`·`metrics.py`, 레거시) |

한 줄로: **"부위별 각도가 균일 원뿔을 이긴다"는 지금 표본과 지표로는 서지 않는다.** 남는 것은 두 가지다. 같은 오버행을 더 작은 평균 틸트로 낸다는 것, 그리고 그 틸트 절감에 실물 가치가 있느냐는 질문(J2)이다.

## 4. 실물 출력 준비 — REP5X (Ender-3 V3 SE)

기계 규약은 `docs/rep5x_machine_facts.md` (REP5X·REP5X-Marlin 소스를 직접 읽음).

2026-11-10에 이전 실험 A 파일에서 **치명 결함 6개**를 찾아 생성기와 검사기를 함께 고쳤다:

| 결함 | 고친 곳 |
|---|---|
| G28 직후 B=−135°(호밍 자세)인 채 프라임하고 G43.4를 켬 | `profiles/rep5x_ender3v3se.ini`: B0 C0 복귀 → 프라임 → 원점 선언 → B0 C0에서만 TCP 켜기 |
| 기계 원점이 베드 모서리인데 경로를 (0,0) 둘레로 냄. 범위 밖의 회전 이동은 펌웨어가 조용히 버림 | 베드 중앙 native (100,100) [추정] + 검사기가 native 범위를 봄 |
| F가 팁 XYZ에만 적용돼 축 근처 C 급회전이 46,305°/s를 요구 | `limit_rotary_speed`: 회전 상한(기본 90°/s)으로 F를 깎음 |
| 기운 노즐 몸통이 베드를 침 (공식 충돌 모델 기준 팁이 베드면일 때 한계 약 22.8°) | `bed_safe_profile`: 바닥 쪽 각도를 B_safe로 제한. `--strict`를 주면 낮추지 않고 멈춤 |
| 이동 줄 주석이 M668 SD 전처리를 깨뜨림 | 이동 줄 형식 고정 + 검사 |
| 되감기 끝 자세가 C 창 밖에 떨어짐 (351.7 → −368.3°) | `add_c_rewinds`가 직전 C를 판정 범위에 넣음 |

이것과 별도로, 축을 감싸는 링을 번갈아 돌려 C 누적을 줄였다 (되감기 80 → 35회, flare 15°).

검증 층:
- 검사기 C: `rep5x_check.py`
- 팀 가상 프린터의 역기구학과 축 한계: `tools/fibr3d_crosscheck.py` (독립 구현)
- 단위 테스트 203개, ruff 0건

**첫 실험은 `docs/experiment_plan.md` 「R」 사다리** (L0 공중 시운전 → L1 평면 원기둥 → L2p/L2 평면 대조와 원뿔 15° → L3a/L3b 균일 22° 대 밴드 22→0°). 전부 10~20분이고 예측과 판정 기준을 미리 적어 두었다. 예전 실험 A(램프 30° 대 24°)는 베드 충돌 한계 때문에 실기에서 대비가 성립하지 않아 다시 설계했다.

## 5. 아직 모르는 것 — 실기에서 정할 값

| 값 | 왜 중요한가 |
|---|---|
| LB (출처별 47.9 / 52.87 / 54.67), LC | G-code는 LB에 의존하지 않는다. 검사기의 joint Z와 베드 간섭이 LB에 의존한다 → `M665` |
| 베드 중앙 native 좌표 | 틀리면 부품이 베드 모서리 쪽으로 간다 |
| 축 부호 (B+ / C+ 방향) | 반대면 노즐이 반대로 기운다 → L0 |
| 핫엔드 실측 형상 | B_safe(약 22.8°)가 여기서 나온다. 지금 값은 공식 뷰어 모델 [추정] |
| 갠트리가 Z<0까지 내려가나 | 기울이면 joint Z가 −3.7mm까지 간다 (L3). 라이브 TCP는 리밋을 팁에 걸어 막지 않는다 |
| 회전 상한 | L2·L3는 180°/s로 뽑았다. L0에서 흔들림을 보고 정한다 |

## 6. 연구자 판단이 필요한 것

`docs/gap_audit.md` §7의 J1~J11. 그중 다음 실험을 바꾸는 것:

- **J1** 균일 기준선을 무엇으로 할까: J 최선 균일인가, 같은 아랫각의 균일인가
- **J2** 평균 틸트를 줄이는 것의 실물 가치는 무엇인가: 표면, 시간, 치수 중 어느 것인가
- **J3** 판정 모델을 바꿀까: 바닥을 평평하게 하거나, 각도 하나로 못 푸는 형상을 추가
- **J10** 목적함수의 형태와 정규화
- **J11** 압출 배율: 야코비안으로 바꿔 두었다. 비드가 붙는 내부에서는 부피가 맞지만, **단독 벽은 수평 두께가 w·cosθ로 얇아진다** (22°에서 7.3%). 사다리 L4a/L4b의 벽 두께 비로 가린다: 0.927이면 야코비안, 1.000이면 길이 비가 맞다
- **J5·J7** 사다리 L5(오버행 각도 40~65°)가 이 기계의 문턱을 준다. 해석식은 50° 단부터 실패를, 검사기 A는 60° 단부터 실패를 예측한다
