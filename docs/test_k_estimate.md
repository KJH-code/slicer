# k 추정 — 데이터에서 k 를 '결과로' 뽑고, 그 값이 믿을 만한지 따로 검증한다

> 앞 시험(`docs/test_k_sweep.md`)은 k 9 개를 **판정**했을 뿐 k 를 **추정**하지 않았다. 같은 21 모델로 고르고 같은 21 모델로
> 평가했으므로 "k = 0.05 만 통과" 는 표본 안 결과이고 불확실성이 없다. 이 시험은 k 를 출력으로 내는 추정량을 정하고,
> 신뢰구간과 **표본 밖(held-out) 검증**으로 그 값을 믿을 수 있는지 판정한다.
>
> **정직 메모**: 이 문서는 k 스윕 결과(셀별 통과 범위 0.05~0.15 등)를 **본 뒤에** 쓴다. 그래서 이 사전 등록이 막는 것은
> "추정 결과를 보고 추정 규칙·신뢰 기준을 고치는 것" 이다. k 의 대략적 위치는 이미 알고 있다 — 그래서 판정을 표본 밖 검증에 건다.
> §1 은 추정 결과를 보기 전에 커밋한다.

## 1. 사전 등록

### 1.0 데이터 (새 측정 최소화)

- 표본·층고·베드 상한·검사기·무승부 폭은 T1 / k 스윕과 같다(21 모델, 0.3/0.4, 상한 없음/22.79°, 검사기 A 낙관 미지지 mm, 0.5 mm).
- 툴패스 값: `t1_conventional_results.json` + `k_sweep_cache/`. 고른 각이 아직 안 잰 각이면(음수 격자 등) 그것만 새로 잰다.
- 해석식 S(θ): `k_sweep_cache/sel_*.json` 의 부호 있는 격자 S (`support_fraction`, 판정식 `analytic.py`).
- 사후 최적(정답지)·후회 정의는 k 스윕 §1.0 과 같다(정답지 후보 = T1 후보 ∪ 이 시험에서 고른 균일각).

### 1.1 추정 대상과 추정량

- 대상: **자동 균일(J) 의 k** — 기준선 (a). 밴드2 는 추정에 쓰지 않고 §1.4 에서 확인만 한다(밴드2 선택은 k 마다 수 초라 촘촘한 격자에 못 쓴다).
- k 격자: **0.005 ~ 0.5, 0.005 간격 (100 값)**. k = 0 은 뺀다(J 가 평평해 동점 처리 규칙이 결과를 정한다).
- 각 k 의 균일 선택은 S(θ) 에서 J(θ) = ΔS(θ) − k|θ| 를 부호 있는 격자(±0~44°, 2°)에서 최대화해 다시 계산한다
  (상한 판은 |θ| ≤ 22°, `select_capped` 와 같은 동점 규칙). **확인**: k 스윕의 0 아닌 k 8 개에서 `select_banded_j(N=1)`·`select_capped` 의
  실제 선택과 21 모델 × 2 판 모두 같아야 한다. 하나라도 다르면 그 차이를 적고 실제 선택기 쪽을 믿는다.
- 손실: L(k) = Σ_{4 셀} median_{모델}(후회 mm). (T1 판정 지표인 후회 중앙값을 4 셀 합한 것.)
- 점 추정: **k̂_min** = argmin L (동점이면 큰 k — 각도를 덜 쓰는 쪽).
- 권장 추정: **k̂_1SE** = L(k) ≤ L(k̂_min) + SE 인 k 중 가장 큰 값 (1-표준오차 규칙). SE = 모델 부트스트랩에서 L(k̂_min) 의 표준편차.
  "손실이 통계적으로 구별 안 되면 각도를 덜 쓰는 k" 를 고르는 보수적 규칙이다.
- 층고별 추정도 따로 낸다: k̂(0.3) = 0.3 두 셀만, k̂(0.4) = 0.4 두 셀만으로 같은 규칙.

### 1.2 불확실성

- 모델 부트스트랩 B = 2000 (seed 0): 21 모델을 복원추출 → k̂_min, k̂_1SE 재계산 → 2.5~97.5 백분위 **95% 구간**.
- 가족 묶음 부트스트랩(민감도): 모델은 독립이 아니다(허리 r 6 개, 허리3 배율 5 개, 로브 5 개가 서로 닮았다). 가족 5 개
  {구, 허리 r=*, 허리3 ×*, 허리3 로브*, 데모 4} 를 단위로 복원추출한 구간도 같이 적는다.

### 1.3 표본 밖 검증 (판정의 핵심)

- **가족 제외 교차검증(LOFO, 5 겹)**: 한 가족을 빼고 나머지로 k̂_1SE 를 고른 뒤, 뺀 가족의 모델에서 그 k 의 후회를 잰다.
  5 겹의 held-out 후회를 모아 셀마다 중앙값을 낸다. 같은 모델에서 고정 15·20·25·45° 와 k = 0.2 의 후회 중앙값과 비교한다.
- 모델 하나 제외(LOO, 21 겹)도 같은 방식으로 적는다(보조).

### 1.4 '신뢰할 만한 k' 판정 기준

k̂_1SE (전체 표본) 를 **"신뢰할 만하다"** 고 쓰려면 셋 다 성립해야 한다:

- **(R1) 정밀도**: 모델 부트스트랩 k̂_1SE 의 95% 구간 폭 ≤ **0.10** %p/°.
- **(R2) 안정성**: LOFO 5 겹에서 고른 k̂_1SE 가 모두 (R1) 의 95% 구간 안에 든다.
- **(R3) 표본 밖 성능**: LOFO held-out 후회 중앙값이 **4 셀 모두** 최선 실현 가능 고정각의 후회 중앙값 + 0.5 mm 이하
  (T1 보조 기준 (i′) 의 표본 밖 판). 엄격 기준(고정각보다 작음)도 같이 적는다.

결과 문구:
- 셋 다 성립 → "k = k̂_1SE (95% 구간 [a, b]) 는 이 표본·검사기 기준으로 신뢰할 만하다."
- (R1)·(R2) 만 → "k 값은 안정적으로 추정되지만 표본 밖에서 관례각을 이기지 못한다."
- (R1) 또는 (R2) 실패 → "이 데이터로는 k 를 하나로 정할 수 없다" 와 그 이유(층고 의존 / 가족 의존)를 적는다.
- **층고 의존 판정**: k̂(0.3) 과 k̂(0.4) 의 모델 부트스트랩 95% 구간이 겹치지 않으면 "k 는 층고에 따라 다르다" 로 적는다.
- k = 0.2 판정: k = 0.2 가 k̂_1SE 의 95% 구간 밖이면 "현재 기본값은 데이터와 맞지 않는다" 로 적는다. (기본값은 바꾸지 않는다.)

### 1.5 확인 · 해석 (판정 밖)

- **밴드2 확인**: k̂_1SE 에서 `select_banded_j(N=2)` 와 `select_capped` 밴드2 를 실제로 돌려 재고, 셀별 후회 중앙값을 고정각과 나란히 적는다.
- **외부 제약**: S³ 3 모델(ring·topopt·armadillo)의 k* = 0.164 / 0.097 / 0.153 (`k_funnel_results.json`). k̂ 가 k* 보다 작으면 그 모델에서 0° 가 아닌 각을 고른다.
  툴패스는 없으므로 '0° 를 벗어나는가' 만 적는다.
- **비용 포함 k̂(λ)**: 손실을 L_λ(k) = Σ_셀 median(mm + λ·평균|θ|) 로 바꿔 λ ∈ {0, 1, 2, 5, 10, 20} mm/° 마다 k̂_min 을 적는다.
  λ 는 "1° 를 미지지 몇 mm 와 바꾸겠나" 이다. 이 값은 데이터가 아니라 사용자가 정할 값이므로 판정에 쓰지 않는다.
- 이 시험의 k 는 **'검사기 A 의 미지지 mm 를 가장 잘 따라가는 해석식 J 의 k'** 이다. 출력 시간·표면 품질 같은 각도 비용은
  손실에 없다(λ = 0). 그래서 추정값은 각도를 쓰는 쪽으로 치우친다 — 이것을 결론에 함께 적는다.

## 2. 결과 (`analyze_k_estimate.py` → `k_estimate_results.json`, 그림 `docs/report/figures/k_estimate.png`)

실행 1.1 분. 새 툴패스 측정 0 개(필요한 각도는 전부 T1·k 스윕 캐시에 있었다), 밴드2 확인만 새로 골랐다.
**확인**: S(θ) 로 다시 계산한 균일 선택이 k 스윕의 0 아닌 k 8 개 × 21 모델 × 2 판에서 실제 선택기와 **모두 같다**(불일치 0).

### 2.1 추정값

| 추정 대상 | k̂_min | **k̂_1SE** | 모델 부트스트랩 95% (k̂_1SE) | 가족 부트스트랩 95% | 손실 L(k̂) / L(0.2) (mm) |

| 4 셀 전체 | 0.055 | **0.060** | **[0.055, 0.080]** | [0.050, 0.085] | 0.0 / 61.8 |
| 층고 0.3 두 셀 | 0.105 | **0.115** | [0.085, 0.160] | [0.085, 0.185] | 0.0 / 15.7 |
| 층고 0.4 두 셀 | 0.055 | **0.060** | [0.055, 0.080] | [0.050, 0.085] | 0.0 / 46.1 |

k̂_1SE = 0.06 에서 셀별 후회 중앙값(표본 안): 0.3·없음 0.0, 0.3·상한 0.0, 0.4·없음 0.17, 0.4·상한 0.0 mm.
4 셀 합 손실이 0.06 근처에서 거의 0 으로 떨어지는 구간은 좁다 — 0.4·상한 없음 셀이 k = 0.065 부터 후회가 생기고(0.08 에서 3.4 mm),
0.3·상한 없음 셀은 k ≤ 0.05 에서 각도를 너무 많이 써 후회가 생긴다(0.02 에서 1.7 mm). 그 사이의 창이 k ≈ 0.055~0.06 이다.

가족 제외(LOFO) 5 겹에서 고른 k: **0.06, 0.07, 0.075, 0.075, 0.06**. 모델 제외(LOO) 21 겹: 0.06~0.07.

| 0.3 · 없음 | **0.0** | 0.0 | 15.7 | 48.3 / 35.2 / 13.8 / 1.6 | ✔ | ✔ |
| 0.3 · 상한 | **0.0** | 0.0 | 0.0 | 18.9 / 5.7 / — / — | ✔ | ✔ |
| 0.4 · 없음 | **1.9** | 1.5 | 43.3 | 84.9 / 66.4 / 57.7 / **0.0** | ✘ | **✘** (45° 0.0 + 0.5 초과) |

표본 밖에서 고른 k(0.07~0.075)가 표본 안 최적(0.06)보다 조금 크고, 0.4·상한 없음 셀은 그 0.01~0.015 차이에 1~2 mm 씩 반응한다.

### 2.3 판정 (사전 등록 §1.4 그대로)

| 기준 | 결과 |
|---|---|
| (R1) 정밀도: 95% 구간 폭 ≤ 0.10 | **통과** — [0.055, 0.080], 폭 0.025 |
| (R2) 안정성: LOFO 겹별 k 가 구간 안 | **통과** — 0.06~0.075 |
| (R3) 표본 밖: 4 셀 모두 최선 고정각 + 0.5 mm 이하 | **불통과** — 0.4·상한 없음 1.9 mm vs 고정 45° 0.0 mm (나머지 3 셀은 엄격 통과) |
| 층고 의존 | **있다** — k̂(0.3) 95% [0.085, 0.160] 와 k̂(0.4) [0.055, 0.080] 가 겹치지 않는다 |
| k = 0.2 | **95% 구간 밖** — 현재 기본값은 이 데이터와 맞지 않는다 |

**결론 문구(사전 등록)**: "k 값은 안정적으로 추정되지만(k̂ = 0.06, 95% 구간 0.055~0.08) 표본 밖에서 관례각을 모두 이기지는 못한다."
그리고 **k 는 층고에 따라 다르다** — 층고 0.3 만 보면 k̂ = 0.115 [0.085, 0.16], 0.4 만 보면 0.06 [0.055, 0.08].
4 셀 합으로 낸 0.06 은 사실상 '층고 0.4 의 값' 이다(0.4 셀들의 mm 가 커서 손실을 지배한다).

### 2.4 확인 · 해석 (판정 밖)

- **밴드2 @ k = 0.06** (실제 선택기로 다시 고르고 잼): 후회 중앙 0.0 / 0.0 / 0.2 / 0.0 mm (셀 순서 0.3·없음, 0.3·상한, 0.4·없음, 0.4·상한).
  표본 안 값이지만 4 셀 모두 최선 고정각 + 0.5 mm 안이다.
- **S³ 3 모델**: k = 0.06 은 ring(0.164)·topopt(0.097)·armadillo(0.153) 의 k* 보다 작아 셋 다 0° 를 벗어난다(툴패스 미측정).
- **각도 비용을 넣으면**: L_λ 로 고른 k̂ 는 λ = 0 → 0.055, 1 → 0.07, 2 → 0.14, 5 → 0.365, 10·20 → 0.5(격자 끝).
  현재 k = 0.2 는 "평균 기울기 1° 를 미지지 약 2~5 mm 와 바꾼다" 는 가치판단과 맞는다. 즉 **k = 0.2 는 데이터가 아니라 λ 를 정해야 나오는 값**이다.
- 이 추정의 k 는 '검사기 A 의 미지지 mm 를 가장 잘 따라가는 J 의 k' 이고 출력 시간·품질 비용은 0 으로 둔 값이라 각도를 쓰는 쪽(작은 k)으로 치우친다.
  0.4·상한 없음 셀에서 표본 밖 1~2 mm 를 지는 것도, 각도를 거의 최대로(44° 쪽) 써야 이기는 셀이기 때문이다.

### 2.5 '신뢰할 만한 k' 에 대한 답

- 이 데이터가 말하는 k 는 **약 0.06 (95% 구간 0.055~0.08)** 이고, 표본을 흔들거나 모델 가족을 하나씩 빼도 0.06~0.075 에 머문다 — **값 자체는 안정적이다.**
- 그러나 사전 기준으로는 **"신뢰할 만한 단일 k" 라고 쓸 수 없다.** (1) 층고 0.3 의 최적(약 0.115)과 0.4 의 최적(약 0.06)이 통계적으로 다르고,
  (2) 표본 밖에서 층고 0.4·상한 없음 조건의 고정 45° 를 이기지 못한다.
- 보고서에 쓸 수 있는 정직한 문장: "미지지만 기준으로 하면 k 는 0.06 근처(층고 0.4)~0.1 근처(층고 0.3)이고, 현재 기본값 0.2 는 두 구간 모두 밖이다.
  0.2 는 각도 1° 를 미지지 2~5 mm 와 바꾸는 비용 가정에 해당한다."
- 실물 기계(REP5X, 베드 상한 22.79°)에 해당하는 상한 셀 둘만 보면 k = 0.005~0.18 전 구간에서 후회 0 이라 k 선택에 둔감하다 — 기계에서는 k 를 0.06 으로 낮춰도 0.2 와 결과가 거의 같다.
