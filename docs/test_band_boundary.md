## 1. 사전 등록 (결과 보기 전, 2026-11-10)

### 1.0 공통

- 표본: T4 와 같은 21 모델 (`analyze_t1_conventional.all_specs()`), 선택기 설정도 T4 와 같다
  (`select_banded_j`, k=0.2, k_blend=0.1, 격자 ±0~44° 2°, 임계각 45°, 층간격 한계 1.5).
- 사전에 이미 아는 것(정직): T4 원자료(`t4_robustness_results.json`)와, 구 하나를 손으로 돌려 본 결과
  **구는 세분화 전후 가운데 경계가 10.00mm 로 같고 바깥 끝(면 중심 z 최소·최대)만 0.073→0.036mm 로 움직인다**는 것.
  즉 "가운데 경계 후보가 면 중심 높이에 의존" 하는 것만으로는 구의 변화를 설명하지 못할 수 있다.
  그래서 원인을 아래처럼 **세 경로로 나눠** 확인한다.

### 1.1 원인 조사 (할 일 1)

`select_banded_j` 가 메시에 기대는 경로는 세 가지다.

| 경로 | 무엇 | 메시 의존 |
|---|---|---|
| (E) 경계 | `assign_height_bands`: edges = linspace(면 중심 z 최소, 최대) | 경계 위치와 프로필 양 끝(블렌드가 쓸 자리 `room_lo/hi`)이 면 크기에 따라 움직인다 |
| (S) 출발점 | 밴드별 독립 최선각(`best_angle_for_mask`)을 면 중심 라벨로 고른다 | 경계를 걸친 면의 소속이 쪼개면 바뀐다 → 좌표하강의 출발점이 바뀐다 |
| (Q) 구적 | J 의 서포트·평균|θ|·블렌드 면적을 **면 중심 한 점**의 θ 로 센다 | 블렌드를 걸친 면이 쪼개지면 적분값이 바뀐다 (이산화 오차 — 세분화하면 참값에 가까워진다) |

실험 (재현 대상 = T4 에서 세분화 ×4 로 밴드2 각이 바뀐 모델 전부, 그중 >2° 인 4 모델을 주 대상으로):
1. 원본 / 세분화 메시에서 edges, 출발점, 최종 각도, J 를 적는다.
2. **절제(ablation)**: 세분화 메시에서 선택을 다시 하되 (a) edges 를 원본 메시의 것으로 고정, (b) edges + 출발점을 원본 것으로 고정.
3. 원본 각도와 세분화 각도의 J 를 **세분화 메시에서** 둘 다 잰다 (ΔJ).

**분류 기준**:
- **결함 (E 또는 S)**: (a) 또는 (b) 에서 각도가 원본으로 돌아온다 → 메시 의존 경계/출발점이 원인.
  형상이 같은데 경계가 움직이는 것은 J 가 평평하든 아니든 **결함**으로 적는다 (경계는 형상의 함수여야 한다).
- **정상적 동점 깨기**: (b) 에서도 각도가 바뀌고, ΔJ ≤ 0.4 %p(= k × 격자 한 칸) 이다 → Q 의 작은 이산화 차이가
  평평한 J 위에서 argmax 를 옮긴 것.
- **구적 결함 의심**: (b) 에서도 바뀌고 ΔJ > 0.4 %p.
- 한 모델에 여러 원인이 겹칠 수 있다 — 그대로 적는다.

### 1.2 옵션 수정 (할 일 2)

- `assign_height_bands(mesh, n_bands, edges_from="centroid")` 와 `select_banded_j(..., band_edges="centroid")` 에
  옵션 **`"bounds"`** 를 추가한다: edges = linspace(정점 z 최소, 최대) = 메시 bounds = `RadiusProfile.z0/z1`.
  중점 분할·면 수와 무관하다(형상의 높이 범위). **기본값은 `"centroid"` 그대로** — 기존 결과·테스트는 바뀌지 않는다.
- 조사 결과 (S) 가 주원인이면 출발점도 메시 독립으로 만드는 옵션을 같은 이름 아래 추가할 수 있다
  (예: 출발점 각도를 면 라벨 대신 bounds 경계로 '면을 자르지 않고' 정하는 방식). 추가하면 무엇을 바꿨는지 §2 에 적는다.
  (Q) 는 이번 수정 범위 밖이다.
- 회귀 테스트: 수정 옵션에서 세분화 ×4 전후 **edges 가 1e-9 안에서 같다** (구·허리·funnel 등 대표 모델).

**재측정**: T4 의 해상도·정렬 교란 6 개(세분화 ×4, 단순화 ×0.5, 중심 0.1·0.5mm, 기울임 1°·3°)에서 밴드2 를
기본(centroid) / 수정(bounds) 두 판으로 다시 고른다. 기본 판은 T4 숫자와 같아야 한다(재현 확인).

**지표**:
- |Δθ| ≤ 2° 인 모델 비율 (T4 와 같은 정의, max_i |Δθᵢ|).
- **J 손실** = J_orig(θ_원본) − J_orig(θ_교란) : 교란 메시에서 고른 각도를 **원본 메시**(같은 판의 edges)에서 평가했을 때 J 가
  얼마나 줄었나 (%p). 모델별 값, 중앙값·최대, ≤ 0.4 %p 인 모델 수.
- 툴패스 검사기 A 미지지 mm: 원본 메시에서 기본 판·수정 판 밴드2 (층고 0.3·0.4) — 수정이 품질을 깎는지.
  교란 메시의 mm 는 각도가 바뀐 경우만 재고 T4 처럼 Δmm 중앙값을 적는다.

**사전 기준**:
1. **세분화 결함 해소**: 수정 판에서 세분화 ×4 의 edges 가 21/21 같고, 밴드2 |Δθ| ≤ 2° 가 **21/21** 이면 "해소".
   |Δθ| = 0 이 21/21 이면 "완전 해소". 아니면 남은 모델과 그 원인(1.1 분류)을 적는다.
2. **부작용 없음**: 다른 교란 5 개 각각에서 수정 판의 ≤2° 모델 수가 기본 판보다 **2 개 넘게 줄지 않는다**.
   (견고하다고 주장하는 기준은 T4 와 같이 축의 모든 교란에서 ≥ 90% — 이번에도 같은 문장으로 적는다.)
3. **품질 비열등**: 원본 메시에서 수정 판 밴드2 의 미지지 mm 가 기본 판보다 0.5mm 넘게 나빠지는 모델이
   층고마다 **21 중 2 개 이하**. 넘으면 "수정이 품질을 깎는다" 로 적는다.
4. 기본값을 바꿀지는 이 문서에서 판정하지 않는다 (옵션 추가까지만).

### 1.3 작은 Δθ 밴드 병합 — 민감도 (할 일 3, **사후 · 판정 밖**)

- `claude/serene-cray-u07dzk` 의 `report/README.md` 실험 3 은 **결과를 본 뒤** 나온 관찰이다(보류 구 두 개가 26°→24° 를 골라
  비관 지지에서 졌다). 그래서 이 절은 판정이 아니라 민감도다.
- 규칙: 밴드2 결과 |θ₁ − θ₂| < 4° 이면 밴드를 버리고 **자동 균일(J, N=1) 해**로 바꾼다. 문턱 2°·4°·6° 를 나란히 적는다.
- 대상: serene-cray 실험 3 의 rand:5, rand:10 (생성 규칙은 그 브랜치 `report_experiments.random_model` 을 그대로 옮긴다,
  시드 20261110) + 이 표본의 구·sphere. 판정 계량은 이 브랜치의 것(검사기 A 낙관 mm, 비관 mm 는 참고)으로 다시 잰다 —
  serene-cray 의 %p 표와 단위가 다르다는 것을 적는다.
- 21 모델 표본에서 이 규칙이 몇 모델의 밴드를 지우는지와, 지운 모델의 mm 변화도 적는다.
