### 1.1 원인 조사 (할 일 1)

`select_banded_j` 가 메시에 기대는 경로는 세 가지다.

| 경로 | 무엇 | 메시 의존 |
|---|---|---|
| (E) 경계 | `assign_height_bands`: edges = linspace(면 중심 z 최소, 최대) | 경계 위치와 프로필 양 끝(블렌드가 쓸 자리 `room_lo/hi`)이 면 크기에 따라 움직인다 |
| (S) 출발점 | 밴드별 독립 최선각(`best_angle_for_mask`)을 면 중심 라벨로 고른다 | 경계를 걸친 면의 소속이 쪼개면 바뀐다 → 좌표하강의 출발점이 바뀐다 |
| (Q) 구적 | J 의 서포트·평균|θ|·블렌드 면적을 **면 중심 한 점**의 θ 로 센다 | 블렌드를 걸친 면이 쪼개지면 적분값이 바뀐다 (이산화 오차 — 세분화하면 참값에 가까워진다) |

실험 (재현 대상 = T4 에서 세분화 ×4 로 밴드2 각이 바뀐 모델 전부, 그중 >2° 인 4 모델을 주 대상으로):
1. 원본 / 세분화 메시에서 edges, 출발점, 최종 각도, J 를 적는다.
2. **절제(ablation)**: 세분화 메시에서 선택을 다시 하되 (a) edges 를 원본 메시의 것으로 고정, (b) edges + 출발점을 원본 것으로 고정.
3. 원본 각도와 세분화 각도의 J 를 **세분화 메시에서** 둘 다 잰다 (ΔJ).

**분류 기준**:
- **결함 (E 또는 S)**: (a) 또는 (b) 에서 각도가 원본으로 돌아온다 → 메시 의존 경계/출발점이 원인.
  형상이 같은데 경계가 움직이는 것은 J 가 평평하든 아니든 **결함**으로 적는다 (경계는 형상의 함수여야 한다).
- **정상적 동점 깨기**: (b) 에서도 각도가 바뀌고, ΔJ ≤ 0.4 %p(= k × 격자 한 칸) 이다 → Q 의 작은 이산화 차이가
  평평한 J 위에서 argmax 를 옮긴 것.
- **구적 결함 의심**: (b) 에서도 바뀌고 ΔJ > 0.4 %p.
- 한 모델에 여러 원인이 겹칠 수 있다 — 그대로 적는다.

### 1.2 옵션 수정 (할 일 2)

- `assign_height_bands(mesh, n_bands, edges_from="centroid")` 와 `select_banded_j(..., band_edges="centroid")` 에
  옵션 **`"bounds"`** 를 추가한다: edges = linspace(정점 z 최소, 최대) = 메시 bounds = `RadiusProfile.z0/z1`.
  중점 분할·면 수와 무관하다(형상의 높이 범위). **기본값은 `"centroid"` 그대로** — 기존 결과·테스트는 바뀌지 않는다.
- 조사 결과 (S) 가 주원인이면 출발점도 메시 독립으로 만드는 옵션을 같은 이름 아래 추가할 수 있다
  (예: 출발점 각도를 면 라벨 대신 bounds 경계로 '면을 자르지 않고' 정하는 방식). 추가하면 무엇을 바꿨는지 §2 에 적는다.
  (Q) 는 이번 수정 범위 밖이다.
- 회귀 테스트: 수정 옵션에서 세분화 ×4 전후 **edges 가 1e-9 안에서 같다** (구·허리·funnel 등 대표 모델).

**재측정**: T4 의 해상도·정렬 교란 6 개(세분화 ×4, 단순화 ×0.5, 중심 0.1·0.5mm, 기울임 1°·3°)에서 밴드2 를
기본(centroid) / 수정(bounds) 두 판으로 다시 고른다. 기본 판은 T4 숫자와 같아야 한다(재현 확인).

**지표**:
- |Δθ| ≤ 2° 인 모델 비율 (T4 와 같은 정의, max_i |Δθᵢ|).
- **J 손실** = J_orig(θ_원본) − J_orig(θ_교란) : 교란 메시에서 고른 각도를 **원본 메시**(같은 판의 edges)에서 평가했을 때 J 가
  얼마나 줄었나 (%p). 모델별 값, 중앙값·최대, ≤ 0.4 %p 인 모델 수.
- 툴패스 검사기 A 미지지 mm: 원본 메시에서 기본 판·수정 판 밴드2 (층고 0.3·0.4) — 수정이 품질을 깎는지.
  교란 메시의 mm 는 각도가 바뀐 경우만 재고 T4 처럼 Δmm 중앙값을 적는다.

**사전 기준**:
1. **세분화 결함 해소**: 수정 판에서 세분화 ×4 의 edges 가 21/21 같고, 밴드2 |Δθ| ≤ 2° 가 **21/21** 이면 "해소".
   |Δθ| = 0 이 21/21 이면 "완전 해소". 아니면 남은 모델과 그 원인(1.1 분류)을 적는다.
2. **부작용 없음**: 다른 교란 5 개 각각에서 수정 판의 ≤2° 모델 수가 기본 판보다 **2 개 넘게 줄지 않는다**.
   (견고하다고 주장하는 기준은 T4 와 같이 축의 모든 교란에서 ≥ 90% — 이번에도 같은 문장으로 적는다.)
3. **품질 비열등**: 원본 메시에서 수정 판 밴드2 의 미지지 mm 가 기본 판보다 0.5mm 넘게 나빠지는 모델이
   층고마다 **21 중 2 개 이하**. 넘으면 "수정이 품질을 깎는다" 로 적는다.
4. 기본값을 바꿀지는 이 문서에서 판정하지 않는다 (옵션 추가까지만).

### 2.1 원인 — 경계가 아니라 '면 중심 한 점 구적' 이다 (§1.1 의 가설은 틀렸다)

  층간격 제약 위반으로 실현 불가다. 즉 원본의 [26,22] 는 거친 메시가 블렌드를 '못 본' 결과다(E 와 Q 가 겹친 경우).

### 2.2 옵션 수정 (`band_edges="bounds"`) — 재측정

| 교란 | 기본 ≤2° | =0 | 최대 \|Δθ\| | J 손실 중앙 / 최대 (%p) | ≤0.4 | bounds ≤2° | =0 | 최대 | J 손실 중앙 / 최대 | ≤0.4 |
|---|---|---|---|---|---|---|---|---|---|---|
| 세분화 ×4 | 17/21 | 13 | 4° | 0.000 / 0.388 | 21/21 | 17/21 | 13 | 14° | 0.000 / 0.129 | 21/21 |
| 단순화 ×0.5 | 14/21 | 5 | 22° | 0.098 / 0.400 | 20/20 | 15/21 | 6 | 8° | 0.071 / 0.400 | 20/20 |
| 중심 0.1mm | 13/21 | 9 | 22° | 0.007 / 0.115 | 21/21 | 14/21 | 10 | 8° | 0.000 / 0.211 | 21/21 |
| 중심 0.5mm | 15/21 | 7 | 10° | 0.056 / 0.166 | 21/21 | 15/21 | 6 | 10° | 0.066 / 0.166 | 21/21 |
| 기울임 1° | 10/21 | 5 | 8° | 0.050 / 0.424 | 19/20 | 10/21 | 5 | 10° | 0.059 / 0.436 | 20/21 |
| 기울임 3° | 11/21 | 2 | 44° | 0.097 / 7.329 | 17/19 | 11/21 | 3 | 44° | 0.085 / 7.329 | 16/20 |

J 손실 = 교란 메시에서 고른 각도를 **원본 메시**에서 평가했을 때 J 가 준 양. 분모가 21 보다 작은 칸은 교란 해가 원본 메시에서
층간격 제약을 어겨 실현 불가인 경우다(구 단순화·기울임 3°, funnel 기울임 3°, 허리3 ×2 기울임 1°). 기울임 3° 의 7.33 은 mushroom
(0° → [−28, 44], 형상이 바뀐 경우 — T4 §3.2).

**사전 기준 판정**
1. 세분화 결함 해소 — **불통과.** bounds 경계는 세분화 전후 21/21 같지만(최대 이동 0, 기본 판은 1.67mm),
   밴드2 각도 ≤2° 는 17/21 로 그대로이고 바뀐 4 모델(구·허리3 ×1.2·×1.3·funnel)도 같다. funnel 은 bounds 판에서
   [18,40] → [24,26] (14°) 로 오히려 더 크게 바뀐다. 남은 원인은 전부 §2.1 의 Q 다.
2. 부작용 없음 — **통과.** 다른 교란 5 개 모두 bounds 의 ≤2° 수가 기본보다 2 개 넘게 줄지 않는다(15/14, 14/13, 15/15, 10/10, 11/11).
3. 품질 비열등 — **통과.** 원본 메시에서 bounds 가 다른 각도를 고르는 모델은 funnel 하나다([26,22] → [18,40]):
   미지지 0.3mm 층고 2.2 → 1.2 mm(좋아짐), 0.4mm 층고 809 → 911 mm(나빠짐). 나머지 20 모델은 각도가 같고 mm 차 < 0.05.
- 견고(축의 모든 교란 ≥ 90%)는 두 판 모두 해상도·정렬 축 **둘 다 아니다.**
- 대신 **J 손실로 보면 견고하다**: 해상도·정렬 교란에서 실현 가능한 해의 J 손실이 0.4 %p 안인 비율이 기울임 3° 를 빼면 95~100 %다.
  각도는 흔들려도 **고른 해가 원본에서 거의 최선**이다 — T4 §3.2 의 '평평한 J' 해석을 J 손실로 직접 확인한 것.

**결론**: 메시 독립 경계 옵션은 넣었지만(기본값 불변, 회귀 테스트 `tests/test_band_edges_mesh_independent.py`),
**세분화에서 각도가 바뀌는 문제는 경계 때문이 아니므로 이 옵션으로 고쳐지지 않는다.** 고칠 대상은 J 의 면적 적분
(서포트·평균|θ|·블렌드 면적)을 면 중심 한 점으로 세는 구적이다 — 블렌드 슬랩과 면의 겹친 넓이로 세거나 면을 블렌드
경계에서 자르는 방식이 후보다(이번 범위 밖, 다음 시험 후보).

### 2.3 작은 Δθ 병합 — 민감도 (사후 · 판정 밖)

**전제가 이 브랜치에서는 재현되지 않는다.** serene-cray 실험 3 의 보류 구 rand:5·rand:10 은 그 브랜치 코드에서 26°→24° 를
골랐지만, 이 브랜치의 지금 코드(같은 생성 규칙·시드 20261110)에서는 **둘 다 [36°, 28°] (|Δθ| = 8°)** 를 고른다.
그래서 |Δθ| < 4° 병합 규칙은 이 두 모델에 걸리지 않는다.

| 모델 | 균일 J | 밴드2 | 층고 0.3 미지지 mm 낙관 / 비관 (밴드2 · 균일) | 층고 0.4 (밴드2 · 균일) |
|---|---|---|---|---|
| rand:5 (구 r=8.9) | 26° | 36°→28° | 0.7 / 370 · 4.9 / 326 | 24.7 / 286 · 38.0 / 444 |
| rand:10 (구 r=5.8) | 26° | 36°→28° | 0.7 / 163 · 2.8 / 139 | 10.0 / 63 · 16.4 / 186 |
| 구 (표본) | 28° | 28°→20° | 7.7 / 533 · 7.7 / 410 | 94.2 / 538 · 35.6 / 578 |
| sphere (데모) | 32° | 32°→26° | 1.2 / 454 · 1.2 / 367 | 57.7 / 550 · 20.5 / 572 |

- 이 브랜치에서 보류 구 두 개의 밴드2 는 낙관 지지에서 균일보다 낫고(두 층고 모두), 비관 지지에서는 층고 0.3 에서 지고
  0.4 에서 이긴다. serene-cray 의 '밴드2 가 비관에서 3~6 %p 진다'와 같은 방향은 층고 0.3 에서만 보인다.
- 21 모델 표본에서 병합 규칙이 지우는 밴드: 문턱 2° → 0 개, **4° → 허리 r=7 하나**([18,16], mm 는 균일과 똑같아 변화 없음),
  6° → 허리 r=7 + funnel(기본 판 [26,22]; 지우면 층고 0.3 1.9 mm 로 0.3 좋아지고 0.4 는 910 mm 로 101 mm 나빠진다).
- 구·sphere 처럼 |Δθ| 6~8° 인 밴드가 층고 0.4 에서 균일에 크게 진다(94 대 36, 58 대 21 mm). '작은 Δθ' 문턱으로는 이것을 못 잡는다 —
  지는 이유는 Δθ 크기가 아니라 **블렌드가 뚱뚱한 곳(구 r_b 7.6mm)에 놓이는 것**으로 보인다(그림 D (d)).
