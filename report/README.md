모든 오버행 수치는 **실제 툴패스**를 검사기로 잰 '진짜 오버행 %p' 이고, 낙관(처진 비드도

⚠ 전부 시뮬레이션 경향이다. 물리(브리징·수축·냉각)는 실험 4(실물)만 말할 수 있다.

## 한 줄 요약

> 밴드(가변각) 원뿔은 **같은 왜곡량을 쓴 균일 원뿔**보다 오버행이 적다 — 층고 0.3 mm 에서는
> 두 지지 모델 모두에서(16 모델 중 15·14 승). 층고 0.4 mm 에서는 **지지 모델에 따라 정반대**
> (낙관 15 승, 비관 1 승)라서 실물 출력이 판정한다. 비용 축으로 보면 램프에서 밴드2 는
> 오버행 0 을 **균일 4° 만큼의 시간**에 얻는다 (오버행 0 인 균일 36~40° 는 1.6~1.8 배 느리다).
> 대가는 표면 계단이다.

## 실험 1 — 형상 의존성 (17 모델) → `exp1_table.md`, `fig1_*`, `fig2_delta_exp1.png`

기준선은 **등왜곡 균일**(균일각 0~44° 스윕 곡선을 밴드의 평균 왜곡각에서 보간). tie |Δ|<0.1 %p.

| 층고 | 지지 모델 | 밴드2 vs 등왜곡 균일 | 밴드2 vs J 균일 |
|---|---|---|---|
| 0.3 | 낙관 | **15 승 1 무 0 패** | 9 승 7 무 0 패 |
| 0.3 | 비관 | **14 승 1 무 1 패** | 10 승 1 무 5 패 |
| 0.4 | 낙관 | **15 승 0 무 1 패** | 9 승 2 무 5 패 |
| 0.4 | 비관 | **1 승 0 무 15 패** | 0 승 0 무 16 패 |

- 구: 선택기가 밴드를 **쓰지 않았다**(28°→28°) — H2 예측대로
- 유일한 0.3 mm 패: **허리3 ×2** (밴드 42°→28°, 평균 36°). 아주 뚱뚱한 모델은 등왜곡 균일이 이미 오버행 0
- tie 기준을 0.05 / 0.20 으로 바꿔도 승패 수가 거의 같다 (표의 민감도 열)
- J 균일 대비가 약한 이유: J 균일은 밴드보다 **왜곡을 더 쓴다** (예: 허리3 ×1.3 은 J 균일 34°, 밴드 평균 19°) — 그래서 주 비교는 등왜곡이다

## 실험 5 — 왜곡의 비용: 왜 그냥 균일 44° 가 아닌가 → `exp5_cost_table.md`, `fig5_cost.png`

균일각을 키우면 오버행은 0 으로 가지만 **출력 시간·표면이 나빠진다**. REP5X G-code 를 실제로
뽑아 `motion.plan_motion`(REP5X 실측 축 한계, 되감기 제외)으로 잰 값:

| 램프, 층고 0.3 | 출력 시간 | 오버행 낙관 / 비관 | 계단 정렬비 (평면=1) |
|---|---|---|---|
| 균일 4° | 21.0 분 | 1.37 / 5.41 | 0.98 |
| 균일 24° (실험 4 비교군) | 28.3 분 | 0.27 / 4.11 | 0.88 |
| 균일 36° (오버행 0 이 처음 되는 각) | 35.3 분 | 0.00 / 0.00 | 0.98 |
| 균일 44° | 42.6 분 | 0.02 / 1.17 | 1.08 |
| **밴드2 [30°→0°]** | **21.5 분** | **0.00 / 0.00** | **1.09** |

- 허리 r=3 도 같은 모양: 밴드2 22.1 분, 오버행 0.10 / 4.06 (균일 24° 30.0 분, 0.25 / 3.91)
- 구: 밴드2 = 균일 28° (34.2 분) — 이득 없음
- **대가는 표면**: 밴드의 계단 정렬비 1.09~1.10 은 균일 24° (0.88) 보다 나쁘고 균일 44° 수준이다.
  θ=0 윗부분은 평면 층이라 나팔처럼 벌어진 윗면에서 계단이 커진다. 숨기지 말 것
- 시간이 원뿔에서 급증하는 이유(평면 5.7 분 → 4° 21 분): 축 근처에서 C 축이 방위각을 따라
  크게 돌고, C 가속도 500 deg/s² 가 병목이다. 절대 시간은 근사, **비만 본다**

## 실험 4 — 실물 → `physical/`

키트 준비 완료: 블록 무작위 출력 순서, 블라인드 평가지, 실기 프로파일로 재생성 + 사전 점검 스크립트.
⚠ **되감기 교란**: 균일 24° 는 블렌드 위(z>19 mm)에서 들기·되감기를 약 70 회 하고 밴드2 는 0 회다.
표면 자국을 처짐으로 매기면 밴드가 부당하게 유리해진다 → 평가지에 따로 적는 칸을 뒀다.
