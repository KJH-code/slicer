# 보고서용 결과 모음 (2026-11-10)

설계·가설·판정 기준: [`docs/report_experiment_design.md`](../docs/report_experiment_design.md)
(판정 규칙과 보류 시드는 **결과를 보기 전에** 커밋했다 — git 기록이 증거).

모든 오버행 수치는 **실제 툴패스**를 검사기로 잰 '진짜 오버행 %p' 이고, 낙관(처진 비드도
위층을 받친다) / 비관(지지된 재료만 받친다) 두 지지 모델로 같이 잰다.
⚠ 전부 시뮬레이션 경향이다. 물리(브리징·수축·냉각)는 실험 4(실물)만 말할 수 있다.

## 한 줄 요약

> 밴드(가변각) 원뿔은 **같은 왜곡량을 쓴 균일 원뿔**보다 오버행이 적다 — 층고 0.3 mm 에서는
> 두 지지 모델 모두에서(16 모델 중 15·14 승). 층고 0.4 mm 에서는 **지지 모델에 따라 정반대**
> (낙관 15 승, 비관 1 승)라서 실물 출력이 판정한다. 비용 축으로 보면 램프에서 밴드2 는
> 오버행 0 을 **균일 4° 만큼의 시간**에 얻는다 (오버행 0 인 균일 36~40° 는 1.6~1.8 배 느리다).
> 대가는 표면 계단이다. 튜닝에 안 쓴 무작위 모델에서는 허리형에서만 같은 경향이 재현됐고,
> 구에서는 비관 모델 기준으로 밴드가 졌다.

## 실험 1 — 형상 의존성 (17 모델) → `exp1_table.md`, `fig1_*`, `fig2_delta_exp1.png`

기준선은 **등왜곡 균일**(균일각 0~44° 스윕 곡선을 밴드의 평균 왜곡각에서 보간). tie |Δ|<0.1 %p.

| 층고 | 지지 모델 | 밴드2 vs 등왜곡 균일 | 밴드2 vs J 균일 |
|---|---|---|---|
| 0.3 | 낙관 | **15 승 1 무 0 패** | 9 승 7 무 0 패 |
| 0.3 | 비관 | **14 승 1 무 1 패** | 10 승 1 무 5 패 |
| 0.4 | 낙관 | **15 승 0 무 1 패** | 9 승 2 무 5 패 |
| 0.4 | 비관 | **1 승 0 무 15 패** | 0 승 0 무 16 패 |

- 구: 선택기가 밴드를 **쓰지 않았다**(28°→28°) — H2 예측대로
- 유일한 0.3 mm 패: **허리3 ×2** (밴드 42°→28°, 평균 36°). 아주 뚱뚱한 모델은 등왜곡 균일이 이미 오버행 0
- tie 기준을 0.05 / 0.20 으로 바꿔도 승패 수가 거의 같다 (표의 민감도 열)
- J 균일 대비가 약한 이유: J 균일은 밴드보다 **왜곡을 더 쓴다** (예: 허리3 ×1.3 은 J 균일 34°, 밴드 평균 19°) — 그래서 주 비교는 등왜곡이다

## 실험 2 — 층고 × 지지 모델 → `fig3_layer_height.png`, `exp2_layer_height.json`

비교 상대는 J 균일(램프 24°, 허리 r=3 20°, 구 28°). 재실행 결과(2026-11-10):

| 모델 | 낙관 판정 | 비관 판정 |
|---|---|---|
| 램프 (0.20~0.50, 6 점) | 0.20 무승부(0.02 차), 나머지 **밴드2** | 0.20 균일 · **0.25~0.30 밴드2** · 0.35~0.50 균일 |
| 허리 r=3 (0.25~0.50, 4 점) | 전부 **밴드2** | **0.25~0.30 밴드2** · 0.40~0.50 균일 |
| 구 (0.25~0.50, 4 점) | 무승부 (밴드를 안 씀) | 무승부 |

- 비관 판정 경계는 **0.30~0.35 mm** (램프), **0.30~0.40 mm** (허리 r=3) — 이전 결과 재현
- 새로 보인 것: 램프는 **0.20 mm 에서도 비관 판정이 균일** 쪽(0.78 %p 차). 그래서 "얇을수록 밴드가
  유리" 가 아니라 **0.25~0.30 mm 창**에서만 두 모델이 함께 밴드를 지지한다. 0.20 은 균일도 오버행 0 이라
  밴드가 얻을 게 없고 블렌드 비용만 남는 자리다
- 실험 1 의 0.3 / 0.4 두 점이 17 모델 전체에서 같은 갈림을 보였다 → 갈림은 램프 하나의 우연이 아니다

## 실험 3 — 보류 모델 (funnel + 무작위 20, 시드 20261110) → `exp3_table.md`, `fig4_delta_exp3.png`

튜닝에 안 쓴 21 모델. 사전에 정한 기준과 단서를 그대로 적용한다.

| | 모델 수 | 낙관 | 비관 |
|---|---|---|---|
| 전체 | 21 | 3 승 3 무 0 패, 밴드 안 씀 15 | 2 승 2 무 2 패, 밴드 안 씀 15 |
| 허리형 (waisted_lobe 3 개) | 3 | **3 승** | 1 승 2 무 |
| 구 (3 개) | 3 | 2 무, 1 밴드 안 씀 | **2 패** (+3.0, +5.8 %p) |
| funnel | 1 | 무 | 승 |
| 원기둥·상자·나팔 (14 개) | 14 | 전부 밴드 안 씀 (평면 오버행 0 — 고칠 게 없다) | |

**사전 기준대로 판정하면:**
- 글자 그대로("보류 표본 밴드 승률이 튜닝 표본의 절반 이하면 H4 기각"): 낙관 승률 3/21 = 14% → **H4 기각**
- 하지만 사전에 적어 둔 단서("무작위 모델은 대부분 허리형이 아닐 수 있다 — 허리 깊이별로 나눠 볼 것")대로
  나누면, 무작위 모델 14/21 은 **오버행 자체가 없는 형상**이고 선택기는 거기서 밴드를 쓰지 않았다(올바른 동작).
  허리형에서는 낙관 3/3 승으로 튜닝 표본과 같은 경향이다
- 보고서에는 **두 판정을 다 적는다.** 무작위 생성 규칙(wjd)이 허리형을 1/5 만 뽑는다는 것도 같이 적는다

**새로 나온 실패 — 구에서 '거의 균일한' 밴드가 비관 모델에서 진다.** 튜닝 표본의 구(r=10)는 선택기가
28°→28° 로 수렴했는데, 보류 구 두 개(r=8.9, 5.8)는 **26°→24°** 라는 2° 차이 밴드를 골랐고
비관 모델에서 등왜곡 균일보다 3~6 %p 나빴다(낙관에서는 무승부). 블렌드 구간이 이득 없이 미지지 연쇄만
만든 것으로 보인다. → 선택기가 **각도 차가 작은 밴드를 버리고 균일로 합치는 규칙**이 필요하다는 근거
(향후 과제로 적는다. 결과를 본 뒤의 수정이므로 이번 판정에는 반영하지 않는다).

## 실험 5 — 왜곡의 비용: 왜 그냥 균일 44° 가 아닌가 → `exp5_cost_table.md`, `fig5_cost.png`

균일각을 키우면 오버행은 0 으로 가지만 **출력 시간·표면이 나빠진다**. REP5X G-code 를 실제로
뽑아 `motion.plan_motion`(REP5X 실측 축 한계, 되감기 제외)으로 잰 값:

| 램프, 층고 0.3 | 출력 시간 | 오버행 낙관 / 비관 | 계단 정렬비 (평면=1) |
|---|---|---|---|
| 균일 4° | 21.0 분 | 1.37 / 5.41 | 0.98 |
| 균일 24° (실험 4 비교군) | 28.3 분 | 0.27 / 4.11 | 0.88 |
| 균일 36° (오버행 0 이 처음 되는 각) | 35.3 분 | 0.00 / 0.00 | 0.98 |
| 균일 44° | 42.6 분 | 0.02 / 1.17 | 1.08 |
| **밴드2 [30°→0°]** | **21.5 분** | **0.00 / 0.00** | **1.09** |

- 허리 r=3 도 같은 모양: 밴드2 22.1 분, 오버행 0.10 / 4.06 (균일 24° 30.0 분, 0.25 / 3.91)
- 구: 밴드2 = 균일 28° (34.2 분) — 이득 없음
- **대가는 표면**: 밴드의 계단 정렬비 1.09~1.10 은 균일 24° (0.88) 보다 나쁘고 균일 44° 수준이다.
  θ=0 윗부분은 평면 층이라 나팔처럼 벌어진 윗면에서 계단이 커진다. 숨기지 말 것
- 시간이 원뿔에서 급증하는 이유(평면 5.7 분 → 4° 21 분): 축 근처에서 C 축이 방위각을 따라
  크게 돌고, C 가속도 500 deg/s² 가 병목이다. 절대 시간은 근사, **비만 본다**
