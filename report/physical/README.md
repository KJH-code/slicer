# 실험 4 실물 출력 키트 — 램프 2×2 (층고 × 전략)

`docs/report_experiment_design.md` 5절을 **오늘 바로 돌릴 수 있게** 만든 것.
판정 기준은 출력 전에 고정돼 있다(아래 4절). 출력물을 보고 나서 바꾸지 않는다.

## 0. 출력 전 (건너뛰면 기계가 상한다)

- [ ] 축 부호 눈 확인 — `G0 B10` 을 치고 노즐이 어느 쪽으로 기우는지 본다
- [ ] 기계 Z 영점과 소프트리밋 확인 (틸트 시 Z 가 음수로 갈 수 있다)
- [ ] `profiles/machine.example.ini` 를 복사해 **실기 값**으로 고친다: `name`(TEMPLATE 지우기), 온도, 호밍(U/V 포함), 프라임 선 좌표, `part_origin_x/y`
- [ ] G-code 재생성 + 사전 점검:
  ```
  bash report/physical/regen_expA.sh profiles/our_machine.ini rep5x
  ```
  → `report/physical/gcode/` 에 4 파일, `rep5x_check` 치명 0 이어야 한다
- [ ] **첫 출력은 램프가 아니라 작은 시험편**(높이 5mm 원기둥 등)으로 축·온도·접착 확인
- [ ] 재료·노즐·온도·속도·냉각·스풀을 8 장 내내 **바꾸지 않는다**. 바꿨으면 노트에 적는다

⚠ 3축 기계로 뽑는다면 `xyz` 모드. 이때 밴드2 는 노즐 간섭 예측이 6.47% (균일 3.51%)
라서 밴드 쪽이 노즐 긁힘으로 망가질 수 있다 — 그 경우 결과를 '전략 차이' 로 읽으면 안 된다.

## 1. 출력 순서 (블록 무작위, 시드 20261110)

`key_DO_NOT_SHOW_RATERS.csv` 에 있다. **출력 담당자만** 연다.

- 블록 1 (1~4번) = 네 조건 한 장씩. **오늘 4 장만 뽑아도 2×2 가 완성된다**
- 블록 2 (5~8번) = 반복. 시간 되면 같은 날, 아니면 다음 날
- 순서를 바꾸지 말 것 — 시간에 따라 변하는 것(노즐 마모, 실 습도)이 조건 차이로 섞인다
- 다 뽑으면 바닥에 **코드 글자만** 마커로 적는다 (조건·층고 적지 말 것)

## 2. 측정 (블라인드)

조건을 모르는 팀원 **2 명(A, B)** 이 따로 `rating_sheet.csv` 를 채운다. 상의하지 않는다.

**관찰 구역:** 바닥에서 **z ≈ 16~19 mm**(블렌드 구간) 와 그 위의 아래보기 면.
자로 높이를 재서 테이프로 표시해 두면 둘이 같은 곳을 본다.

**처짐 등급 (0~3)**

| 등급 | 기준 |
|---|---|
| 0 | 깨끗. 설계 형상과 구별 안 됨 |
| 1 | 비드가 늘어지거나 물결이 보이지만 **층은 연속** |
| 2 | 층 분리·틈·구멍이 **일부** 있음 |
| 3 | 무너짐 · 실 뭉침 · 출력 실패 |

**최대 처짐(mm):** 캘리퍼스, 또는 자를 같이 넣고 찍은 사진에서 설계선 대비 최대 편차.

**사진:** 같은 거리·같은 각도·**비스듬한 조명 한 방향**(계단·처짐이 잘 보인다).
파일명 = 코드 (예: `R_side.jpg`).

## 3. 기록할 것 (출력 담당자)

| 코드 | 시작 시각 | 걸린 시간 | 성공? | 특이사항 (노즐 긁힘, 축 근처 감속, 떨림 …) |
|---|---|---|---|---|

시간은 실험 D(출력 시간 모델 검증)에도 쓴다 — 추가 출력 없이 공짜다.

## 4. 판정 (출력 전에 고정 — `experiment_plan.md` 1-bis 와 같다)

조건별로 두 평가자의 블렌드 구간 등급 평균을 낸다 (반복이 있으면 그것도 평균).

| 관찰 | 결론 |
|---|---|
| **0.3mm** 에서 밴드2 가 균일보다 등급이 **1 이상 나쁨** | 두 지지 모델(낙관·비관)이 **다 틀렸다** — 판정식 자체를 다시 봐야 한다 |
| 0.3mm 밴드2 ≤ 균일, **0.4mm 밴드2 가 균일보다 1 이상 좋음** | **낙관 모델 채택** — 처진 비드도 위층을 받친다. 밴드 우세 주장 유지 |
| 0.3mm 밴드2 ≤ 균일, **0.4mm 밴드2 가 균일보다 1 이상 나쁨** | **비관 모델 채택** — 밴드 우세 주장을 층고 0.3mm 이하로 **한정** |
| 0.4mm 에서 차이 < 1 등급 | 이 모델·이 기계에서는 **구별 불가**. 그것도 결과로 적는다 |
| 두 평가자 차이가 2 등급 이상 | 그 출력물은 등급 대신 사진으로만 보고하고 이유를 적는다 |

예측(계산, 진짜 오버행 %p, 낙관 / 비관):

| 층고 | 균일 24° | 밴드2 [30°→0°] | 낙관 판정 | 비관 판정 |
|---|---|---|---|---|
| 0.3 | 0.267 / 4.113 | 0.000 / 0.000 | 밴드2 | 밴드2 |
| 0.4 | 1.210 / 7.644 | 0.767 / 8.528 | 밴드2 | **균일** |
