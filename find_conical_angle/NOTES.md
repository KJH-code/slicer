# 팀메 탐색 알고리즘을 우리 검증 도구로 — 예측과 결과

규칙은 `docs/dof_ladder.md` 와 같다. **재기 전에 예측을 적고**, 틀리면 취소선으로 남긴다.
자는 전부 바깥 저장소 것이다: 해석식 자(`conical/s3io.py` `support_fraction_dirs`,
45°, 바닥 제외) · 툴패스 검사기 A 의 **진짜 오버행 %p**(`compare_waist.run_pipeline`,
층고 0.4) · 평균 기울기.

## 0. 쓰기 전에 본 것

램프 하나를 팀메 CLI 로 돌려 봤다(다리 만들기 전, 2026-10-30):
균일 outward 14.03°, 성분 2개(구 밑면 4,032면 / 벌어진 윗부분 1,408면), 둘 다
`q=None → κ=−0.3`(아랫방향 경계 면적 0), 밴드 [17.94°, 9.08°], h 구간 0~10.6 과
20.3~31.1, 전이 h=15.44. 그 밖의 모델·수치는 안 봤다.

비교 대상(이미 아는 값, `dof_ladder_results.json`): 램프 균일 J 24° → 0.69 %,
밴드2 J [30, 0] → 0.00 %, 균일 최소 30° → 0.00 %. 툴패스(0.4mm, 낙관): 균일 24°
1.21 %p, 밴드2 0.77 %p (`docs/experiment_plan.md`).

## 1. 예측 (2026-10-30, 재기 전)

**P1. 면적가중 평균은 구조적으로 절반을 남긴다.** 성분 각도를 면 최소각의 평균으로
잡으면 평균보다 큰 최소각을 가진 면은 그 각도에서 **위반**한다. 팀메 자신의
`selected_angle_allows_all` 이 램프 두 성분에서 모두 False 일 것이고, 위반 면적이
성분 면적의 30~60 % 일 것이다.

**P2. 그래서 우리 자(45°)로 재면 팀메 균일은 우리 균일 J 와 균일 최소 사이에 온다.**
램프: 0.69 %(J 24°) 보다 높고 평면 7.90 % 보다 훨씬 낮다 — 예측 **1~4 %**.
κ=−0.3 이 엄격해서 각도가 커지는 효과와 평균이 깎는 효과가 상쇄된다.

**P3. 팀메 밴드는 램프의 목을 찾는다.** 전이 h=15.44 가 우리 선택기가 옮긴 블렌드
(16.35~18.66)와 3mm 안에 있다. 층간격 제약을 걸어 프로필로 만들면 블렌드 폭은 우리와
비슷(2~3mm)하고, 툴패스 진짜 오버행은 **우리 밴드2(0.77 %p)보다 나쁘되 균일 24°
(1.21 %p)와 비슷**할 것이다 — 아랫밴드가 30° 가 아니라 18° 라서.

**P4. κ 를 고정 45° 로 바꾸면 각도가 내려가고 우리 자 서포트는 올라간다.** 램프
균일 14° → 8~11°, 해석식 서포트 2배 이상.

**P5. S³ 모델(비축대칭)에서 팀메 균일 각도는 8~25° 사이, 기울기는 우리 균일
최소(22~44°)의 절반 이하, 해석식 서포트는 우리 균일 J(0° 가 많음)보다 낫고 균일
최소보다 나쁘다.** 즉 사다리에서 **J 선택선과 능력선 사이**에 놓인다. ring 에서는
inward 가 선택될 가능성이 있다(동률 규칙이 inward 우선).

**P6. 팀메 밴드 수는 성분 수에 묶인다.** teapot·bunny 같은 모델은 성분이 수십 개라
병합 후에도 밴드 4개 이상, 전이가 많아 층간격 제약을 건 프로필에서 각도 삭감 메모가
여러 개 붙을 것이다.

## 2. 판정 기준 (재기 전)

| 관찰 | 뜻 | 하는 일 |
|---|---|---|
| P1 맞음 | 선택 규칙(평균)이 첫 수정 대상 | 평균 → "면적 가중 분위수 p"(p=1 이면 전부 통과) 로 바꾸고 p 를 손잡이로. 우리 자·툴패스로 p 스윕 |
| P1 틀림 (전부 통과가 많음) | 최소각 분포가 좁다 | 선택 규칙은 두고 κ 규칙부터 본다 |
| P3 맞음 | 팀메의 h 구간 병합이 **형상에서 밴드 경계를 찾는** 좋은 방법 | linspace 대신 이것을 경계 후보로 쓴다. 각도는 우리 능력선 방식(전수/ε-제약)으로 |
| P3 틀림 (전이가 목에서 멀다) | h 구간 중점이 좋은 경계가 아니다 | 전이를 반경 최소로 옮기는 우리 `max_shift` 가 살리는지 본다 |
| P5 에서 팀메 균일이 우리 J 보다 서포트도 낮고 기울기도 낮음 | 팀메 선택 규칙이 J 보다 낫다 | J 를 버리는 근거. 1순위 작업(ε-제약)과 합친다 |
| S³ 모델 어디서든 inward 선택 | 5축 간섭 불안전(README 17) | 다리에서 outward 만 허용하는 스위치를 켜고 다시 잰다 |
